# 第 1 章：数系（Number Systems）

## 章概览

什么是"数"？

这个问题看似简单，答案却贯穿了数千年的数学史。牧羊人数羊时发明了自然数；商人计算盈亏时需要了负数；工匠分割布料时引入了分数；建筑师测量对角线时发现了无理数；数学家求解方程时创造了复数。每一种新的"数"，都是为了回答一个在旧框架下无法回答的问题。

本章沿着这条历史线索，系统地构建从自然数到复数的数系链：

$$\mathbb{N} \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R} \subset \mathbb{C}$$

在每一步扩展中，我们将关注三个问题：
1. **为什么**需要扩展？（旧数系缺少什么？）
2. **怎样**扩展？（新数如何从旧数构造？）
3. **代价**是什么？（扩展后失去了什么？）

## 学习成果

本章完成后你将能够：

- **描述每个数系的定义和基本性质**：$\mathbb{N}$（良序性、归纳原理）、$\mathbb{Z}$（有序环）、$\mathbb{Q}$（有序域、稠密性）、$\mathbb{R}$（完备有序域）、$\mathbb{C}$（域、不可排序）
- **解释每次扩展的动机**：减法 → $\mathbb{Z}$，除法 → $\mathbb{Q}$，求极限/开方 → $\mathbb{R}$，求根 → $\mathbb{C}$
- **理解关键性质的得与失**：离散 → 稠密 → 完备；有序 → 不可全序（$\mathbb{C}$）
- **进行基本的构造论证**：如用等价类构造 $\mathbb{Z}$ 和 $\mathbb{Q}$
- **证明关键事实**：如 $\sqrt{2} \notin \mathbb{Q}$、有理数的稠密性
