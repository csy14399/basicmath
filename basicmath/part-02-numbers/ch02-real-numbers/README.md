# 第 2 章：实数的深入（Deep Dive into Real Numbers）

## 章概览

在第 1 章中，我们建立了从自然数到复数的完整数系链 $\mathbb{N} \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R} \subset \mathbb{C}$，并且在 §3 中**暂时接受**了实数的完备性公理——"有上界的非空集合必有上确界"。这条公理是整个分析学的基石，却是所有公理中最不"显然"的一条。

本章的任务就是**向下挖掘**：深入理解实数为什么特殊，完备性意味着什么，以及它如何从更基本的构造中浮现出来。

## 学习成果

本章完成后你将能够：

- **陈述并运用有序域公理**：理解 $\mathbb{R}$ 作为有序域的代数和序结构
- **证明阿基米德性质及其推论**：包括 $\inf\{1/n : n \in \mathbb{N}^+\} = 0$
- **运用有理数稠密性定理**：任意两个实数之间存在有理数
- **理解区间套定理**：闭区间套有唯一公共点
- **深入理解完备性公理**：从暂认到兑现——通过 Dedekind 切割理解完备性的来源
- **解释为什么 $\mathbb{Q}$ 不完备**：构造具体的无有理数上确界的例子
- **比较完备性的多种等价形式**：上确界原理、区间套、Cauchy 序列、单调收敛
