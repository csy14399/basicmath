# 第二部分：数系与数论（Number Systems and Number Theory）

## 本部分概览

数学从数开始。人类最早的数学活动是计数——一只羊、两只羊、三只羊——而今天数学家研究的"数"已经远远超出了指头能数的范围。从自然数到整数，从整数到有理数，从有理数到实数，再从实数到复数，每一次扩展都是为了解决一个在旧数系中"不可能"的问题。这条扩展之路，就是数学最基本的叙事线之一。

与此同时，最简单的数——整数——却蕴含着最深刻的奥秘。素数的分布、整除的规律、同余的结构……数论（number theory）将这些问题变成严格的数学理论，高斯称之为"数学的女王"。

本部分包含三章：

| 章 | 主题 | 内容 |
|----|------|------|
| [第 1 章：数系](ch01-number-systems/README.md) | 数系（number systems） | $\mathbb{N} \to \mathbb{Z} \to \mathbb{Q} \to \mathbb{R} \to \mathbb{C}$：逐步构建数系，理解每次扩展的动机与代价 |
| [第 2 章：实数的深入](ch02-real-numbers/README.md) | 实数的深入（deep dive into real numbers） | 完备性公理、确界原理、实数的十进制表示、不可数性的严格证明 |
| [第 3 章：数论](ch03-number-theory/README.md) | 初等数论（elementary number theory） | 整除性、素数、最大公因数、同余、费马小定理、欧拉函数 |

这三章的关系：第 1 章建立数的"大地图"——从 $\mathbb{N}$ 到 $\mathbb{C}$ 的全景；第 2 章"向下挖掘"，深入理解实数的精细结构；第 3 章"回头审视"，探索最古老的数——整数——中隐藏的深层规律。

## 学习路线

```
Ch01 数系 → Ch02 实数的深入
             ↘
              Ch03 数论
```

- **第 1 章（数系）** 是起点，建立从 $\mathbb{N}$ 到 $\mathbb{C}$ 的整体图景。
- **第 2 章（实数的深入）** 依赖第 1 章对实数的初步理解，深入讨论完备性和拓扑性质。
- **第 3 章（数论）** 主要依赖第 1 章中关于 $\mathbb{N}$ 和 $\mathbb{Z}$ 的内容，可以与第 2 章并行学习。

## 前置知识

**第一部分（数学基础）**。具体而言：

- **集合论**（Part 1 Ch02）：集合运算、关系、等价关系、函数、基数——数系的构造依赖这些工具。
- **逻辑**（Part 1 Ch01）：命题逻辑与谓词逻辑——精确表述定理和证明需要逻辑语言。
- **证明方法**（Part 1 Ch03）：直接证明、反证法、数学归纳法——本部分的每一章都需要独立进行数学证明。

## 本部分完成后你将能够

- **理解数系的层次结构**：清晰描述 $\mathbb{N} \subset \mathbb{Z} \subset \mathbb{Q} \subset \mathbb{R} \subset \mathbb{C}$ 每一步扩展的动机、方法和得失
- **运用实数的完备性**：理解确界原理及其在分析学中的核心地位，并运用它证明基本定理
- **掌握初等数论的工具箱**：运用整除性、素数分解、同余算术解决问题
- **欣赏数学的统一性**：看到代数结构（群、环、域）如何自然地从数系的研究中浮现
- **为后续部分做好准备**：本部分的内容是代数（Part 3）、函数与分析预备（Part 4、Part 6）的基础
