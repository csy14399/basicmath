# 第 3 章：数论（Number Theory）

## 章概览

高斯称数论为"数学的女王"（die Königin der Mathematik）。这门学科研究的是最简单、最古老的数——整数——中隐藏的深层规律。什么数能被什么数整除？质数如何分布？方程 $ax + by = c$ 何时有整数解？这些问题看似初等，答案却往往出人意料地深刻。

数论是纯数学中最古老的分支之一，其历史可以追溯到公元前 300 年欧几里得的《几何原本》。但它绝非"陈旧"——20 世纪以来，数论在密码学（cryptography）、编码理论（coding theory）和计算机科学中找到了惊人的应用。RSA 加密算法的安全性直接依赖于大整数分解的困难性。

本章涵盖初等数论的三大主题：整除性与质数、同余与模运算、丢番图方程。
