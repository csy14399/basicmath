# 第 3 章 数论 — 练习题

## §1 整除性与质数（Divisibility and Primes）

1. ★☆☆ 计算 $\gcd(84, 36)$，写出欧几里得算法的每一步。

2. ★☆☆ 将 $5040$ 分解为质因数的乘积。

3. ★☆☆ 求 $\gcd(91, 65)$，并找出整数 $x, y$ 使得 $\gcd(91, 65) = 91x + 65y$。

4. ★★☆ 证明：若 $a \mid b$ 且 $a \mid c$，则 $a \mid (b^2 + c^2)$。

5. ★★☆ 证明：对任意 $n \in \mathbb{Z}^+$，$\gcd(n, 2n + 1) = 1$。

6. ★★☆ 证明：若 $\gcd(a, b) = 1$ 且 $a \mid c$，$b \mid c$，则 $ab \mid c$。

7. ★★☆ 用算术基本定理证明：$\sqrt{3}$ 是无理数。

8. ★★★ 证明：$\gcd(a, b) \cdot \text{lcm}(a, b) = |ab|$ 对所有正整数 $a, b$ 成立。

9. ★★★ 证明：对任意 $n \geq 2$，在 $n! + 2, n! + 3, \ldots, n! + n$ 中每个数都是合数。（由此构造任意长的连续合数序列。）

10. ★★★ 设 $p$ 是大于 $3$ 的质数。证明 $p^2 \equiv 1 \pmod{24}$。

## §2 同余与模运算（Congruences and Modular Arithmetic）

11. ★☆☆ 计算 $7^{50} \bmod 11$。

12. ★☆☆ 在 $\mathbb{Z}/7\mathbb{Z}$ 中，求 $[3]$ 的乘法逆元。

13. ★☆☆ 判断 $x \equiv 3 \pmod{6}$ 且 $x \equiv 5 \pmod{6}$ 是否有解。

14. ★★☆ 用中国剩余定理求满足以下条件的最小正整数 $x$：
    $$x \equiv 1 \pmod{5}, \quad x \equiv 2 \pmod{7}, \quad x \equiv 3 \pmod{9}$$

15. ★★☆ 证明：$n^3 - n$ 对所有整数 $n$ 都是 $6$ 的倍数。

16. ★★☆ 求 $2^{1000} \bmod 13$。

17. ★★☆ 证明：若 $p$ 是奇质数，则 $\mathbb{Z}/p\mathbb{Z}$ 中恰好有 $(p-1)/2$ 个非零元素是完全平方。

18. ★★★ 设 $p$ 是质数，$p \geq 5$。证明 $1^{p-1} + 2^{p-1} + \cdots + (p-1)^{p-1} \equiv -1 \pmod{p}$。

19. ★★★ 设 $\gcd(a, m) = 1$。证明同余方程 $ax \equiv b \pmod{m}$ 恰好有一个模 $m$ 的解。

20. ★★★ 利用 Fermat 小定理证明：若 $p$ 是奇质数且 $p \mid (a^2 + b^2)$，则 $p \equiv 1 \pmod{4}$ 或 $p \mid a$ 且 $p \mid b$。（提示：考虑 $(a/b)^2 \equiv -1 \pmod{p}$ 的两边取 $(p-1)/2$ 次方。）

## §3 丢番图方程初步（Diophantine Equations）

21. ★☆☆ 求 $4x + 6y = 10$ 的所有整数解。

22. ★☆☆ 用参数化公式生成 $m = 5, n = 2$ 对应的勾股数。

23. ★★☆ 求 $15x + 25y = 100$ 的所有非负整数解。

24. ★★☆ 证明 $x^2 + y^2 \equiv 3 \pmod{4}$ 无解，从而 $x^2 + y^2 = 4k + 3$ 无整数解。

25. ★★☆ 找出所有满足 $a^2 + b^2 = c^2$ 且 $c \leq 50$ 的本原勾股数。

26. ★★★ 证明方程 $x^2 + y^2 = 3z^2$ 的唯一整数解是 $x = y = z = 0$。（提示：用模 $3$ 的方法加无穷递降。）

27. ★★★ 求所有正整数解 $(x, y)$ 使得 $x^2 - y^2 = 105$。

28. ★★★ 证明：不存在正整数 $x, y$ 使得 $x^2 + 3y^2 = 8$。

29. ★★★ 设 $p$ 为奇质数。证明方程 $x^2 \equiv -1 \pmod{p}$ 有解当且仅当 $p \equiv 1 \pmod{4}$。

30. ★★★★ 证明：方程 $x^4 - y^4 = z^2$ 没有正整数解。（提示：用无穷递降法。）
