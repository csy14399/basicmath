# 第 1 章：方程（Equations）

## 章概览

"解方程"也许是大多数人对"代数"的第一印象——给定一个包含未知数的等式，找出满足它的数。这个看似简单的问题，却贯穿了从古巴比伦到现代数学的整个代数学发展史。

本章从最简单的一元一次方程出发，逐步探索一元二次方程（求根公式的推导）、方程组（几何直觉与代数方法的交融），直到高次方程与根式解的深刻问题。在最后一节，我们将遇到代数学史上最震撼的定理之一——**Abel-Ruffini 定理**：五次及以上的一般方程没有根式解。这个否定性结果不是终点，而是通向抽象代数的起点。

## 前置知识

- **Part 1 第 3 章（证明方法）**：直接证明、数学归纳法——推导公式和验证结果的基本方法
- **Part 2 第 1 章（数系）**：$\mathbb{R}$ 和 $\mathbb{C}$ 的基本性质——方程的解可能是实数或复数
- **Part 2 第 1 章 §4（复数引入）**：复数的四则运算——处理判别式为负的情况

## 学习成果

本章完成后你将能够：

- **系统求解一元一次和一元二次方程**：理解求根公式的推导过程而非仅仅记忆
- **运用判别式分析方程根的情况**：$\Delta > 0$（两个不同实根）、$\Delta = 0$（重根）、$\Delta < 0$（共轭复数根）
- **灵活运用韦达定理**：从根与系数的关系中获取信息，而不必实际求根
- **求解线性方程组**：掌握代入法和消元法，理解方程组解的几何意义
- **了解高次方程的历史和基本结果**：Cardano 公式、Ferrari 方法、Abel-Ruffini 定理的意义
- **体会从具体到抽象的数学思维**：理解为什么"不可解"的结论反而推动了数学的深刻发展
