# §3 高次方程与根式解（Higher-Degree Equations and Radical Solutions）

**前置知识**：[§1 一元一次与一元二次方程](01-linear-quadratic.md)（二次方程的求根公式与配方法）、[Part 2 第 1 章 §4 复数引入](../../part-02-numbers/ch01-number-systems/04-complex-intro.md)（复数的基本运算与虚数单位 $i$）

**全景图**：二次方程有优雅的求根公式。那三次方程呢？四次方程呢？五次呢？这个自然的追问驱动了从文艺复兴到十九世纪的代数学核心叙事。三次方程的求根公式（Cardano 公式）来得比预期困难得多——它的发现伴随着数学史上最戏剧性的优先权争议。四次方程（Ferrari 方法）在三次方程之后不久被攻克。但五次方程……数学家们奋斗了三个世纪，直到 Abel 和 Ruffini 证明了一个惊人的否定性结论：**一般五次方程不存在根式解**。这个"不可能"的定理不是数学的失败，而是一扇通向更深刻理论——**Galois 理论**和**抽象代数**——的大门。

**预估学习时间**：约 2–3 小时

---

## 动机

二次方程的求根公式

$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

告诉我们：方程的根可以用系数 $a, b, c$ 通过加减乘除和开方来**显式表达**。这种解叫做**根式解**（solution by radicals）。

自然的问题：

- 三次方程 $ax^3 + bx^2 + cx + d = 0$ 是否也有根式解？
- 四次？五次？任意次？

这些问题看似纯粹技术性的，但它们的答案深刻地揭示了代数的本质。

---

## 1. 三次方程与 Cardano 公式

### 1.1 简化形式

一般的三次方程

$$ax^3 + bx^2 + cx + d = 0 \quad (a \neq 0)$$

可以通过代换 $x = t - \frac{b}{3a}$ 消去二次项，化为**压缩三次方程**（depressed cubic）：

$$t^3 + pt + q = 0$$

其中 $p, q$ 可以用 $a, b, c, d$ 表达。这个代换类似于二次方程中的配方——通过平移未知数来简化方程的形式。

**推导**：令 $x = t - \frac{b}{3a}$，代入 $ax^3 + bx^2 + cx + d = 0$ 并展开。由于 $(t - \frac{b}{3a})^3$ 展开后二次项与 $b(t - \frac{b}{3a})^2$ 中的二次项恰好抵消，得到

$$p = \frac{3ac - b^2}{3a^2}, \quad q = \frac{2b^3 - 9abc + 27a^2d}{27a^3}$$

### 1.2 Cardano 公式

> **定理 1**（Cardano 公式，Cardano's formula）
>
> 压缩三次方程 $t^3 + pt + q = 0$ 的一个根为
>
> $$t = \sqrt[3]{-\frac{q}{2} + \sqrt{\frac{q^2}{4} + \frac{p^3}{27}}} + \sqrt[3]{-\frac{q}{2} - \sqrt{\frac{q^2}{4} + \frac{p^3}{27}}}$$

**推导思路（Cardano-Tartaglia 方法）**：

设 $t = u + v$。代入 $t^3 + pt + q = 0$：

$$(u + v)^3 + p(u + v) + q = 0$$

$$u^3 + 3u^2v + 3uv^2 + v^3 + p(u + v) + q = 0$$

$$u^3 + v^3 + (3uv + p)(u + v) + q = 0$$

现在我们**选择** $u, v$ 满足额外条件 $3uv + p = 0$，即 $uv = -\frac{p}{3}$。

于是 $u^3 + v^3 = -q$ 且 $u^3 v^3 = -\frac{p^3}{27}$。

由韦达定理，$u^3$ 和 $v^3$ 是二次方程

$$w^2 + qw - \frac{p^3}{27} = 0$$

的两个根。由二次公式：

$$u^3 = -\frac{q}{2} + \sqrt{\frac{q^2}{4} + \frac{p^3}{27}}, \quad v^3 = -\frac{q}{2} - \sqrt{\frac{q^2}{4} + \frac{p^3}{27}}$$

取立方根得 $t = u + v$，即 Cardano 公式。

### 1.3 三次方程的判别式

三次方程的判别式定义为

$$\Delta_3 = -4p^3 - 27q^2$$

它的符号决定了根的性质：

| 判别式 | 根的情况 |
|--------|----------|
| $\Delta_3 > 0$ | 三个不同的实根 |
| $\Delta_3 = 0$ | 有重根（所有根为实数） |
| $\Delta_3 < 0$ | 一个实根，两个共轭复数根 |

### 1.4 不可约情况（Casus Irreducibilis）

当 $\Delta_3 > 0$（三个不同实根）时，Cardano 公式中的根号下出现**负数**——尽管最终结果是实数！这就是著名的**不可约情况**（casus irreducibilis）。

**例子**：方程 $t^3 - 7t + 6 = 0$ 有三个实根 $t = 1, 2, -3$。但 Cardano 公式要求计算 $\sqrt{-\frac{100}{27}}$，必须经过复数域。

这个现象在历史上产生了深远的影响——它迫使数学家认真对待复数，即使他们只关心实数根。正是三次方程的不可约情况，而不是二次方程的 $\Delta < 0$，真正推动了复数在数学中的合法化。

**例题 1**. 用 Cardano 公式求方程 $t^3 - 6t - 9 = 0$ 的一个根。

**解**：这里 $p = -6$，$q = -9$。

$$\frac{q^2}{4} + \frac{p^3}{27} = \frac{81}{4} + \frac{-216}{27} = \frac{81}{4} - 8 = \frac{49}{4}$$

$$t = \sqrt[3]{\frac{9}{2} + \frac{7}{2}} + \sqrt[3]{\frac{9}{2} - \frac{7}{2}} = \sqrt[3]{8} + \sqrt[3]{1} = 2 + 1 = 3$$

**验证**：$3^3 - 6(3) - 9 = 27 - 18 - 9 = 0$。✓

## 2. 四次方程（Quartic Equations）

### 2.1 Ferrari 方法

在 Cardano 公式发现后不久，他的学生 Lodovico Ferrari（1522–1565）找到了四次方程的解法——通过引入辅助变量，将四次方程转化为一个三次方程（称为**预解式**，resolvent cubic）和两个二次方程。

一般四次方程 $ax^4 + bx^3 + cx^2 + dx + e = 0$ 的求解步骤概述如下：

**第 1 步**：消去三次项。令 $x = t - \frac{b}{4a}$，化为压缩四次方程 $t^4 + pt^2 + qt + r = 0$。

**第 2 步**：引入辅助变量 $y$，将方程改写为两个完全平方之差的形式。

**第 3 步**：选择 $y$ 使得差式也是完全平方，得到关于 $y$ 的**预解三次方程**。

**第 4 步**：用 Cardano 公式解预解三次方程，再回代解两个二次方程。

**结论**：四次方程的根可以用系数通过加减乘除、开平方和开立方来表达——即四次方程**有根式解**。

**例题 2**. 解方程 $x^4 - 10x^2 + 9 = 0$。

**解**：这是双二次方程（bi-quadratic），即缺少奇数次项的四次方程。令 $u = x^2$：

$$u^2 - 10u + 9 = 0$$

$$(u - 1)(u - 9) = 0$$

$u = 1$ 或 $u = 9$。

回代：$x^2 = 1 \Rightarrow x = \pm 1$，$x^2 = 9 \Rightarrow x = \pm 3$。

四个根：$x \in \{-3, -1, 1, 3\}$。

## 3. Abel-Ruffini 定理——五次方程的不可解性

### 3.1 问题的提出

到十八世纪末，数学家已经有了一次、二次、三次、四次方程的根式解公式。自然的下一步是寻找**五次方程的根式解公式**。

Euler、Lagrange、Tschirnhaus 等大数学家都尝试过，但都失败了。问题不在于他们不够聪明——而在于这件事**根本不可能**。

### 3.2 Abel-Ruffini 定理

> **定理 2**（Abel-Ruffini 定理，1799/1824）
>
> 对于次数 $n \geq 5$ 的**一般**多项式方程，**不存在**用系数的加减乘除和开 $k$ 次方来表达的根式解公式。

**关键词解释**：

- "一般"意味着对**所有**系数组合。某些**特殊**的五次方程仍可以用根式求解（例如 $x^5 = 32$，解为 $x = 2$）。
- "不存在根式解公式"不是说方程没有根（代数基本定理保证了根的存在），而是说根不能用系数通过有限次加减乘除和开方来表达。

### 3.3 历史脉络

| 时间 | 人物 | 贡献 |
|------|------|------|
| 约前 2000 年 | 古巴比伦人 | 用文字描述求解二次方程（配方法的雏形） |
| 1545 年 | Cardano（基于 Tartaglia 的工作） | 出版三次方程的求根公式 |
| 1545 年 | Ferrari（Cardano 的学生） | 四次方程的解法 |
| 1770 年 | Lagrange | 系统分析为什么低次方程可解，预见五次的困难 |
| 1799 年 | Ruffini | 第一个（不完全的）五次方程不可根式求解的证明 |
| 1824 年 | Abel | 给出严格证明 |
| 1832 年 | Galois | 创立群论，给出方程可否根式求解的完整判据 |

### 3.4 为什么四次可以而五次不行？

> **[Bridge → 抽象代数]**
>
> 这个问题的深层答案来自 **Galois 理论**（Galois theory），它将方程的可解性与一种称为 **Galois 群**（Galois group）的代数结构联系起来。
>
> 粗略地说：
>
> - 二次方程的 Galois 群是 $S_2$（$2$ 个元素的置换群），它是**可解群**。
> - 三次方程的 Galois 群是 $S_3$（$6$ 个元素），可解群。
> - 四次方程的 Galois 群是 $S_4$（$24$ 个元素），仍然是可解群。
> - 五次方程的 Galois 群是 $S_5$（$120$ 个元素），它**不是**可解群。
>
> "群是否可解"取决于它是否能被分解为一系列特殊的"阶梯"结构（正规子群链的商群是否都是交换群）。$S_5$ 不能被这样分解——因为它包含一个"不可分解"的子群 $A_5$（$60$ 阶交替群，最小的非交换单群）。
>
> 这个故事的完整版本将在 **Part 3 第 5 章（抽象代数初步）** 中继续。

### 3.5 Abel-Ruffini 定理之后

Abel-Ruffini 定理告诉我们五次方程没有根式解公式。但这并不意味着五次方程的根无法描述：

1. **数值方法**：Newton 迭代等算法可以以任意精度逼近根。
2. **椭圆函数**：Hermite（1858）证明一般五次方程的根可以用椭圆模函数表达。
3. **Bring 根式**：通过变换，一般五次方程可以化为 $x^5 + x + a = 0$ 的形式（Bring-Jerrard 正规形式），但这个方程的根仍然不能用根式表达。

**例题 3**. 证明方程 $x^5 - 1 = 0$ 可以用根式求解。

**解**：$x^5 = 1$ 的解是 $5$ 个单位根：

$$x_k = e^{2\pi i k / 5} = \cos\frac{2\pi k}{5} + i\sin\frac{2\pi k}{5}, \quad k = 0, 1, 2, 3, 4$$

$x_0 = 1$ 是显然的实数根。其他四个根可以用根式表达。事实上，

$$\cos\frac{2\pi}{5} = \frac{-1 + \sqrt{5}}{4}$$

这可以验证如下：$x^5 - 1 = (x - 1)(x^4 + x^3 + x^2 + x + 1)$。

设 $\omega$ 是 $x^4 + x^3 + x^2 + x + 1 = 0$ 的根。两边除以 $x^2$：

$$x^2 + x + 1 + x^{-1} + x^{-2} = 0$$

令 $y = x + x^{-1}$，则 $x^2 + x^{-2} = y^2 - 2$：

$$y^2 + y - 1 = 0$$

$$y = \frac{-1 \pm \sqrt{5}}{2}$$

这是根式！从 $y$ 可以进一步解出 $x$（再解一个二次方程），因此 $x^5 = 1$ 的所有根都可以用根式表达。

这与 Abel-Ruffini 定理不矛盾——该定理说的是**一般**五次方程没有根式解，而 $x^5 - 1 = 0$ 是一个**特殊**的五次方程。

## 要点回顾

1. **三次方程**可以通过代换 $x = t - \frac{b}{3a}$ 化为压缩形式 $t^3 + pt + q = 0$，由 **Cardano 公式**给出根式解。
2. **不可约情况**：当三次方程有三个实根时，Cardano 公式中会出现复数——这在历史上推动了复数的接受。
3. **四次方程**通过 **Ferrari 方法**可以化为三次预解式，因此也有根式解。
4. **Abel-Ruffini 定理**：一般的五次及以上方程**没有**根式解公式。
5. 方程可否根式求解的深层原因来自 **Galois 理论**：对称群 $S_n$ 在 $n \geq 5$ 时不是可解群。
6. "不可解"不意味着"没有根"——代数基本定理保证了根的存在，只是根不能用根式表达。

## 自测题

**自测题 1**：将三次方程 $x^3 + 6x^2 + 11x + 6 = 0$ 化为压缩三次形式（提示：令 $x = t - 2$）。

<details>
<summary>答案</summary>

令 $x = t - \frac{b}{3a} = t - \frac{6}{3} = t - 2$。

代入：$(t-2)^3 + 6(t-2)^2 + 11(t-2) + 6$

$= t^3 - 6t^2 + 12t - 8 + 6(t^2 - 4t + 4) + 11t - 22 + 6$

$= t^3 - 6t^2 + 12t - 8 + 6t^2 - 24t + 24 + 11t - 22 + 6$

$= t^3 + (−6+6)t^2 + (12−24+11)t + (−8+24−22+6)$

$= t^3 - t$

压缩形式：$t^3 - t = 0$，即 $t(t-1)(t+1) = 0$，$t \in \{-1, 0, 1\}$。

回代：$x = t - 2$，得 $x \in \{-3, -2, -1\}$。

验证：$x^3 + 6x^2 + 11x + 6 = (x+1)(x+2)(x+3)$。✓
</details>

**自测题 2**：用 Cardano 公式求方程 $t^3 + 6t - 20 = 0$ 的一个根。

<details>
<summary>答案</summary>

$p = 6$，$q = -20$。

$$\frac{q^2}{4} + \frac{p^3}{27} = \frac{400}{4} + \frac{216}{27} = 100 + 8 = 108$$

$$\sqrt{108} = 6\sqrt{3}$$

$$t = \sqrt[3]{10 + 6\sqrt{3}} + \sqrt[3]{10 - 6\sqrt{3}}$$

注意到 $(1 + \sqrt{3})^3 = 1 + 3\sqrt{3} + 9 + 3\sqrt{3} = 10 + 6\sqrt{3}$，
$(1 - \sqrt{3})^3 = 1 - 3\sqrt{3} + 9 - 3\sqrt{3} = 10 - 6\sqrt{3}$。

所以 $t = (1 + \sqrt{3}) + (1 - \sqrt{3}) = 2$。

验证：$8 + 12 - 20 = 0$。✓
</details>

**自测题 3**：为什么 Abel-Ruffini 定理不与 $x^5 = 7$ 有根式解 $x = \sqrt[5]{7}$ 矛盾？

<details>
<summary>答案</summary>

Abel-Ruffini 定理说的是**一般**五次方程（系数任意）没有**统一的**根式解公式。$x^5 = 7$ 是一个**特殊**的五次方程，它的 Galois 群是循环群 $\mathbb{Z}/5\mathbb{Z}$（一个可解群），因此它可以用根式求解。定理禁止的是对所有五次方程都适用的公式，而不是禁止任何特定的五次方程有根式解。
</details>
