# 第 1 章 方程 — 练习题解答

## §1 一元一次与一元二次方程

**1.** 解方程 $5x - 3 = 2x + 9$。

$$5x - 2x = 9 + 3 \implies 3x = 12 \implies x = 4$$

---

**2.** 解方程 $\frac{x+1}{2} - \frac{x-1}{3} = 1$。

两边乘以 $6$：$3(x+1) - 2(x-1) = 6$

$3x + 3 - 2x + 2 = 6$

$x + 5 = 6$

$x = 1$

验证：$\frac{2}{2} - \frac{0}{3} = 1 - 0 = 1$。✓

---

**3.** 用求根公式解方程 $x^2 - 6x + 8 = 0$。

$\Delta = 36 - 32 = 4$

$x = \frac{6 \pm 2}{2}$

$x_1 = 4$，$x_2 = 2$。

韦达定理验证：$x_1 + x_2 = 6 = -\frac{-6}{1}$ ✓，$x_1 x_2 = 8 = \frac{8}{1}$ ✓。

---

**4.** 判断根的情况。

(a) $\Delta = 9 + 40 = 49 > 0$：两个不同实根。

(b) $\Delta = 36 - 36 = 0$：一个重根（$x = \frac{1}{3}$）。

(c) $\Delta = 4 - 20 = -16 < 0$：两个共轭复数根。

---

**5.** 配方法化为顶点式。

$f(x) = 3x^2 + 12x + 7 = 3(x^2 + 4x) + 7 = 3(x^2 + 4x + 4 - 4) + 7$

$= 3(x + 2)^2 - 12 + 7 = 3(x + 2)^2 - 5$

顶点 $(-2, -5)$，最小值 $f(-2) = -5$。

---

**6.** 韦达定理：$x_1 + x_2 = 4$，$x_1 x_2 = 1$。

(a) $x_1^2 + x_2^2 = (x_1 + x_2)^2 - 2x_1 x_2 = 16 - 2 = 14$

(b) $x_1^3 + x_2^3 = (x_1 + x_2)(x_1^2 - x_1 x_2 + x_2^2) = 4(14 - 1) = 52$

(c) $\frac{x_1}{x_2} + \frac{x_2}{x_1} = \frac{x_1^2 + x_2^2}{x_1 x_2} = \frac{14}{1} = 14$

---

**7.** 由韦达定理：$x_1 + x_2 = -(m-1) = 1 - m$，$x_1 x_2 = m + 2$。

$x_1^2 + x_2^2 = (x_1 + x_2)^2 - 2x_1 x_2 = (1-m)^2 - 2(m+2) = 7$

$1 - 2m + m^2 - 2m - 4 = 7$

$m^2 - 4m - 10 = 0$

$m = \frac{4 \pm \sqrt{16 + 40}}{2} = \frac{4 \pm \sqrt{56}}{2} = 2 \pm \sqrt{14}$

还需检验 $\Delta \geq 0$：$\Delta = (m-1)^2 - 4(m+2) = m^2 - 6m - 7 = (m-7)(m+1)$。

$m = 2 + \sqrt{14} \approx 5.74$：$\Delta = (5.74 - 7)(5.74 + 1) < 0$。**不满足**。

$m = 2 - \sqrt{14} \approx -1.74$：$\Delta = (-1.74 - 7)(-1.74 + 1) = (-8.74)(-0.74) > 0$。✓

故 $m = 2 - \sqrt{14}$。

---

**8.** 令 $t = x^2$，$t^2 - 13t + 36 = 0$，$(t - 4)(t - 9) = 0$。

$t = 4$：$x = \pm 2$。$t = 9$：$x = \pm 3$。

四个解：$x \in \{-3, -2, 2, 3\}$。

---

**9.** 分两种情况：

- $k = 0$：方程化为 $-2x + 1 = 0$，$x = \frac{1}{2}$，有实数根。
- $k \neq 0$：$\Delta = 4 - 4k \geq 0$，即 $k \leq 1$。

综合：$k \leq 1$。

---

**10.** 由韦达定理：$\alpha + \beta = p$，$\alpha\beta = q$。

$\alpha^2 + \beta^2 = (\alpha + \beta)^2 - 2\alpha\beta = p^2 - 2q$

$\alpha^2 \beta^2 = (\alpha\beta)^2 = q^2$

以 $\alpha^2, \beta^2$ 为根的方程：

$$x^2 - (p^2 - 2q)x + q^2 = 0$$

---

**11.** 设两根为非负整数 $m, n$（$m, n \geq 0$）。韦达定理：

$m + n = -a$，$mn = a - 1$。

由第一式 $a = -(m+n)$，代入第二式：

$mn = -(m+n) - 1$

$mn + m + n + 1 = 0$

$(m+1)(n+1) = 0$

因为 $m, n \geq 0$，所以 $m + 1 \geq 1 > 0$，$n + 1 \geq 1 > 0$。矛盾！

因此不存在满足条件的 $a$。

等等——让我们重新检验。$(m+1)(n+1) = 0$ 要求 $m = -1$ 或 $n = -1$，但 $m, n \geq 0$，所以确实不存在满足条件的 $a$。

---

**12.** 代入 $x = 1$：$a(1) + b(1) + c = a + b + c = 0$。✓

所以 $x = 1$ 是一个根。由韦达定理，另一个根为 $x_2 = \frac{c}{a \cdot 1} = \frac{c}{a}$。

又因为 $c = -(a+b)$，所以 $x_2 = \frac{-(a+b)}{a} = -1 - \frac{b}{a}$。

或者更直接：$x_2 = \frac{c}{a}$。$\blacksquare$

---

## §2 方程组

**1.** 从第二个方程：$x = 3y - 1$。代入第一个：$2(3y-1) + y = 5$，$7y = 7$，$y = 1$。$x = 2$。

解：$(x, y) = (2, 1)$。

---

**2.** 第一个方程 $\times 3$：$9x + 12y = 54$。第二个 $\times 2$：$10x + 12y = 56$。

相减：$x = 2$。代入：$6 + 4y = 18$，$y = 3$。

解：$(x, y) = (2, 3)$。

---

**3.**

(a) 第二个方程是第一个的 $2$ 倍：$2(x+2y) = 2 \times 3 = 6$。✓ 两直线重合，**无穷多解**。

(b) $\frac{1}{2} = \frac{2}{4}$ 但 $\frac{3}{7} \neq \frac{3}{7}$…… 实际上 $D = 1 \times 4 - 2 \times 2 = 0$，而 $\frac{c_1}{c_2} = \frac{3}{7} \neq \frac{1}{2}$。两直线平行，**无解**。

(c) $D = 1 \times (-1) - 3 \times 2 = -7 \neq 0$。**唯一解**。

解之：方程 (1) $\times 3$：$3x + 6y = 9$。(1) $\times 3 - $ (2)：$7y = 8$，$y = \frac{8}{7}$。$x = 3 - 2 \times \frac{8}{7} = \frac{5}{7}$。

---

**4.** (1) + (3)：$4x + 3y - 3z = 3$ …… (4)

(1) $\times 2 - $ (2)：$4y - 3z = -1$ …… (5)

(4) $\times 3 + $ (5) $\times 4$：需要更仔细地消元。

换个方法。(1) + (2)：$3x + 0y + 0z = 7$，$x = \frac{7}{3}$。

代入 (1)：$y - z = 2 - \frac{7}{3} = -\frac{1}{3}$，即 $y = z - \frac{1}{3}$。

代入 (3)：$7 + 2(z - \frac{1}{3}) - 2z = 1$，$7 - \frac{2}{3} = 1$，$\frac{19}{3} = 1$。矛盾！

方程组**无解**。

验证：(1) + (2) 得 $3x = 7$；(2) + (3) 得 $5x + y - z = 6$，代入 $x = 7/3$ 得 $y - z = 6 - 35/3 = -17/3$；但从 (1) 得 $y - z = -1/3$。$-17/3 \neq -1/3$，矛盾。确认无解。

---

**5.** $x, y$ 是 $t^2 - 10t + 21 = 0$ 的根。$(t-3)(t-7) = 0$。

$(x, y) = (3, 7)$ 或 $(7, 3)$。

---

**6.** $(x+y)^2 = 25$，$x^2 + 2xy + y^2 = 25$，$xy = \frac{25-13}{2} = 6$。

$x, y$ 是 $t^2 - 5t + 6 = 0$ 的根：$(t-2)(t-3) = 0$。

$(x,y) = (2, 3)$ 或 $(3, 2)$。

---

**7.** 设十位数字为 $x$，个位数字为 $y$。原数 $= 10x + y$。

$\begin{cases} x + y = 9 \\ 10y + x - (10x + y) = 27 \end{cases}$

第二个方程化简：$9y - 9x = 27$，即 $y - x = 3$。

$\begin{cases} x + y = 9 \\ y - x = 3 \end{cases}$

$2y = 12$，$y = 6$，$x = 3$。原数为 **36**。

验证：$3 + 6 = 9$ ✓，$63 - 36 = 27$ ✓。

---

**8.** $x, y, z$ 是 $t^3 - 6t^2 + 11t - 6 = 0$ 的根（由韦达定理的推广）。

$t = 1$：$1 - 6 + 11 - 6 = 0$。✓

$t^3 - 6t^2 + 11t - 6 = (t-1)(t^2 - 5t + 6) = (t-1)(t-2)(t-3)$

$\{x, y, z\} = \{1, 2, 3\}$（共 $6$ 种排列）。

---

**9.** 设 $x + y = s$。由两个方程：$xy = s$ 且 $x/y = s$。

由第二式：$x = sy$。代入 $x + y = s$：$sy + y = s$，$y(s+1) = s$，$y = \frac{s}{s+1}$（要求 $s \neq -1$）。

$x = s - y = s - \frac{s}{s+1} = \frac{s^2}{s+1}$。

代入 $xy = s$：$\frac{s^2}{s+1} \cdot \frac{s}{s+1} = s$，$\frac{s^3}{(s+1)^2} = s$。

若 $s \neq 0$：$\frac{s^2}{(s+1)^2} = 1$，$s^2 = (s+1)^2$，$s = \pm(s+1)$。

$s = s + 1$：$0 = 1$，矛盾。

$s = -(s+1)$：$2s = -1$，$s = -\frac{1}{2}$。

则 $y = \frac{-1/2}{1/2} = -1$，$x = \frac{1/4}{1/2} = \frac{1}{2}$。

验证：$x + y = -\frac{1}{2}$，$xy = -\frac{1}{2}$ ✓，$x/y = \frac{1/2}{-1} = -\frac{1}{2}$ ✓。

若 $s = 0$：$x + y = 0$，$xy = 0$。则 $x = 0, y = 0$。但 $x/y$ 无定义。排除。

**解**：$(x, y) = \left(\frac{1}{2}, -1\right)$。

## §3 高次方程与根式解

**1.** 验证：$8 - 12 + 4 = 0$。✓

$x^3 - 3x^2 + 4 = (x - 2)(x^2 - x - 2) = (x-2)(x-2)(x+1) = (x-2)^2(x+1)$

其余两根：$x = 2$（重根）和 $x = -1$。

---

**2.** $x^3 = 8$。$x = \sqrt[3]{8} \cdot \omega^k$（$k = 0, 1, 2$），其中 $\omega = e^{2\pi i/3}$。

$x_0 = 2$

$x_1 = 2\left(-\frac{1}{2} + \frac{\sqrt{3}}{2}i\right) = -1 + \sqrt{3}\,i$

$x_2 = 2\left(-\frac{1}{2} - \frac{\sqrt{3}}{2}i\right) = -1 - \sqrt{3}\,i$

---

**3.** 令 $x = t + 1$：

$(t+1)^3 - 3(t+1)^2 + 3(t+1) - 9$

$= t^3 + 3t^2 + 3t + 1 - 3t^2 - 6t - 3 + 3t + 3 - 9$

$= t^3 - 8$

压缩形式：$t^3 = 8$，$t = 2$（实数根），$x = 3$。

---

**4.** $p = -3$，$q = -2$。

$\frac{q^2}{4} + \frac{p^3}{27} = 1 - 1 = 0$

$t = \sqrt[3]{1 + 0} + \sqrt[3]{1 - 0} = 1 + 1 = 2$

验证：$8 - 6 - 2 = 0$。✓

（$\Delta_3 = -4(-27) - 27(4) = 108 - 108 = 0$：有重根。实际上 $t^3 - 3t - 2 = (t-2)(t+1)^2$。）

---

**5.** 令 $t = x^3$：$t^2 - 9t + 8 = 0$，$(t-1)(t-8) = 0$。

$t = 1$：$x^3 = 1$，$x = 1$（实数根），以及 $x = \frac{-1 \pm i\sqrt{3}}{2}$（复数根）。

$t = 8$：$x^3 = 8$，$x = 2$（实数根），以及 $x = -1 \pm i\sqrt{3}$（复数根）。

共 $6$ 个根。实数根：$x = 1$ 和 $x = 2$。

---

**6.** $f(x) = x^3 - 3x + 1$。

$f(-2) = -8 + 6 + 1 = -1 < 0$

$f(0) = 1 > 0$

$f(1) = 1 - 3 + 1 = -1 < 0$

$f(2) = 8 - 6 + 1 = 3 > 0$

由介值定理：$(-2, 0)$、$(0, 1)$、$(1, 2)$ 各有一个实根，共三个实根。

Cardano 公式：$p = -3$，$q = 1$。

$\frac{q^2}{4} + \frac{p^3}{27} = \frac{1}{4} - 1 = -\frac{3}{4} < 0$

根号下为负，必须经过复数——这就是不可约情况（casus irreducibilis）。

---

**7.** 观察系数：$1, -4, 6, -4, 1$ 是 $(1-1)^4$ 的二项式系数。

$x^4 - 4x^3 + 6x^2 - 4x + 1 = (x - 1)^4$

唯一的根 $x = 1$（四重根）。
