## 挑战题 1：对称方程组与不等式

设 $x, y > 0$ 且满足

$$\begin{cases} x + y + \frac{1}{x} + \frac{1}{y} = \frac{25}{6} \\[6pt] x^2 + y^2 + \frac{1}{x^2} + \frac{1}{y^2} = \frac{289}{36} \end{cases}$$

求 $x$ 和 $y$。

### 提示

- 令 $s = x + \frac{1}{x}$，$t = y + \frac{1}{y}$。注意 $s^2 = x^2 + 2 + \frac{1}{x^2}$。
- 利用韦达定理将问题转化为一个关于 $s, t$ 的二次方程。

### 解答

令 $s = x + \frac{1}{x}$，$t = y + \frac{1}{y}$。

由 AM-GM 不等式，$s \geq 2$，$t \geq 2$（等号当 $x = 1$ 或 $y = 1$ 时取到）。

从条件得 $s + t = \frac{25}{6}$ 且 $s^2 - 2 + t^2 - 2 = \frac{289}{36}$，即

$$s^2 + t^2 = \frac{289}{36} + 4 = \frac{433}{36}$$

因此 $st = \frac{(s+t)^2 - (s^2 + t^2)}{2} = \frac{625/36 - 433/36}{2} = \frac{192/36}{2} = \frac{192}{72} = \frac{8}{3}$

$s, t$ 是方程 $w^2 - \frac{25}{6}w + \frac{8}{3} = 0$ 的根，即 $6w^2 - 25w + 16 = 0$。

$$w = \frac{25 \pm \sqrt{625 - 384}}{12} = \frac{25 \pm \sqrt{241}}{12}$$

由于 $\sqrt{241} \approx 15.52$，$s \approx \frac{25 + 15.52}{12} \approx 3.38$ 或 $s \approx \frac{25 - 15.52}{12} \approx 0.79$。

但 $s \geq 2$，所以 $s = \frac{25 + \sqrt{241}}{12}$，$t = \frac{25 - \sqrt{241}}{12}$。

但 $t \approx 0.79 < 2$，矛盾！

让我重新检查……这表明此方程组可能需要更精巧的值。让我尝试特殊值。

若 $x = 2, y = 3$：$2 + 3 + \frac{1}{2} + \frac{1}{3} = 5 + \frac{5}{6} = \frac{35}{6}$。不行。

若 $x = 2, y = \frac{1}{3}$：$2 + \frac{1}{3} + \frac{1}{2} + 3 = \frac{35}{6}$。也不行。

若 $x = 3, y = \frac{1}{2}$：$3 + \frac{1}{2} + \frac{1}{3} + 2 = \frac{35}{6}$。

修正条件为 $s + t = \frac{35}{6}$：

$s = 3 + \frac{1}{3} = \frac{10}{3}$，$t = \frac{1}{2} + 2 = \frac{5}{2}$。$s + t = \frac{10}{3} + \frac{5}{2} = \frac{35}{6}$。✓

$s^2 + t^2 = \frac{100}{9} + \frac{25}{4} = \frac{400 + 225}{36} = \frac{625}{36}$

所以正确的条件应该是 $\frac{625}{36} - 4 = \frac{481}{36}$。

**修正后的问题**：将条件改为 $x + y + \frac{1}{x} + \frac{1}{y} = \frac{35}{6}$ 和 $x^2 + y^2 + \frac{1}{x^2} + \frac{1}{y^2} = \frac{481}{36}$。

令 $s = x + \frac{1}{x}$，$t = y + \frac{1}{y}$。

$s + t = \frac{35}{6}$，$s^2 + t^2 = \frac{625}{36}$。

$st = \frac{(35/6)^2 - 625/36}{2} = \frac{1225/36 - 625/36}{2} = \frac{600/36}{2} = \frac{25}{3}$

$s, t$ 是 $w^2 - \frac{35}{6}w + \frac{25}{3} = 0$ 的根，即 $6w^2 - 35w + 50 = 0$。

$w = \frac{35 \pm \sqrt{1225 - 1200}}{12} = \frac{35 \pm 5}{12}$

$w_1 = \frac{40}{12} = \frac{10}{3}$，$w_2 = \frac{30}{12} = \frac{5}{2}$。

从 $x + \frac{1}{x} = \frac{10}{3}$：$3x^2 - 10x + 3 = 0$，$(3x-1)(x-3) = 0$，$x = 3$ 或 $x = \frac{1}{3}$。

从 $y + \frac{1}{y} = \frac{5}{2}$：$2y^2 - 5y + 2 = 0$，$(2y-1)(y-2) = 0$，$y = 2$ 或 $y = \frac{1}{2}$。

**解**：$(x, y) \in \left\{(3, 2), (3, \frac{1}{2}), (\frac{1}{3}, 2), (\frac{1}{3}, \frac{1}{2})\right\}$ 及 $s, t$ 互换后的对应解。

## 挑战题 2：含绝对值的方程

求方程 $|x^2 - 4x + 3| = |x^2 + 2x - 3|$ 的所有实数解。

### 提示

- $|A| = |B|$ 当且仅当 $A = B$ 或 $A = -B$。
- 先因式分解方程中的两个二次表达式。

### 解答

注意 $x^2 - 4x + 3 = (x-1)(x-3)$，$x^2 + 2x - 3 = (x-1)(x+3)$。

**情况 1**：$(x-1)(x-3) = (x-1)(x+3)$

若 $x \neq 1$：$x - 3 = x + 3$，即 $-3 = 3$，矛盾。无解。

若 $x = 1$：$0 = 0$，成立。$x = 1$ 是解。

**情况 2**：$(x-1)(x-3) = -(x-1)(x+3)$

$(x-1)(x-3) + (x-1)(x+3) = 0$

$(x-1)[(x-3) + (x+3)] = 0$

$(x-1)(2x) = 0$

$x = 0$ 或 $x = 1$。

验证 $x = 0$：$|0 - 0 + 3| = 3$，$|0 + 0 - 3| = 3$。✓

**解**：$x = 0$ 或 $x = 1$。

## 挑战题 3：从 Cardano 到 Galois 的思想实验

考虑方程 $x^5 - 6x + 3 = 0$。

**(a)** 证明这个方程有至少一个实根（提示：中间值定理）。

**(b)** 用有理根定理证明这个方程没有有理根。

**(c)** 解释为什么 Abel-Ruffini 定理不能告诉我们**这个特定的**方程是否有根式解——只有 Galois 理论才能给出判定。简要说明 Galois 理论如何做判定（无需严格证明，只需描述思路）。

### 解答大纲

**(a)** 令 $f(x) = x^5 - 6x + 3$。

$f(0) = 3 > 0$

$f(1) = 1 - 6 + 3 = -2 < 0$

由介值定理（连续函数在 $(0, 1)$ 区间内至少有一个零点），方程有至少一个实根。

$f(-2) = -32 + 12 + 3 = -17 < 0$

$f(2) = 32 - 12 + 3 = 23 > 0$

$f(-1) = -1 + 6 + 3 = 8 > 0$

综合：$(-2, -1)$ 有一个根，$(0, 1)$ 有一个根。进一步分析可知方程有三个实根和两个复数根。

**(b)** 由有理根定理，若 $\frac{p}{q}$（最简分数）是方程 $x^5 - 6x + 3 = 0$ 的有理根，则 $p \mid 3$ 且 $q \mid 1$。

候选有理根：$\pm 1, \pm 3$。

$f(1) = -2 \neq 0$，$f(-1) = 8 \neq 0$，$f(3) = 243 - 18 + 3 = 228 \neq 0$，$f(-3) = -243 + 18 + 3 = -222 \neq 0$。

没有有理根。

**(c)** Abel-Ruffini 定理说的是不存在**一个统一的公式**能用根式表达所有五次方程的根。它没有排除某些特定的五次方程可以用根式求解。

Galois 理论的方法：

1. 计算方程 $f(x) = x^5 - 6x + 3$ 在 $\mathbb{Q}$ 上的**分裂域**（splitting field）$K$。
2. 确定 **Galois 群** $\text{Gal}(K/\mathbb{Q})$。
3. 判断这个群是否是**可解群**（solvable group）。

若 Galois 群是可解群，方程有根式解；否则没有。

对于 $x^5 - 6x + 3$，可以证明其 Galois 群为 $S_5$（对称群），而 $S_5$ 不是可解群，因此这个特定的方程**没有**根式解。

判定 Galois 群为 $S_5$ 的思路：
- $f$ 在 $\mathbb{Q}$ 上不可约（可由 Eisenstein 判别法在适当代换后证明，或直接分析）。
- $f$ 的判别式不是完全平方，所以 Galois 群不含在 $A_5$ 中。
- $f$ 恰好有三个实根和一对复数共轭根，这意味着 Galois 群包含一个 $2$ 阶元素（复共轭），同时不可约性保证群是传递的。
- 结合这些信息可以推出 $\text{Gal}(K/\mathbb{Q}) \cong S_5$。
