# 第三部分：代数（Algebra）

## 本部分概览

代数是数学的核心语言。如果说第一部分（基础）建立了推理的规则，第二部分（数系）认识了数的世界，那么第三部分要做的就是**用符号和结构的力量去解决问题**。

代数的精髓在于**抽象**：用字母代替具体的数，用等式和不等式表达约束，用多项式刻画关系，用结构揭示本质。从最具体的一元一次方程到最抽象的群论初步，本部分讲述的是一段从计算走向结构的旅程。

这段旅程的叙事线如下：

1. **方程**——数学最古老的问题之一："什么数满足这个条件？"
2. **不等式**——从"精确相等"到"范围估计"，从等式约束到不等式约束
3. **多项式**——方程的主角，代数的核心对象，连接代数与分析的桥梁
4. **复数代数**——在复数域中重新理解代数，打开新的视野
5. **抽象代数初步**——从具体运算中提炼出"群"的概念，走向现代代数

本部分包含五章：

| 章 | 主题 | 内容 |
|----|------|------|
| [第 1 章：方程](ch01-equations/README.md) | 方程（equations） | 一元一次与一元二次方程、方程组、高次方程与根式解 |
| [第 2 章：不等式](ch02-inequalities/README.md) | 不等式（inequalities） | 基本不等式、经典不等式（AM-GM、Cauchy-Schwarz 等） |
| [第 3 章：多项式](ch03-polynomials/README.md) | 多项式（polynomials） | 多项式运算、因式分解、多项式的根、代数基本定理 |
| 第 4 章：复数代数 | 复数代数（complex algebra） | 复数运算、复平面、极坐标形式、棣莫弗定理、单位根 |
| 第 5 章：抽象代数初步 | 抽象代数（abstract algebra intro） | 群的定义与例子、子群、同态、环与域的初步 |

这五章的关系：前三章从具体到一般，建立代数的基本工具箱——方程求解、不等式估计、多项式理论。第四章在复数域中重新审视这些工具，获得更完整的图景（例如代数基本定理的意义）。第五章是一次质的飞跃——从研究具体的数和方程，转向研究运算本身的结构，为后续的线性代数（Part 9）和更深入的数学学习铺路。

## 学习路线

```
Ch01 方程 ──→ Ch02 不等式 ──→ Ch03 多项式
                                    ↓
                              Ch04 复数代数
                                    ↓
                              Ch05 抽象代数初步
```

- **第 1 章（方程）** 是起点，建立基本的方程求解技能和符号体系。
- **第 2 章（不等式）** 与第 1 章平行但互补——方程求"精确值"，不等式求"范围"。
- **第 3 章（多项式）** 综合前两章，系统研究多项式作为代数对象的性质。
- **第 4 章（复数代数）** 依赖第 3 章（多项式的根需要复数域）和 Part 2 Ch01 §4（复数引入）。
- **第 5 章（抽象代数初步）** 依赖前四章积累的代数直觉，是一次范式转换。

## 前置知识

**第一部分（数学基础）** 和 **第二部分（数系与数论）**。具体而言：

- **集合论**（Part 1 Ch02）：集合运算、关系、函数——代数结构的底层语言。
- **逻辑与证明方法**（Part 1 Ch01, Ch03）：命题逻辑、直接证明、反证法、数学归纳法——证明不等式和代数恒等式的基本工具。
- **数系**（Part 2 Ch01）：$\mathbb{N}, \mathbb{Z}, \mathbb{Q}, \mathbb{R}, \mathbb{C}$ 的基本性质——代数运算的"舞台"。
- **初等数论**（Part 2 Ch03）：整除性、素数分解——有理根定理等工具的基础。

## 本部分完成后你将能够

- **熟练求解各类方程**：从一元一次到一元高次，从单个方程到方程组，掌握系统的求解策略

- **在复数域中自如运算**：极坐标表示、棣莫弗定理、单位根
- **初步理解代数结构**：群的概念和基本性质，感受从具体到抽象的思维跃迁
- **为后续部分做好准备**：本部分的内容是函数论（Part 4）、几何（Part 5）、分析预备（Part 6）和线性代数（Part 9）的代数基础

## 本部分的主题：代数工具与结构

贯穿本部分的一条主线是**从工具到结构**的认识论跃迁：

1. **工具阶段**（Ch01–Ch03）：方程、不等式、多项式是解决具体问题的"工具"。我们学会使用它们。
2. **统一阶段**（Ch04）：在复数域中，这些工具获得更优雅、更统一的表述。代数基本定理是这一统一的巅峰。
3. **结构阶段**（Ch05）：我们从工具中抽象出"结构"——群、环、域。这不仅是更高层次的理解，也是通往现代数学的大门。

这条从具体到抽象的路径，正是代数学数百年发展的缩影。
