## 1. Gauss 与正十七边形——尺规作图的代数之魂

### 一个少年的惊人发现

1796 年 3 月 30 日，年仅 18 岁的 Carl Friedrich Gauss 做出了一个令世人震惊的发现：**正十七边形可以用尺规作图**。

这个问题已经困扰数学家两千年。古希腊人知道正 $3$、$4$、$5$、$6$、$8$、$10$、$12$、$15$、$16$ 边形可以用尺规作图，但正七边形和正十一边形不行。正十七边形是素数，看起来完全没有希望。

### 关键联系：单位根

Gauss 的突破在于看到**几何问题其实是代数问题**。

作正 $n$ 边形等价于将单位圆 $n$ 等分——即找到 $n$ 次单位根 $\omega = \text{cis}\frac{2\pi}{n}$。更精确地说，需要用尺规作出 $\cos\frac{2\pi}{n}$ 的值。

**尺规作图能做什么？** 从已知长度出发，只能进行加法、减法、乘法、除法和开平方根。换言之，尺规可作长度恰好是"从有理数出发，通过四则运算和开平方根可以得到的数"。

### Gauss 的定理

> **Gauss 定理**（1796）
>
> 正 $n$ 边形可用尺规作图当且仅当 $n$ 的奇素数因子都是不同的**费马素数**（Fermat prime），即形如 $F_k = 2^{2^k} + 1$ 的素数。

已知的费马素数只有五个：$F_0 = 3$，$F_1 = 5$，$F_2 = 17$，$F_3 = 257$，$F_4 = 65537$。

$17 = F_2$ 是费马素数，所以正 $17$ 边形可以尺规作图！

### 为什么是 $17$？

$\cos\frac{2\pi}{17}$ 可以用嵌套平方根表示：

$$\cos\frac{2\pi}{17} = \frac{-1 + \sqrt{17} + \sqrt{34 - 2\sqrt{17}} + 2\sqrt{17 + 3\sqrt{17} - \sqrt{34 - 2\sqrt{17}} - 2\sqrt{34 + 2\sqrt{17}}}}{16}$$

这个表达式虽然复杂，但只用了四则运算和平方根——正是尺规可作的运算。其背后的代数机制是：$z^{17} = 1$ 的本原根满足一个 $16$ 次方程（分圆方程），而 $16 = 2^4$，可以逐层分解为二次方程——每一步只需要开平方根。

Gauss 对这一发现极为自豪，据说他决定终身从事数学而不是语言学，正是因为这个突破。他甚至要求在自己的墓碑上刻一个正十七边形（石匠认为太难了，刻了一个十七角星代替）。

## 2. Mandelbrot 集——复数迭代的惊人之美

### 一个简单的迭代

取一个复数 $c$，定义序列：

$$z_0 = 0, \quad z_{n+1} = z_n^2 + c$$

**Mandelbrot 集** $\mathcal{M}$ 是使得序列 $\{z_n\}$ **有界**（不趋向无穷）的所有 $c$ 值的集合：

$$\mathcal{M} = \{c \in \mathbb{C} : \{z_n\} \text{ 有界}\}$$

### 例子

- $c = 0$：$z_n = 0$ 对所有 $n$。有界，$0 \in \mathcal{M}$。
- $c = 1$：$z_0 = 0, z_1 = 1, z_2 = 2, z_3 = 5, z_4 = 26, \ldots$。无界，$1 \notin \mathcal{M}$。
- $c = -1$：$z_0 = 0, z_1 = -1, z_2 = 0, z_3 = -1, \ldots$。有界（周期 $2$），$-1 \in \mathcal{M}$。
- $c = i$：$z_0 = 0, z_1 = i, z_2 = -1 + i, z_3 = -i, z_4 = -1 + i, \ldots$。有界（周期 $2$），$i \in \mathcal{M}$。

### 惊人的复杂性

Mandelbrot 集的边界是一个**分形**（fractal）——无论你放大多少倍，它的边界都展现出无穷的细节和自相似性。这个集合的形状——一个心形主体加上无数个"芽"——是 20 世纪数学中最标志性的图像之一。

一些令人惊叹的事实：

- Mandelbrot 集是**连通的**（一块，没有被分开的部分）——这是 1982 年 Douady 和 Hubbard 证明的深刻定理
- 其面积大约为 $1.50659\ldots$，至今无已知的精确公式
- 它的边界的 Hausdorff 维数为 $2$——与面积相同！（这意味着边界"几乎填满"了平面的一部分）
- 放大后可以看到"小 Mandelbrot 集"——它包含自身的（变形）副本

Mandelbrot 集只用了复数的加法和乘法——这两个最基本的运算——就产生了如此惊人的复杂性。这深刻地说明了复数运算中蕴含的丰富结构。

## 3. 四元数——超越复数的尝试

### Hamilton 的执念

William Rowan Hamilton 是 19 世纪最伟大的数学家之一。他完全理解了复数的几何意义（二维旋转），并花了十年时间试图构建一个"三维复数"——一种能描述三维旋转的数系。

他失败了。

原因深刻而优美：**三维没有类似复数的除法代数**。这可以严格证明（Frobenius 定理, 1877）。

### 1843 年 10 月 16 日

在经历了漫长的挫折后，Hamilton 终于意识到应该跳到**四维**。1843 年 10 月 16 日，在都柏林的 Brougham 桥上散步时，他灵光一闪：

$$i^2 = j^2 = k^2 = ijk = -1$$

这就是**四元数**（quaternions）$\mathbb{H}$。每个四元数形如

$$q = a + bi + cj + dk, \quad a, b, c, d \in \mathbb{R}$$

Hamilton 兴奋到在桥上刻下了这些方程（这些刻痕至今仍在）。

### 四元数的代价：交换律

四元数乘法不满足交换律：$ij = k$，但 $ji = -k$。

$$ij = k, \quad jk = i, \quad ki = j$$
$$ji = -k, \quad kj = -i, \quad ik = -j$$

这是数系扩展史上最深刻的"代价"。回顾：

| 数系 | 维度 | 失去的性质 |
|------|------|-----------|
| $\mathbb{R}$ | $1$ | — |
| $\mathbb{C}$ | $2$ | 全序性 |
| $\mathbb{H}$ | $4$ | 交换律 |
| $\mathbb{O}$（八元数） | $8$ | 交换律 + 结合律 |

Hurwitz 定理（1898）证明：只有 $\mathbb{R}$、$\mathbb{C}$、$\mathbb{H}$、$\mathbb{O}$ 是实数上的赋范可除代数。维度必须是 $1, 2, 4, 8$——没有其他选择。

### 四元数在现代的应用

虽然四元数在 19 世纪被向量分析取代了一般性用途，但它们在现代计算机科学中焕发了新生：

- **3D 图形和游戏引擎**：四元数是表示三维旋转最高效、最稳定的方法，避免了"万向锁"（gimbal lock）问题
- **航空航天**：飞行器姿态控制使用四元数
- **机器人学**：关节旋转的表示和插值

Hamilton 可能没有想到，他在桥上刻下的方程会在 170 年后驱动着每一个 3D 游戏。

## 4. 延伸思考

- $\mathbb{C}$ 是代数封闭的（代数基本定理），但 $\mathbb{H}$ 不是——四元数系数的多项式可能没有四元数根，或者根的个数可能不等于次数。代数封闭性在非交换世界中变得微妙得多。

- 复数与物理的关系异常深刻。量子力学的基本框架——Hilbert 空间、概率幅——本质上是建立在 $\mathbb{C}$ 上的。2022 年的实验已经证明，**量子力学不能仅用实数来表述**——复数在物理中不仅是方便，而是**必要**的。

- Euler 公式 $e^{i\theta} = \cos\theta + i\sin\theta$ 将指数函数、三角函数和虚数单位统一在一个等式中。当 $\theta = \pi$ 时，得到被称为"数学中最美的公式"的 $e^{i\pi} + 1 = 0$。这个公式需要 Part 6（分析）中 $e^x$ 和三角函数的幂级数定义才能严格证明。
