# 第 4 章：复数的代数运算（Complex Algebra）

## 章概览

在 Part 2 第 1 章 §4 中，我们引入了虚数单位 $i$（满足 $i^2 = -1$）和复数 $z = a + bi$ 的基本概念。本章将系统深入地发展复数的代数运算和几何理论。

复数不仅是"填补 $x^2 + 1 = 0$ 的缺口"的工具——它们拥有丰富的几何内涵。每一个复数对应复平面上的一个点，加法对应向量平移，乘法对应旋转与缩放。当我们用极坐标形式重新理解复数时，De Moivre 定理将三角恒等式与代数运算优雅地统一起来，单位根将代数方程与正多边形的几何联系在一起。

## 学习成果

本章完成后你将能够：

- **熟练进行复数的四则运算**：特别是除法（乘以共轭）
- **理解共轭和模的性质**：$z\bar{z} = |z|^2$、共轭对加法和乘法的分配
- **在复平面中可视化复数**：把复数当作点或向量
- **理解复数运算的几何意义**：加法 = 平移，乘法 = 旋转 + 缩放
- **掌握极坐标表示**：$z = r(\cos\theta + i\sin\theta)$
- **运用 De Moivre 定理**：计算复数的高次幂、推导三角恒等式
- **求解 $z^n = w$**：理解 $n$ 次方根的 $n$ 个值及其在单位圆上的分布
