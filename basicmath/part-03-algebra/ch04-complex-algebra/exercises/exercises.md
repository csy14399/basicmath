# 第 4 章 复数的代数运算 — 练习题

## §1 复数的运算（Complex Number Operations）

1. ★☆☆ 计算 $(5 + 3i) + (2 - 7i)$。

2. ★☆☆ 计算 $(3 + 4i)(2 - i)$。

3. ★☆☆ 计算 $\displaystyle\frac{1 + i}{1 - i}$。

4. ★☆☆ 求 $z = 2 - 3i$ 的共轭 $\bar{z}$、模 $|z|$，以及 $z\bar{z}$。

5. ★☆☆ 计算 $i^{2025}$。

6. ★★☆ 设 $z = 1 + 2i$，计算 $z^2$，$z^3$，$z\bar{z}$。

7. ★★☆ 计算 $\displaystyle\frac{3 - 4i}{2 + i} + \frac{3 + 4i}{2 - i}$。

8. ★★☆ 设 $|z| = 3$，求 $|z + 4 + 3i|$ 的取值范围。

9. ★★☆ 证明：对任意 $z \in \mathbb{C}$，$z + \bar{z}$ 和 $z\bar{z}$ 都是实数。

10. ★★☆ 在复平面上描述满足 $|z - 2 + i| = 3$ 的点的集合。

11. ★★☆ 设 $z_1 = 2 + i$，$z_2 = 1 - 3i$。验证 $\overline{z_1 z_2} = \bar{z}_1 \bar{z}_2$。

12. ★★☆ 求满足 $z^2 = 3 + 4i$ 的复数 $z$（提示：设 $z = a + bi$，比较实部和虚部）。

13. ★★★ 证明：若 $|z| = 1$，则 $\displaystyle\frac{z - 1}{z + 1}$ 是纯虚数或零（$z \neq -1$）。

14. ★★★ 设 $z_1, z_2 \in \mathbb{C}$，证明 $|z_1 + z_2|^2 + |z_1 - z_2|^2 = 2(|z_1|^2 + |z_2|^2)$（平行四边形恒等式）。

## §2 复数的极坐标形式（Polar Form）

1. ★☆☆ 将 $z = 1 - i$ 化为极坐标形式。

2. ★☆☆ 将 $z = -3$ 化为极坐标形式。

3. ★☆☆ 将 $z = 4\,\text{cis}\,(\pi/3)$ 化为直角坐标形式。

4. ★☆☆ 用极坐标形式计算 $(1+i)(1-i)$。

5. ★★☆ 用 De Moivre 定理计算 $(\sqrt{3} + i)^6$。

6. ★★☆ 求 $z^4 = 1$ 的所有解，并在复平面上画出。

7. ★★☆ 求 $z^3 = -27$ 的所有解。

8. ★★☆ 求 $z^4 = -8 + 8\sqrt{3}\,i$ 的所有解。

9. ★★☆ 用 De Moivre 定理推导 $\cos(4\theta)$ 的展开式（用 $\cos\theta$ 表示）。

10. ★★☆ 证明 $(\text{cis}\,\alpha)(\text{cis}\,\beta) = \text{cis}\,(\alpha + \beta)$，并由此给出三角函数和角公式的另一种证明。

11. ★★★ 设 $\omega = \text{cis}\,\frac{2\pi}{5}$。证明 $\omega^4 + \omega^3 + \omega^2 + \omega + 1 = 0$，并求 $\cos\frac{4\pi}{5}$ 的精确值。

12. ★★★ 设 $z^n = 1$（$z \neq 1$）。证明 $(1 - z)(1 - z^2)\cdots(1 - z^{n-1}) = n$。

（提示：考虑 $z^n - 1$ 的因式分解 $(z-1)(z^{n-1} + \cdots + 1)$，令 $z = 1$。）

13. ★★★ 求 $z^6 + z^3 + 1 = 0$ 的所有解。
