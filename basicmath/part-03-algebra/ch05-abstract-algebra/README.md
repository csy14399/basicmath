# 第 5 章：抽象代数初步（Introduction to Abstract Algebra）[Bridge]

## 章概览

前四章中，我们在具体的数系和多项式上进行了大量的代数运算。现在我们退后一步，问一个更深的问题：**这些运算有什么共同结构？**

整数的加法、实数的乘法、模运算、多项式的加法、复数的旋转、几何图形的对称变换——这些看似不同的运算，背后却共享着相同的代数规律。**群论**（group theory）就是从这些具体例子中抽象出来的统一框架。

本章是一座**桥梁**（Bridge）——连接本书中的具体计算与更高等的代数学。我们将引入群的定义和最基本的定理，为后续 Part 5（变换几何）中的变换群和更远的数学学习打下基础。

> **[Bridge] 标记说明**：本章内容超出传统初等数学的范畴，为有志于深入学习数学的读者提供一个通向抽象代数的入口。初次阅读时可以跳过本章的部分证明，优先理解动机和例子。

## 学习成果

本章完成后你将能够：

- **识别对称性中的代数结构**：理解为什么对称变换"自然地"满足群公理
- **陈述群的定义**：封闭性、结合律、单位元、逆元
- **验证具体结构是否构成群**：$(\mathbb{Z}, +)$、$(\mathbb{Z}/n\mathbb{Z}, +)$、$S_3$、$(\mathbb{R}^*, \times)$ 等
- **理解子群的概念**：掌握子群判定法
- **陈述 Lagrange 定理**：子群的阶整除群的阶
- **看到群论与几何的联系**：几何变换在复合下构成群
