# 第 2 章：不等式（Inequalities）

## 章概览

方程问的是"**哪个**值使等式成立？"不等式问的是"**哪些**值使关系成立？"——从一个点变成一个区间，从精确解变成范围估计。

不等式不仅是代数的基本工具，更是分析学的命脉。几乎所有关于"逼近""估计""有界"的数学论证，最终都归结为某种不等式。本章从最基本的不等式性质出发，经过线性不等式、二次不等式、绝对值不等式，一路走到 AM-GM、Cauchy-Schwarz 等经典不等式——这些是数学分析中反复使用的核心工具。

- **系统求解线性和二次不等式**：在数轴上表示解集
- **熟练运用绝对值不等式**：$|x - a| < r$ 与区间的转换
- **掌握三角不等式**：$|a + b| \leq |a| + |b|$ 及其变体
- **证明和应用 AM-GM 不等式**：用于优化问题和证明其他不等式
- **证明和应用 Cauchy-Schwarz 不等式**：理解其几何含义（向量夹角）
