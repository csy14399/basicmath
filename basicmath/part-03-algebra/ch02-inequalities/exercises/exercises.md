# 第 2 章 不等式 — 练习题

## §1 基本不等式（Basic Inequalities）

1. ★☆☆ 解不等式 $3x + 7 > 2x - 5$。

2. ★☆☆ 解不等式 $-2x + 4 \leq 3x + 9$。

3. ★☆☆ 解联立不等式 $\begin{cases} x - 1 > 0 \\ 3x + 2 < 14 \end{cases}$

4. ★☆☆ 解不等式 $x^2 - 3x - 10 > 0$。

5. ★☆☆ 解不等式 $2x^2 + 5x - 3 \leq 0$。

6. ★☆☆ 解不等式 $|x - 4| < 3$。

7. ★☆☆ 解不等式 $|2x + 1| \geq 7$。

8. ★★☆ 解不等式 $x^2 - 2x + 3 > 0$。

9. ★★☆ 解不等式 $\frac{x - 1}{x + 2} > 0$。

10. ★★☆ 证明三角不等式的推论：对任意实数 $a, b, c$，$|a - c| \leq |a - b| + |b - c|$。

11. ★★☆ 已知 $|x - 1| < \frac{1}{2}$，估计 $|2x^2 - 2|$ 的上界。

12. ★★★ 解不等式 $|x - 1| + |x + 2| > 5$。

13. ★★★ 设 $a, b, c$ 是三角形的三条边长。证明 $a^2 + b^2 + c^2 < 2(ab + bc + ca)$（提示：三角形不等式 $a < b + c$ 等）。

## §2 经典不等式（Classical Inequalities）

1. ★☆☆ 设 $x > 0$，用 AM-GM 不等式求 $x + \frac{4}{x}$ 的最小值。

2. ★☆☆ 设 $a, b > 0$ 且 $a + b = 4$。求 $ab$ 的最大值。

3. ★☆☆ 验证 Cauchy-Schwarz 不等式对 $a_1 = 1, a_2 = 2, b_1 = 3, b_2 = 4$ 成立。

4. ★★☆ 设 $a, b > 0$。证明 $\frac{a + b}{2} \geq \frac{2}{\frac{1}{a} + \frac{1}{b}}$（即算术平均 $\geq$ 调和平均）。

5. ★★☆ 设 $x, y, z > 0$ 且 $xyz = 8$。求 $x + y + z$ 的最小值。

6. ★★☆ 用 Cauchy-Schwarz 不等式证明：$(1 + 2 + \cdots + n)^2 \leq n(1^2 + 2^2 + \cdots + n^2)$。

7. ★★☆ 设 $a, b, c > 0$。证明 $(a + b)(b + c)(c + a) \geq 8abc$。

8. ★★☆ 设 $x_1, x_2, \ldots, x_n > 0$ 且 $\sum x_i = S$。证明 $\sum \frac{1}{x_i} \geq \frac{n^2}{S}$。

9. ★★★ 设 $a, b, c$ 是三角形的三条边长。证明

   $$\frac{a}{b + c - a} + \frac{b}{a + c - b} + \frac{c}{a + b - c} \geq 3$$

10. ★★★ 证明**幂平均不等式**的特殊情况：对 $a, b > 0$，

    $$\sqrt{\frac{a^2 + b^2}{2}} \geq \frac{a + b}{2} \geq \sqrt{ab} \geq \frac{2ab}{a + b}$$

    即 QM $\geq$ AM $\geq$ GM $\geq$ HM。
