# 第 3 章 多项式 — 挑战题（Challenge Problems）

以下挑战题综合运用多项式理论，难度超出常规练习。

---

## 挑战题 1：Newton 恒等式

设 $r_1, r_2, \ldots, r_n$ 是首一 $n$ 次多项式 $f(x) = x^n + c_{n-1}x^{n-1} + \cdots + c_0$ 的根。定义**幂和**（power sums）：

$$p_k = r_1^k + r_2^k + \cdots + r_n^k$$

以及初等对称多项式 $e_1, e_2, \ldots, e_n$（由韦达定理，$e_j = (-1)^{j+1} c_{n-j}$）。

**(a)** 对 $n = 3$ 的情况，验证 **Newton 恒等式**：

$$p_1 = e_1$$
$$p_2 = e_1 p_1 - 2e_2$$
$$p_3 = e_1 p_2 - e_2 p_1 + 3e_3$$

**(b)** 已知 $r_1 + r_2 + r_3 = 5$，$r_1^2 + r_2^2 + r_3^2 = 15$，$r_1^3 + r_2^3 + r_3^3 = 35$。求 $r_1 r_2 r_3$。

### 解答

**(a)** 设 $e_1 = r_1 + r_2 + r_3$，$e_2 = r_1 r_2 + r_1 r_3 + r_2 r_3$，$e_3 = r_1 r_2 r_3$。

$p_1 = r_1 + r_2 + r_3 = e_1$。✓

$p_2 = r_1^2 + r_2^2 + r_3^2 = (r_1 + r_2 + r_3)^2 - 2(r_1 r_2 + r_1 r_3 + r_2 r_3) = e_1^2 - 2e_2 = e_1 p_1 - 2e_2$。✓

$p_3 = r_1^3 + r_2^3 + r_3^3$。利用恒等式 $a^3 + b^3 + c^3 - 3abc = (a + b + c)(a^2 + b^2 + c^2 - ab - ac - bc)$：

$p_3 = e_1(p_2 - e_2) + 3e_3 = e_1 p_2 - e_1 e_2 + 3e_3$。

但 Newton 恒等式说 $p_3 = e_1 p_2 - e_2 p_1 + 3e_3$。由于 $p_1 = e_1$，这是一致的。✓

**(b)** 由 Newton 恒等式：

$p_1 = e_1 = 5$。

$p_2 = e_1 p_1 - 2e_2 = 15$，即 $25 - 2e_2 = 15$，$e_2 = 5$。

$p_3 = e_1 p_2 - e_2 p_1 + 3e_3 = 35$，即 $75 - 25 + 3e_3 = 35$，$3e_3 = -15$，$e_3 = -5$。

$r_1 r_2 r_3 = e_3 = -5$。

三个根是 $x^3 - 5x^2 + 5x + 5 = 0$ 的根。

## 挑战题 2：多项式插值

**Lagrange 插值公式**：给定 $n + 1$ 个不同的点 $(x_0, y_0), (x_1, y_1), \ldots, (x_n, y_n)$，存在唯一的次数不超过 $n$ 的多项式 $P(x)$ 使得 $P(x_i) = y_i$（$i = 0, 1, \ldots, n$）。

**(a)** 写出 Lagrange 插值公式的显式表达。

**(b)** 求经过点 $(0, 1)$、$(1, 3)$、$(2, 7)$ 的二次多项式。

**(c)** 证明唯一性：若 $P$ 和 $Q$ 都是次数不超过 $n$ 的多项式且在 $n + 1$ 个不同点上取相同的值，则 $P = Q$。

### 解答

**(a)** Lagrange 插值公式：

$$P(x) = \sum_{i=0}^n y_i \prod_{\substack{j=0 \\ j \neq i}}^n \frac{x - x_j}{x_i - x_j}$$

每个 $L_i(x) = \prod_{j \neq i} \frac{x - x_j}{x_i - x_j}$ 满足 $L_i(x_i) = 1$ 且 $L_i(x_j) = 0$（$j \neq i$），因此 $P(x_i) = y_i$。

**(b)** $x_0 = 0, x_1 = 1, x_2 = 2$，$y_0 = 1, y_1 = 3, y_2 = 7$。

$$P(x) = 1 \cdot \frac{(x-1)(x-2)}{(0-1)(0-2)} + 3 \cdot \frac{(x-0)(x-2)}{(1-0)(1-2)} + 7 \cdot \frac{(x-0)(x-1)}{(2-0)(2-1)}$$

$$= \frac{(x-1)(x-2)}{2} - 3 \cdot \frac{x(x-2)}{1} + \frac{7x(x-1)}{2}$$

$$= \frac{(x-1)(x-2) + 7x(x-1)}{2} - 3x(x-2)$$

$$= \frac{(x-1)(x-2+7x)}{2} - 3x(x-2)$$

$$= \frac{(x-1)(8x-2)}{2} - 3x(x-2)$$

$$= (x-1)(4x-1) - 3x(x-2)$$

$$= 4x^2 - 5x + 1 - 3x^2 + 6x = x^2 + x + 1$$

验证：$P(0) = 1$ ✓，$P(1) = 3$ ✓，$P(2) = 7$ ✓。

**(c)** 设 $R(x) = P(x) - Q(x)$。则 $\deg R \leq n$ 且 $R(x_i) = 0$ 对 $i = 0, 1, \ldots, n$。

$R$ 有 $n + 1$ 个不同的根，但 $\deg R \leq n$。由推论 2（$n$ 次多项式至多 $n$ 个根），$R$ 必须是零多项式。

因此 $P = Q$。$\blacksquare$

## 挑战题 3：Hilbert 第 17 问题——预览

**Hilbert 第 17 问题**（1900 年提出）：设 $f(x_1, \ldots, x_n)$ 是一个多元多项式，且对所有实数值 $x_i$ 都有 $f(x_1, \ldots, x_n) \geq 0$。$f$ 能否写成有理函数的平方和？

**(a)** 验证：$f(x) = x^2 + 2x + 1 = (x + 1)^2$ 是非负的，且确实是多项式的平方。

**(b)** 验证：$f(x, y) = x^2 + y^2$ 非负，且可以写成多项式的平方和：$x^2 + y^2 = x^2 + y^2$（平凡地就是）。

**(c)** Motzkin 多项式 $M(x, y) = x^4 y^2 + x^2 y^4 - 3x^2 y^2 + 1$ 对所有实数 $(x, y)$ 非负。验证这一点（提示：用 AM-GM）。

**(d)** Motzkin（1967）证明 $M(x, y)$ **不能**写成多项式的平方和。但 Artin（1927）的一般定理保证它可以写成**有理函数**的平方和。简要说明为什么"多项式平方和"和"有理函数平方和"之间的差别令人惊讶。

### 解答大纲

**(c)** 用 AM-GM 不等式。令 $a = x^4 y^2$，$b = x^2 y^4$，$c = 1$。

由 AM-GM（三元）：$\frac{a + b + c}{3} \geq \sqrt[3]{abc} = \sqrt[3]{x^6 y^6} = x^2 y^2$。

所以 $a + b + c \geq 3x^2 y^2$，即 $x^4 y^2 + x^2 y^4 + 1 \geq 3x^2 y^2$，即 $M(x, y) \geq 0$。

等号当 $a = b = c$，即 $x^4 y^2 = x^2 y^4 = 1$，解为 $x^2 = y^2 = 1$，即 $(x, y) = (\pm 1, \pm 1)$。

验证：$M(1, 1) = 1 + 1 - 3 + 1 = 0$。✓

**(d)** 这个差别令人惊讶，因为直觉上，如果一个多项式处处非负，人们期望能用"多项式的平方和"来解释其非负性——这是最自然的"证书"。Motzkin 多项式表明这种直觉在多元情况下是错误的。然而，Artin 的定理表明，只要允许分母（有理函数），平方和表示总是可能的。这个定理的证明用到了模型论（数理逻辑的一个分支），展现了逻辑与代数之间的深刻联系。
