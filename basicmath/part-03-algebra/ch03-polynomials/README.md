# 第 3 章：多项式（Polynomials）

## 章概览

多项式是代数的核心对象。从最简单的一次式 $ax + b$ 到任意次数的 $a_n x^n + \cdots + a_1 x + a_0$，多项式既是方程的"主角"（方程就是多项式等于零），也是函数逼近的"积木"（Taylor 多项式），还是代数结构的原型（多项式环）。

本章系统研究多项式作为代数对象的基本理论。第一节建立多项式运算的基本功——加法、乘法、长除法、综合除法——并引出余数定理和因式分解；第二节探索多项式的根——代数基本定理、有理根定理、韦达定理的一般形式——将本章的内容与 Ch01（方程）和 Ch05（抽象代数初步）紧密连接。

## 学习成果

本章完成后你将能够：

- **进行多项式的四则运算**：加法、乘法、长除法，理解余式的含义
- **熟练运用余数定理和因式定理**：快速判断一个数是否是多项式的根
- **掌握多种因式分解技巧**：提公因式、分组、特殊形式、换元
- **理解代数基本定理的含义**：$n$ 次多项式有 $n$ 个根（含重数，在 $\mathbb{C}$ 中）
- **运用有理根定理**：系统搜索整系数多项式的有理根
- **运用韦达定理的一般形式**：根与系数之间的对称关系
