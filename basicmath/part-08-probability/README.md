# 第八部分：概率论（Probability）

## 本部分概览

概率论（probability theory）是研究**随机现象的数学规律**的学科。它的核心问题是：**不确定的事情，能否用数学精确刻画？**——答案是肯定的，而且由此诞生的理论深刻、优美且极具实用价值。

如果说前面的部分建立了逻辑框架（Part 1）、认识了数的世界（Part 2）、掌握了代数工具（Part 3）、研究了函数家族（Part 4）、探索了几何空间（Part 5）、逼近了无穷极限（Part 6）、学会了计数的艺术（Part 7），那么第八部分将带你进入一个全新的维度——**不确定性的量化**。这里没有确定的等号，取而代之的是概率、期望和分布——用数学的精确语言描述"可能性"。

本部分的核心主题是：**量化不确定性（Quantifying Uncertainty）。**

本部分包含五章：

| 章 | 主题 | 内容 |
|----|------|------|
| [第 1 章：概率公理](ch01-axioms/README.md) | 概率公理（probability axioms） | 样本空间、事件、Kolmogorov 公理、古典概型、频率解释 |

这五章的关系：第一章建立概率的数学基础——公理化体系确保概率有严格的定义。第二章引入"已知部分信息"下的概率更新——Bayes 定理是概率论最强大的推理工具。第三章将随机性封装为"随机变量"——从事件的概率过渡到数值的分布。第四章提取分布的核心特征——期望（均值）和方差（离散程度）。第五章揭示大量随机试验的宏观规律——随机中涌现出确定性。

## 本部分的主题：量化不确定性

贯穿本部分的核心思想是**用数学精确刻画"不确定"**：

1. **概率公理**（Ch01）：给不确定性一个数值——概率是满足三条公理的函数，从而将"可能性"变成可以计算的量。
2. **条件概率**（Ch02）：信息改变概率——已知部分信息后，我们对事件的判断如何更新？Bayes 定理将"因→果"翻转为"果→因"。
3. **随机变量**（Ch03）：将随机结果数值化——随机变量把"抛硬币正面"变成"$X = 1$"，分布把所有可能的值及其概率打包在一起。
4. **期望与方差**（Ch04）：用两个数字概括一个分布——期望是"平均值"，方差是"离散程度"，两者足以刻画分布的核心特征。
5. **大数定律**（Ch05）：随机中涌现确定性——单次试验不可预测，但大量重复趋于稳定。这是概率论最深刻的结论之一。

这五个主题展示了概率论的一个核心哲学：**个体的随机性中蕴含着整体的规律性**。
