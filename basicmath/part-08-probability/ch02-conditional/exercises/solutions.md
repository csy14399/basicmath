# 第 2 章 条件概率 — 练习题解答

## §1 条件概率与乘法规则

**1.** $P(A \mid B) = 0.24/0.4 = 0.6$。$P(B \mid A) = 0.24/0.6 = 0.4$。

---

**2.** $B = \{(i,j): i+j=8\} = \{(2,6),(3,5),(4,4),(5,3),(6,2)\}$，$|B| = 5$。

$A \cap B = \{(3,5)\}$，$|A \cap B| = 1$。

$P(A \mid B) = 1/5$。

---

**3.** $P(\text{黑桃第一}) = 13/52$。$P(\text{红心第二} \mid \text{黑桃第一}) = 13/51$。

$P = (13/52)(13/51) = 169/2652 = 13/204 \approx 0.0637$。

---

**4.** $P = \frac{7}{10} \times \frac{6}{9} \times \frac{5}{8} = \frac{210}{720} = \frac{7}{24} \approx 0.292$。

---

**5.** $P(\text{拥堵}) = 0.20 \times 0.60 + 0.50 \times 0.40 = 0.12 + 0.20 = 0.32$。

---

**6.** $B$ = "$4$ 的倍数"，$|B| = 25$。$A$ = "$6$ 的倍数"。

$A \cap B$ = "$\text{lcm}(4,6)=12$ 的倍数"，$|A \cap B| = 8$。

$P(A \mid B) = 8/25 = 0.32$。

**7.** $P(\text{全不中}) = 0.3 \times 0.2 \times 0.1 = 0.006$。

$P(\text{至少一人命中}) = 1 - 0.006 = 0.994$。

## §2 Bayes 定理

**8.** $P(\text{次品}) = 0.02 \times 0.6 + 0.05 \times 0.4 = 0.012 + 0.020 = 0.032$。

$P(\text{甲} \mid \text{次品}) = 0.012/0.032 = 3/8 = 0.375$。

---

**9.** $P(+) = 0.95 \times 0.02 + 0.10 \times 0.98 = 0.019 + 0.098 = 0.117$。

$P(D \mid +) = 0.019/0.117 \approx 0.162$。

---

**10.** $P(\text{白}) = (7/10)(1/3) + (5/10)(1/3) + (2/10)(1/3) = (7+5+2)/(10 \times 3) = 14/30 = 7/15$。

$P(B_1 \mid \text{白}) = \frac{(7/10)(1/3)}{7/15} = \frac{7/30}{7/15} = \frac{7/30}{14/30} = 1/2$。

---

**11.** $P(\text{真话}) = 0.90 \times 0.70 + 0.40 \times 0.30 = 0.63 + 0.12 = 0.75$。

$P(\text{诚实} \mid \text{真话}) = 0.63/0.75 = 21/25 = 0.84$。

---

**12.** 前两局 $1:1$，还需再打至多 $3$ 局（先到 $3$ 胜者赢），甲需要再赢 $2$ 局，乙也需要再赢 $2$ 局。

剩余局的可能结果（甲赢记 W，乙赢记 L）：

- 两局内甲赢：WW → 概率 $0.6^2 = 0.36$
- 三局甲赢（第三局赢）：WLW 或 LWW → 概率 $2 \times 0.6^2 \times 0.4 = 0.288$
- 合计 $P(\text{甲赢}) = 0.36 + 0.288 = 0.648$。

---

**13.** $10{,}000$ 人中：患者 $200$ 人，健康者 $9{,}800$ 人。

患者阳性：$200 \times 0.95 = 190$。

健康者阳性（假阳性）：$9{,}800 \times 0.10 = 980$。

总阳性 $= 190 + 980 = 1{,}170$。

$P(D \mid +) = 190/1170 \approx 0.162$。与公式结果一致。✓

## §3 独立性

**14.** $P(A)P(B) = 0.5 \times 0.3 = 0.15 = P(A \cap B)$。独立。✓

---

**15.** $P(A \cap B) = 0.4 \times 0.6 = 0.24$（独立）。

$P(A \cup B) = 0.4 + 0.6 - 0.24 = 0.76$。

$P(A^c \cap B) = P(B) - P(A \cap B) = 0.6 - 0.24 = 0.36$。

（或由 $A^c, B$ 独立：$0.6 \times 0.6 = 0.36$。）

---

**16.** $P(A) = 2/6 = 1/3$，$P(B) = 3/6 = 1/2$，$P(C) = 4/6 = 2/3$。

$A \cap B = \{2\}$，$P = 1/6$。$P(A)P(B) = 1/6$。$A, B$ 独立 ✓。

$A \cap C = \{1,2\}$，$P = 2/6 = 1/3$。$P(A)P(C) = 2/9$。$1/3 \neq 2/9$。$A, C$ 不独立 ✗。

$B \cap C = \{2,4\}$，$P = 2/6 = 1/3$。$P(B)P(C) = 1/3$。$B, C$ 独立 ✓。

---

**17.** $P(\text{两个都失败}) = (1-0.95)(1-0.90) = 0.05 \times 0.10 = 0.005$。

$P(\text{系统正常}) = 1 - 0.005 = 0.995$。

---

**18.** 若 $P(A) = 0$：$0 \leq P(A \cap B) \leq P(A) = 0$，所以 $P(A \cap B) = 0 = 0 \cdot P(B) = P(A)P(B)$。

若 $P(A) = 1$：$P(A \cap B) = P(B) - P(A^c \cap B)$。由上面 $P(A^c) = 0$ 的情况，$P(A^c \cap B) = 0$，所以 $P(A \cap B) = P(B) = 1 \cdot P(B) = P(A)P(B)$。$\blacksquare$

---

**19.** $P(\text{全部正确}) = (1 - 0.01)^{10} = 0.99^{10} \approx 0.9044$。

$P(\text{至少一个错误}) = 1 - 0.9044 = 0.0956 \approx 9.6\%$。

**20.** 考虑样本空间 $\Omega = \{1, 2, 3, 4\}$，各概率 $1/4$。

$A = \{1, 2\}$，$B = \{1, 3\}$，$C = \{1, 4\}$。

$P(A) = P(B) = P(C) = 1/2$。

$A \cap B = \{1\}$，$P = 1/4 = P(A)P(B)$ ✓。

$A \cap C = \{1\}$ 和之前类似不行…让我换一个。

取 $\Omega = \{000, 011, 101, 110\}$，均匀分布（各 $1/4$）。$A$ = "第一位为 $0$"，$B$ = "第二位为 $0$"，$C$ = "第三位为 $0$"。

$A = \{000, 011\}$，$B = \{000, 101\}$，$C = \{000, 110\}$，各 $P = 1/2$。

$A \cap B = \{000\}$，$P = 1/4 = P(A)P(B)$ ✓。类似 $P(A \cap C) = P(B \cap C) = 1/4$ ✓。两两独立。

但 $A \cap B \cap C = \{000\}$，$P = 1/4 \neq 1/8 = P(A)P(B)P(C)$。不相互独立。✓
