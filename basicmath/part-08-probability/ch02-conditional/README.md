# 第 2 章：条件概率（Conditional Probability）

## 章概览

"如果已经知道一些信息，概率会怎么变化？"——这是条件概率要回答的核心问题。本章从条件概率的定义出发，推导乘法规则和全概率公式，然后到达概率论最强大的工具——**Bayes 定理**。最后讨论独立性——当一个事件的发生对另一个事件的概率没有影响时。

条件概率不仅是概率论的核心概念，更是统计推断、机器学习和人工智能的理论基础。Bayes 定理将"从原因推断结果"翻转为"从结果推断原因"，这一思想深刻地影响了人类认知和科学方法论。
