# §3 独立性（Independence）

**前置知识**：[§1 条件概率与乘法规则](01-conditional-probability.md)（条件概率、乘法规则）、[§2 Bayes 定理](02-bayes.md)（先验与后验）

**全景图**：直觉上，两个事件"独立"意味着一个事件的发生对另一个事件的概率没有影响。本节精确定义独立性，区分"两两独立"和"相互独立"这两个容易混淆的概念，并简要介绍条件独立。独立性是概率论中最重要的概念之一——它使得复杂系统的分析成为可能。

**预估学习时间**：约 2–3 小时

---

## 动机

掷一个骰子和掷一枚硬币——这两件事显然"没有关系"。知道骰子的结果不会改变硬币正面的概率。这就是**独立性**的直觉。

但独立性的精确定义需要小心。在概率论中，独立性不是基于"物理上没有联系"的判断，而是基于**概率的数学关系**。

---

## 1. 两个事件的独立性

### 1.1 定义

> **定义 1**（独立性）
>
> 事件 $A$ 和 $B$ 是**独立的**（independent），若
>
> $$P(A \cap B) = P(A) \cdot P(B)$$

### 1.2 等价表述

若 $P(B) > 0$，独立性等价于：

$$P(A \mid B) = P(A)$$

即"知道 $B$ 发生不改变 $A$ 的概率"。

**证明**：$P(A \mid B) = P(A \cap B)/P(B) = P(A)P(B)/P(B) = P(A)$。反之亦然。

由对称性，独立性也等价于 $P(B \mid A) = P(B)$（当 $P(A) > 0$）。

### 1.3 独立性 vs 互斥

> **警告**：独立性和互斥性是**完全不同**的概念！

| 概念 | 定义 | 直觉 |
|------|------|------|
| 互斥 | $P(A \cap B) = 0$ | 不能同时发生 |
| 独立 | $P(A \cap B) = P(A)P(B)$ | 互不影响 |

若 $P(A) > 0$ 且 $P(B) > 0$，则互斥事件**不是**独立的！因为互斥意味着 $P(A \mid B) = 0 \neq P(A)$——知道 $B$ 发生意味着 $A$ 一定不发生。

> **例 1**（掷骰子）
>
> 掷一个公平骰子。$A = \{1, 2, 3\}$（$\leq 3$），$B = \{2, 4, 6\}$（偶数）。判断 $A$ 和 $B$ 是否独立。

**解**：$P(A) = 3/6 = 1/2$，$P(B) = 3/6 = 1/2$。

$A \cap B = \{2\}$，$P(A \cap B) = 1/6$。

$P(A) \cdot P(B) = 1/2 \times 1/2 = 1/4 \neq 1/6$。

因此 $A$ 和 $B$ **不独立**。$\blacksquare$

> **例 2**（掷骰子，另一组）
>
> $A = \{1, 2, 3, 4\}$（$\leq 4$），$B = \{2, 4, 6\}$（偶数）。判断独立性。

**解**：$P(A) = 4/6 = 2/3$，$P(B) = 3/6 = 1/2$。

$A \cap B = \{2, 4\}$，$P(A \cap B) = 2/6 = 1/3$。

$P(A) \cdot P(B) = 2/3 \times 1/2 = 1/3 = P(A \cap B)$。

$A$ 和 $B$ **独立**。$\blacksquare$

### 1.4 独立事件的补集

> **命题 1**：若 $A$ 和 $B$ 独立，则以下也独立：
> - $A$ 和 $B^c$
> - $A^c$ 和 $B$
> - $A^c$ 和 $B^c$

**证明**（$A$ 和 $B^c$）：

$P(A \cap B^c) = P(A) - P(A \cap B) = P(A) - P(A)P(B) = P(A)(1 - P(B)) = P(A)P(B^c)$。$\blacksquare$

## 2. 多个事件的独立性

### 2.1 相互独立

> **定义 2**（相互独立）
>
> 事件 $A_1, A_2, \ldots, A_n$ 是**相互独立的**（mutually independent），若对 $\{1, 2, \ldots, n\}$ 的**任意**子集 $S$（$|S| \geq 2$），
>
> $$P\!\left(\bigcap_{i \in S} A_i\right) = \prod_{i \in S} P(A_i)$$

对于 $n = 3$，相互独立要求以下**四个**等式同时成立：

$$P(A_1 \cap A_2) = P(A_1)P(A_2)$$
$$P(A_1 \cap A_3) = P(A_1)P(A_3)$$
$$P(A_2 \cap A_3) = P(A_2)P(A_3)$$
$$P(A_1 \cap A_2 \cap A_3) = P(A_1)P(A_2)P(A_3)$$

### 2.2 两两独立 vs 相互独立

> **定义 3**（两两独立）
>
> 事件 $A_1, \ldots, A_n$ 是**两两独立的**（pairwise independent），若对任意 $i \neq j$，
>
> $$P(A_i \cap A_j) = P(A_i)P(A_j)$$

**相互独立 $\Rightarrow$ 两两独立**，但反过来不成立。

> **例 3**（两两独立但不相互独立）
>
> 掷两枚公平硬币。定义三个事件：
> - $A$ = "第一枚正面"
> - $B$ = "第二枚正面"
> - $C$ = "两枚结果相同"
>
> 样本空间 $\Omega = \{HH, HT, TH, TT\}$，各概率 $1/4$。

$P(A) = P(B) = P(C) = 1/2$。

$A \cap B = \{HH\}$，$P(A \cap B) = 1/4 = P(A)P(B)$。✓

$A \cap C = \{HH\}$，$P(A \cap C) = 1/4 = P(A)P(C)$。✓

$B \cap C = \{HH\}$，$P(B \cap C) = 1/4 = P(B)P(C)$。✓

两两独立 ✓。但：

$A \cap B \cap C = \{HH\}$，$P(A \cap B \cap C) = 1/4 \neq P(A)P(B)P(C) = 1/8$。✗

**不是**相互独立！知道 $A$ 和 $B$ 都发生后，$C$ 一定发生（$P(C \mid A \cap B) = 1 \neq 1/2$）。$\blacksquare$

## 3. 独立性的应用

### 3.1 独立实验

当多次实验互不影响时（如重复掷骰子、抛硬币），各次结果是独立的。

> **例 4**（可靠性）
>
> 一个系统由 $3$ 个独立组件串联组成。各组件正常工作的概率分别为 $0.95$、$0.90$、$0.98$。求系统正常工作的概率。

**解**：串联系统要求所有组件正常。由独立性：

$$P(\text{系统正常}) = 0.95 \times 0.90 \times 0.98 = 0.8379 \quad \blacksquare$$

### 3.2 独立性简化计算

独立性使乘法规则大大简化：不需要条件概率，直接相乘即可。

$$P(A_1 \cap A_2 \cap \cdots \cap A_n) = P(A_1) \cdot P(A_2) \cdots P(A_n) \quad \text{（独立时）}$$

## 4. 条件独立（Conditional Independence）

> **定义 4**（条件独立）
>
> 给定事件 $C$（$P(C) > 0$），事件 $A$ 和 $B$ 在 $C$ 的条件下**条件独立**（conditionally independent），若
>
> $$P(A \cap B \mid C) = P(A \mid C) \cdot P(B \mid C)$$

**注意**：
- 独立 $\nRightarrow$ 条件独立
- 条件独立 $\nRightarrow$ 独立

> **例 5**（条件独立 vs 独立）
>
> 一个骰子，$C$ = "掷出的数 $\leq 3$"。$A$ = "掷出 $1$"，$B$ = "掷出 $2$"。
>
> 无条件：$A$ 和 $B$ 互斥（不独立）。
>
> 但在 $C$ 的条件下：$P(A \mid C) = 1/3$，$P(B \mid C) = 1/3$，$P(A \cap B \mid C) = 0 \neq 1/9$。仍然不是条件独立的。

条件独立在 Bayes 网络和机器学习中非常重要——朴素 Bayes 分类器假设特征在给定类别下条件独立。

## 例题

> **例题 1**
>
> $A$ 和 $B$ 独立，$P(A) = 0.6$，$P(B) = 0.3$。求 $P(A \cup B)$。

**解**：$P(A \cap B) = P(A)P(B) = 0.6 \times 0.3 = 0.18$（独立）。

$P(A \cup B) = P(A) + P(B) - P(A \cap B) = 0.6 + 0.3 - 0.18 = 0.72$。$\blacksquare$

> **例题 2**
>
> 独立掷 $5$ 枚公平硬币，求至少 $1$ 枚正面的概率。

**解**：$P(\text{全部反面}) = (1/2)^5 = 1/32$（独立性）。

$P(\text{至少 $1$ 枚正面}) = 1 - 1/32 = 31/32$。$\blacksquare$

## 要点回顾

| 概念 | 要点 |
|------|------|
| 独立性定义 | $P(A \cap B) = P(A)P(B)$ |
| 等价表述 | $P(A \mid B) = P(A)$——$B$ 的信息不影响 $A$ |
| 独立 ≠ 互斥 | 互斥且概率非零 $\Rightarrow$ 不独立 |
| 两两独立 ≠ 相互独立 | 相互独立更强，要求所有子集的乘法等式 |
| 条件独立 | 给定第三个事件后的独立性，与无条件独立无蕴含关系 |

## 自测题

**题 1**：$P(A) = 0.4$，$P(B) = 0.5$，$P(A \cup B) = 0.7$。$A$ 和 $B$ 独立吗？

<details>
<summary>答案</summary>

$P(A \cap B) = P(A) + P(B) - P(A \cup B) = 0.4 + 0.5 - 0.7 = 0.2$。

$P(A) \cdot P(B) = 0.4 \times 0.5 = 0.2 = P(A \cap B)$。

是独立的。
</details>

**题 2**：$A$ 和 $B$ 独立，$P(A) = 0.3$。求 $P(A^c \cap B^c)$（用 $P(B) = 0.4$）。

<details>
<summary>答案</summary>

$A^c$ 和 $B^c$ 也独立。

$P(A^c \cap B^c) = P(A^c) \cdot P(B^c) = 0.7 \times 0.6 = 0.42$。
</details>

**题 3**：一个系统由两个并联的独立组件组成，每个工作概率 $0.9$。系统正常（至少一个工作）的概率？

<details>
<summary>答案</summary>

$P(\text{两个都失败}) = 0.1 \times 0.1 = 0.01$。

$P(\text{系统正常}) = 1 - 0.01 = 0.99$。
</details>
