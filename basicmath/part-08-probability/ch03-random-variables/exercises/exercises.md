# 第 3 章 随机变量与分布 — 练习题

## §1 离散随机变量

1. ★☆☆ 掷一个骰子，$X$ = 点数。写出 $X$ 的 PMF。

2. ★☆☆ $X$ 的 PMF：$p(0) = 0.1$，$p(1) = 0.3$，$p(2) = 0.4$，$p(3) = 0.2$。求 $P(X \geq 2)$ 和 $F_X(1.5)$。

3. ★★☆ 掷两个骰子，$X$ = 两点数中较大的那个。写出 $X$ 的 PMF。

4. ★★☆ 随机变量 $X$ 的 CDF 为 $F(x) = 0$（$x<1$），$F(x) = 0.2$（$1 \leq x < 3$），$F(x) = 0.5$（$3 \leq x < 5$），$F(x) = 1$（$x \geq 5$）。求 PMF 和 $P(2 < X \leq 5)$。

5. ★★☆ $P(X = k) = c \cdot 2^{-k}$，$k = 1, 2, 3, \ldots$。求 $c$ 和 $P(X \leq 3)$。

## §2 常见离散分布

6. ★☆☆ $X \sim B(8, 0.4)$。求 $P(X = 3)$、$E[X]$、$\text{Var}(X)$。

7. ★☆☆ $X \sim \text{Poi}(2)$。求 $P(X \leq 2)$。

8. ★☆☆ $X \sim \text{Geom}(0.2)$。$E[X]$？$P(X = 3)$？

9. ★★☆ 某彩票中奖概率 $1/1000$。买 $2000$ 张，至少中一次的概率约为多少？（用 Poisson 近似）

10. ★★☆ 掷公平硬币 $6$ 次，求恰好 $3$ 次正面的概率。

11. ★★☆ 一个袋中 $15$ 个球，$5$ 个红球。不放回取 $4$ 个，求恰好 $2$ 个红球的概率。

12. ★★★ 证明几何分布的无记忆性：$P(X > m+n \mid X > m) = P(X > n)$。

13. ★★★ 某保险公司每天平均收到 $3$ 个理赔申请（Poisson）。求 (a) 一天收到恰好 $5$ 个的概率；(b) 连续两天每天都收到至少 $1$ 个的概率。

14. ★★★ 证明 Poisson 极限定理：当 $n \to \infty$，$p = \lambda/n$ 时，$\binom{n}{k}p^k(1-p)^{n-k} \to \lambda^k e^{-\lambda}/k!$。

15. ★★★ $X \sim \text{Hyper}(100, 30, 10)$。计算 $E[X]$ 和 $\text{Var}(X)$，并与 $B(10, 0.3)$ 的对应值比较。
