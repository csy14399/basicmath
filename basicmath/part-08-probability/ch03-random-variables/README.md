# 第 3 章：随机变量与分布（Random Variables & Distributions）

## 章概览

前两章讨论了事件的概率。本章迈出关键一步——将随机结果**数值化**，引入**随机变量**（random variable）的概念。随机变量不是"变量"而是"函数"——它把样本空间中的结果映射为实数，使得我们可以用函数和数列的工具来研究随机性。

在定义了随机变量之后，我们系统学习常见的离散分布：Bernoulli 分布、二项分布、几何分布、Poisson 分布和超几何分布。每种分布都有其特定的应用场景，掌握它们是概率论应用的基础。
