# 第 4 章 期望与方差 — 思考者角落（Thinker's Corner）

> 本节探讨期望和方差的一些深层话题。

---

## 1. 期望不存在的随机变量

### St. Petersburg 悖论

想象这样一个赌博游戏：掷公平硬币，第一次出现正面时停止。如果在第 $k$ 次才出现正面，你赢得 $2^k$ 元。你愿意付多少入场费？

$X$ = 赢得的金额。$P(X = 2^k) = (1/2)^k$，$k = 1, 2, 3, \ldots$。

$$E[X] = \sum_{k=1}^{\infty} 2^k \cdot \left(\frac{1}{2}\right)^k = \sum_{k=1}^{\infty} 1 = \infty$$

期望是**无穷大**！按照"期望最大化"的策略，你应该愿意付任何有限金额来参加这个游戏。但实际上，大多数人只愿意付很少的钱。

### 解决方案

这个悖论（1738 年由 Daniel Bernoulli 提出）有多种解释：

1. **效用理论**（Bernoulli 的解答）：人们最大化的不是金额的期望，而是"效用"（utility）的期望。如果效用函数是对数 $U(x) = \ln x$，则 $E[U(X)] = \sum (1/2)^k \ln 2^k = \ln 2 \sum k/2^k = 2\ln 2 \approx 1.39$，相当于 $e^{1.39} \approx 4$ 元的确定收入。
2. **有限财富**：赌场的资金是有限的，所以 $X$ 被截断，期望变为有限。
3. **风险厌恶**：方差也是无穷大，理性的风险厌恶者不应该只看期望。

## 2. 矩（Moments）

期望 $E[X]$ 和 $E[X^2]$ 是 $X$ 的前两个**矩**（moments）的特例：

| 矩 | 定义 | 含义 |
|----|------|------|
| $k$ 阶矩 | $E[X^k]$ | 分布的"形状"信息 |
| $k$ 阶中心矩 | $E[(X-\mu)^k]$ | 围绕均值的形状 |
| $1$ 阶矩 | $E[X] = \mu$ | 均值（位置） |
| $2$ 阶中心矩 | $E[(X-\mu)^2] = \sigma^2$ | 方差（分散度） |
| $3$ 阶标准中心矩 | $E[((X-\mu)/\sigma)^3]$ | 偏度（skewness，对称性） |
| $4$ 阶标准中心矩 | $E[((X-\mu)/\sigma)^4]$ | 峰度（kurtosis，尾部厚度） |

### 矩与分布的关系

一个自然的问题是：矩序列 $\{E[X^k]\}_{k=1}^{\infty}$ 是否唯一确定了分布？

**矩问题**（moment problem）：答案取决于具体情况。对于有**有限支撑**的离散分布或满足 **Carleman 条件** $\sum 1/(E[X^{2k}])^{1/(2k)} = \infty$ 的分布，矩唯一确定分布。但存在不同的分布有完全相同的矩序列的例子（如某些对数正态分布的变体）。

## 3. 期望的公理化视角

### 从公理出发

在 Kolmogorov 的框架中，期望是通过**Lebesgue 积分**定义的：

$$E[X] = \int_{\Omega} X(\omega) \, dP(\omega)$$

对离散随机变量，这退化为我们学习的求和公式。对连续随机变量，它变成关于密度函数的积分。

这种统一的定义使得期望的所有性质（线性性、单调性、收敛定理等）都可以在一个框架中证明，无需对离散和连续分别处理。

### Kolmogorov 的收敛定理

期望的一个深刻性质是它与极限的关系。在什么条件下 $E[\lim X_n] = \lim E[X_n]$？这涉及到三大收敛定理：

1. **单调收敛定理**：$0 \leq X_1 \leq X_2 \leq \cdots$ 时成立。
2. **Fatou 引理**：$E[\liminf X_n] \leq \liminf E[X_n]$。
3. **控制收敛定理**：如果存在可积的 $Y$ 使得 $|X_n| \leq Y$，则交换极限与期望合法。

这些定理是高级概率论的基石，也是分析学（测度论）与概率论深度融合的例证。
