# 第 4 章：期望与方差（Expectation & Variance）

## 章概览

如果说分布是随机变量的"完整肖像"，那么期望和方差就是这幅肖像的两个最重要的**数字摘要**。**期望**（expectation）告诉我们分布的"中心"在哪里，**方差**（variance）告诉我们分布有多"分散"。本章系统学习这两个概念及其性质。

期望的线性性是概率论中最有用的性质之一——它甚至对非独立的随机变量也成立。方差的分析则需要独立性的支持。最后，Chebyshev 不等式将期望和方差联系起来，给出了概率的通用界。
