# 第 4 章 期望与方差 — 练习题解答

## §1 数学期望

**1.** $E[X] = 1(0.1) + 2(0.2) + 3(0.3) + 4(0.4) = 0.1 + 0.4 + 0.9 + 1.6 = 3.0$。

---

**2.** $E[X] = 50 \times 0.4 = 20$。

---

**3.** $E[X] = 7$。$E[2X+3] = 2 \times 7 + 3 = 17$。

---

**4.** $E[X] = 0$（对称分布）。

$E[X^2] = \frac{1}{7}(9+4+1+0+1+4+9) = 28/7 = 4$。

$E[|X|] = \frac{1}{7}(3+2+1+0+1+2+3) = 12/7 \approx 1.714$。

---

**5.** $E[X] = 1/p = 4$。

$E[X(X-1)] = \sum_{k=2}^{\infty} k(k-1)(1-p)^{k-1}p$。利用 $\sum_{k=2}^{\infty} k(k-1)x^{k-1} = 2x/(1-x)^3$（$|x|<1$）：

$E[X(X-1)] = p \cdot 2q/p^3 = 2q/p^2 = 2(3/4)/(1/16) = 24$。

$E[X^2] = 24 + 4 = 28$。

---

**6.** 设 $X_i$ 为第 $i$ 个骰子的点数。$E[X_i] = 3.5$。

$E[S] = E[X_1] + E[X_2] + E[X_3] = 3 \times 3.5 = 10.5$。

---

**7.** $X_i = 1$ 当第 $i$ 人坐在位置 $i$。$P(X_i = 1) = 1/100$。

$E[X] = 100 \times (1/100) = 1$。

---

**8.** $X_i = 1$ 当第 $i$ 对夫妻相邻。圆桌上 $2n$ 个位置，第 $i$ 对的妻子在丈夫旁边的概率为 $2/(2n-1)$（丈夫有 $2$ 个邻座，共 $2n-1$ 个其他位置）。

$E[X] = n \cdot \frac{2}{2n-1} = \frac{2n}{2n-1}$。

---

## §2 方差

**9.** $\text{Var}(X) = 20 \times 0.5 \times 0.5 = 5$。$\sigma = \sqrt{5} \approx 2.236$。

---

**10.** $E[Y] = 4 \times 5 - 3 = 17$。$\text{Var}(Y) = 16 \times 2 = 32$。

---

**11.** $E[X] = 0(0.5) + 1(0.3) + 4(0.2) = 0 + 0.3 + 0.8 = 1.1$。

$E[X^2] = 0(0.5) + 1(0.3) + 16(0.2) = 0 + 0.3 + 3.2 = 3.5$。

$\text{Var}(X) = 3.5 - 1.1^2 = 3.5 - 1.21 = 2.29$。

---

**12.** $E[S] = 36 \times 10 = 360$。

$\text{Var}(S) = 36 \times 9 = 324$（独立可加）。

$\sigma_S = \sqrt{324} = 18$。

---

**13.** $P(|X-50| \geq 15) \leq 25/225 = 1/9 \approx 11.1\%$。

---

**14.** $\text{Var}(X) = E[(X-\mu)^2]$。$(X-\mu)^2 \geq 0$，所以其期望 $\geq 0$。

等号成立 $\Leftrightarrow$ $P((X-\mu)^2 = 0) = 1$ $\Leftrightarrow$ $P(X = \mu) = 1$，即 $X$ 几乎处处等于常数。$\blacksquare$

---

**15.** $\text{Var}(X) = 10(0.3)(0.7) = 2.1$，$\text{Var}(Y) = 20(0.3)(0.7) = 4.2$。

$\text{Var}(X+Y) = 2.1 + 4.2 = 6.3$（独立）。

验证：$X + Y \sim B(30, 0.3)$（独立二项随机变量相加，参数 $p$ 相同），$\text{Var} = 30(0.3)(0.7) = 6.3$。✓

---

**16.** $E[\bar{X}_n] = \frac{1}{n} \sum E[X_i] = \frac{n\mu}{n} = \mu$。

$\text{Var}(\bar{X}_n) = \frac{1}{n^2} \sum \text{Var}(X_i) = \frac{n\sigma^2}{n^2} = \frac{\sigma^2}{n}$。

---

**17.** 由 Chebyshev 不等式：

$$P(|\bar{X}_n - \mu| \geq \epsilon) \leq \frac{\text{Var}(\bar{X}_n)}{\epsilon^2} = \frac{\sigma^2}{n\epsilon^2}$$

当 $n \to \infty$ 时，$\sigma^2/(n\epsilon^2) \to 0$。

故 $P(|\bar{X}_n - \mu| \geq \epsilon) \to 0$。这就是**弱大数定律**。$\blacksquare$
