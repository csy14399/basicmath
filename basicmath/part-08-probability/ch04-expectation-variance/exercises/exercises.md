# 第 4 章 期望与方差 — 练习题

## §1 数学期望

1. ★☆☆ $X$ 的 PMF：$p(1) = 0.1$，$p(2) = 0.2$，$p(3) = 0.3$，$p(4) = 0.4$。求 $E[X]$。

2. ★☆☆ $X \sim B(50, 0.4)$。$E[X]$？

3. ★☆☆ $X \sim \text{Poi}(7)$。$E[X]$？$E[2X+3]$？

4. ★★☆ $X$ 均匀取 $\{-3, -2, -1, 0, 1, 2, 3\}$。$E[X]$？$E[X^2]$？$E[|X|]$？

5. ★★☆ $X \sim \text{Geom}(1/4)$。$E[X]$？$E[X^2]$？（提示：用 $E[X^2] = E[X(X-1)] + E[X]$。）

6. ★★☆ 随机掷 $3$ 枚公平骰子。$S$ = 点数之和。用线性性求 $E[S]$。

7. ★★★ $100$ 个人随机坐成一排，每人有自己的号码（$1$ 到 $100$）。设 $X$ = 坐在自己号码位置上的人数。用指示器变量法求 $E[X]$。

8. ★★★ $n$ 对夫妻随机围坐圆桌（$2n$ 个座位），$X$ = 坐在一起的夫妻对数。求 $E[X]$。

## §2 方差

9. ★☆☆ $X \sim B(20, 0.5)$。$\text{Var}(X)$ 和 $\sigma$？

10. ★☆☆ $Y = 4X - 3$，$E[X] = 5$，$\text{Var}(X) = 2$。求 $E[Y]$ 和 $\text{Var}(Y)$。

11. ★★☆ $X$ 的 PMF：$p(0) = 0.5$，$p(1) = 0.3$，$p(4) = 0.2$。求 $E[X]$，$E[X^2]$，$\text{Var}(X)$。

12. ★★☆ $X_1, \ldots, X_{36}$ 独立同分布，$E[X_i] = 10$，$\text{Var}(X_i) = 9$。设 $S = \sum X_i$。求 $E[S]$，$\text{Var}(S)$，$\sigma_S$。

13. ★★☆ 用 Chebyshev 不等式：$E[X] = 50$，$\text{Var}(X) = 25$。$P(|X - 50| \geq 15)$ 的上界？

14. ★★★ 证明 Var$(X) \geq 0$，并说明等号何时成立。

15. ★★★ $X$ 和 $Y$ 独立，$X \sim B(10, 0.3)$，$Y \sim B(20, 0.3)$。求 $\text{Var}(X + Y)$，并验证 $X + Y \sim B(30, 0.3)$。

16. ★★★ 设 $\bar{X}_n = (X_1 + \cdots + X_n)/n$，$X_i$ i.i.d.，$E[X_i] = \mu$，$\text{Var}(X_i) = \sigma^2$。求 $E[\bar{X}_n]$ 和 $\text{Var}(\bar{X}_n)$。

17. ★★★ 利用 Chebyshev 不等式和第 16 题的结果，证明：对任意 $\epsilon > 0$，$P(|\bar{X}_n - \mu| \geq \epsilon) \to 0$（$n \to \infty$）。
