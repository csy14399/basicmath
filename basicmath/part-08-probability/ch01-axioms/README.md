# 第 1 章：概率公理（Probability Axioms）

## 章概览

"这件事发生的可能性有多大？"——这个日常生活中再自然不过的问题，在数学上需要一个**严格的定义**。本章建立概率论的数学基础：从样本空间和事件出发，引入 Kolmogorov 的三条公理，由此推导出概率的各种性质。这是整个概率论大厦的地基——所有后续章节（条件概率、随机变量、期望、大数定律）都建立在这个公理体系之上。

本章首先从"实验"和"结果"的直觉出发，建立样本空间 $\Omega$ 和事件的概念，然后给出概率的公理化定义。接着从公理出发推导概率的基本性质：补集概率、加法公式、容斥原理的概率版本、单调性和 Boole 不等式。

## 前置知识

- **Part 1 第 1 章（逻辑）**：命题逻辑、"或""且"的精确含义——事件的运算（并、交、补）与逻辑运算对应
- **Part 1 第 2 章（集合）**：集合的并集、交集、补集、不相交——事件就是样本空间的子集
- **Part 1 第 3 章（证明方法）**：数学归纳法——用于将有限结论推广到可列情形
- **Part 7 第 1 章（计数原理）**：加法原理、容斥原理——古典概型和概率版容斥的基础

- **准确描述随机实验的样本空间和事件**

- **用古典概型计算等可能事件的概率**
