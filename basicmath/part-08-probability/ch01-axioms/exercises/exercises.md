# 第 1 章 概率公理 — 练习题

## §1 概率的概念

1. ★☆☆ 掷一个公平骰子，求掷出大于 $4$ 的数的概率。

2. ★☆☆ 从 $\{1, 2, 3, \ldots, 30\}$ 中随机取一个数，求取到 $5$ 的倍数的概率。

3. ★☆☆ 一个袋中有 $4$ 个红球、$3$ 个白球、$2$ 个蓝球。随机取一个球，求取到红球或蓝球的概率。

4. ★★☆ 掷两个公平骰子，求点数之和为偶数的概率。

5. ★★☆ 从 $52$ 张标准扑克牌中随机抽 $1$ 张，求抽到红心或人头牌（J, Q, K）的概率。

6. ★★☆ 从 $\{1, 2, \ldots, 100\}$ 中随机取一个数。设 $A$ = "是 $4$ 的倍数"，$B$ = "是 $6$ 的倍数"。验证 $P(A \cup B) = P(A) + P(B) - P(A \cap B)$。

7. ★★☆ 掷三枚公平硬币，求恰好两枚正面的概率。

8. ★★★ 从 $10$ 个产品中有 $3$ 个次品。随机抽取 $4$ 个产品，求恰好有 $1$ 个次品的概率。

9. ★★★ 一个可列样本空间 $\Omega = \{\omega_1, \omega_2, \omega_3, \ldots\}$，定义 $P(\{\omega_k\}) = c \cdot (2/3)^k$。求常数 $c$ 使得 $P$ 是合法的概率。

10. ★★★ 设 $P(A) = 0.6$，$P(B) = 0.7$。证明 $P(A \cap B) \geq 0.3$。

## §2 概率的性质

11. ★☆☆ 设 $P(A) = 0.35$。求 $P(A^c)$。

12. ★☆☆ 设 $P(A) = 0.4$，$P(B) = 0.5$，$P(A \cap B) = 0.2$。求 $P(A \cup B)$。

13. ★★☆ 设 $P(A) = 0.5$，$P(B) = 0.6$，$P(A \cup B) = 0.8$。求 $P(A^c \cap B)$。

14. ★★☆ 设 $A \subseteq B$，$P(A) = 0.3$，$P(B) = 0.7$。求 $P(B \setminus A)$。

15. ★★☆ 某班 $40$ 人中，$25$ 人喜欢篮球，$20$ 人喜欢足球，$10$ 人两者都喜欢。随机抽一人，求(a) 至少喜欢一项的概率；(b) 两项都不喜欢的概率。

16. ★★☆ 设 $P(A) = 0.3$，$P(B) = 0.4$，$A$ 和 $B$ 互斥。求 $P(A \cup B)$ 和 $P(A^c \cap B^c)$。

17. ★★★ 证明：对任意事件 $A$ 和 $B$，$P(A \cap B) \geq P(A) + P(B) - 1$（Bonferroni 不等式）。

18. ★★★ 对 $n$ 个事件 $A_1, \ldots, A_n$，每个 $P(A_i) > 1 - 1/n$。证明 $P(A_1 \cap \cdots \cap A_n) > 0$。

19. ★★★ 在 $\{1, 2, \ldots, 1000\}$ 中，有多少个正整数不能被 $2$、$3$ 或 $5$ 整除？用概率语言表述并计算。

20. ★★★ 设 $A_1 \subseteq A_2 \subseteq A_3 \subseteq \cdots$，$P(A_n) = 1 - 1/n$。求 $P\!\left(\bigcup_{n=1}^{\infty} A_n\right)$。
