# 第 4 章：行列式（Determinants）[Bridge]

## 章概览

行列式（determinant）是从方阵到实数的一个函数——它把整个矩阵的信息浓缩为**一个数**。这个数有丰富的含义：几何上它度量线性变换对**体积的缩放**（带符号），代数上它判定矩阵**是否可逆**，计算上它通过 Cramer 法则直接给出**方程组的解**。本章从 $2 \times 2$ 行列式的面积解释出发，推广到 $3 \times 3$ 行列式和一般性质，然后探讨行列式在逆矩阵和方程组求解中的应用。
