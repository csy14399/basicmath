# 第九部分：线性代数初步（Introduction to Linear Algebra）[Bridge]

## 本部分概览

线性代数（linear algebra）是现代数学的**通用语言**。它研究向量空间、线性变换和线性方程组——这些概念渗透到数学的几乎每一个分支，以及物理学、工程学、计算机科学、经济学和数据科学的核心。

如果说前面的部分建立了逻辑框架（Part 1）、认识了数的世界（Part 2）、掌握了代数工具（Part 3）、研究了函数家族（Part 4）、探索了几何空间（Part 5）、逼近了无穷极限（Part 6）、学会了计数的艺术（Part 7）、量化了不确定性（Part 8），那么第九部分将把这些知识**统一到一个强大的框架中**——线性代数用矩阵和向量空间的语言，将几何直觉与代数计算完美结合。

本部分的核心主题是：**线性结构的代数与几何（Algebra and Geometry of Linear Structures）。**

> **[Bridge] 标注**：本部分全部内容标记为 [Bridge]，意味着它是从高中数学迈向大学数学的**桥梁内容**。目标不是穷尽线性代数的所有理论，而是建立正确的直觉和基本技能，使大学线性代数教材读起来不再陌生。

本部分包含四章：

| 章 | 主题 | 内容 |
|----|------|------|
| [第 1 章：向量空间](ch01-vector-spaces/README.md) | 向量空间（vector spaces）[Bridge] | 向量空间公理、$\mathbb{R}^n$、子空间、线性组合、线性无关、基与维数 |
| [第 2 章：矩阵](ch02-matrices/README.md) | 矩阵（matrices）[Bridge] | 矩阵运算、特殊矩阵、转置、逆矩阵、矩阵作为线性变换 |
| [第 3 章：线性方程组](ch03-linear-systems/README.md) | 线性方程组（linear systems）[Bridge] | 增广矩阵、行变换、Gauss 消元、行阶梯形、解的结构、秩 |
| [第 4 章：行列式](ch04-determinants/README.md) | 行列式（determinants）[Bridge] | 2×2 和 3×3 行列式、几何意义、性质、Cramer 法则、可逆性判定 |

这四章的关系：第一章建立向量空间的抽象框架——从几何向量推广到更一般的"线性结构"。第二章引入矩阵——向量空间之间线性映射的**计算工具**。第三章用矩阵语言统一处理线性方程组——Gauss 消元是线性代数最基本的算法。第四章引入行列式——一个从方阵到数的函数，它判定矩阵是否可逆，量化线性变换对体积的缩放。

## 本部分的主题：线性结构的代数与几何

贯穿本部分的核心思想是**线性代数将代数计算与几何直觉统一起来**：

1. **向量空间**（Ch01）：从具体的箭头到抽象的公理——任何满足八条规则的集合都是向量空间，这个抽象赋予了线性代数惊人的普适性。
2. **矩阵**（Ch02）：线性变换的"数字化"——一个 $m \times n$ 矩阵就是一个从 $\mathbb{R}^n$ 到 $\mathbb{R}^m$ 的线性映射，矩阵乘法就是映射的复合。
3. **线性方程组**（Ch03）：$A\mathbf{x} = \mathbf{b}$ 将方程组统一为一个矩阵方程——Gauss 消元提供了系统化的求解算法，解的结构揭示了向量空间的几何。
4. **行列式**（Ch04）：一个数浓缩了一个方阵的核心信息——它度量体积的缩放、判定可逆性、在 Cramer 法则中直接给出方程的解。

这四个主题展示了线性代数的一个核心哲学：**代数的计算与几何的直觉是同一枚硬币的两面**。
