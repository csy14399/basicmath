# 第 1 章 向量空间 — 练习题 [Bridge]

## §1 向量空间的直觉

1. ★☆☆ 在 $\mathbb{R}^3$ 中，计算 $\mathbf{u} + \mathbf{v}$ 和 $3\mathbf{u} - 2\mathbf{v}$，其中 $\mathbf{u} = (1, -2, 3)$，$\mathbf{v} = (4, 0, -1)$。

2. ★☆☆ 向量空间的八条公理中，哪几条属于加法公理？哪几条属于标量乘法公理？哪几条是分配律？

3. ★★☆ 集合 $W = \{(x, y) \in \mathbb{R}^2 : x \geq 0\}$（右半平面）是否为 $\mathbb{R}^2$ 的子空间？说明理由。

4. ★★☆ 集合 $W = \{(x, y, z) \in \mathbb{R}^3 : x - 2y + 3z = 0\}$ 是否为 $\mathbb{R}^3$ 的子空间？用子空间判定法验证。

5. ★★☆ 设 $W = \{p(x) \in P_2 : p(1) = 0\}$。证明 $W$ 是 $P_2$ 的子空间。

6. ★★☆ 设 $W_1 = \{(x, y, z) : x + y = 0\}$ 和 $W_2 = \{(x, y, z) : y + z = 0\}$ 都是 $\mathbb{R}^3$ 的子空间。求 $W_1 \cap W_2$ 并验证它也是子空间。

7. ★★★ 证明：如果 $W$ 是向量空间 $V$ 的子空间，且 $\mathbf{v} \in V \setminus W$，则 $\mathbf{v} + W = \{\mathbf{v} + \mathbf{w} : \mathbf{w} \in W\}$ 不是子空间。

8. ★★★ 设 $V$ 是一个向量空间，$c$ 是标量，$\mathbf{v} \in V$。从公理出发证明：如果 $c \mathbf{v} = \mathbf{0}$，则 $c = 0$ 或 $\mathbf{v} = \mathbf{0}$。

9. ★★☆ 集合 $\{A \in M_{2 \times 2}(\mathbb{R}) : A^T = A\}$（所有 $2 \times 2$ 对称矩阵）是否为所有 $2 \times 2$ 矩阵空间的子空间？

10. ★★★ 设 $W_1, W_2$ 是向量空间 $V$ 的子空间。证明 $W_1 \cup W_2$ 是子空间当且仅当 $W_1 \subseteq W_2$ 或 $W_2 \subseteq W_1$。

## §2 线性无关与基

11. ★☆☆ 判断 $\mathbb{R}^2$ 中 $(1, 3)$ 和 $(2, 6)$ 是否线性无关。

12. ★☆☆ 向量 $(5, 7, 1)$ 是否为 $(1, 1, 0)$ 和 $(0, 1, 1)$ 的线性组合？

13. ★★☆ 判断 $\mathbb{R}^3$ 中 $(1, 0, 1)$、$(0, 1, 1)$、$(1, 1, 0)$ 是否线性无关。

14. ★★☆ 求 $W = \{(x, y, z) \in \mathbb{R}^3 : 2x - y + z = 0\}$ 的一组基和维数。

15. ★★☆ 证明 $\{1 - x, 1 + x\}$ 是 $P_1$ 的一组基。

16. ★★☆ 求 $\text{span}\{(1, 2, 3), (2, 4, 6)\}$ 的维数。

17. ★★★ 设 $\mathbf{v}_1, \mathbf{v}_2, \mathbf{v}_3$ 在 $\mathbb{R}^3$ 中线性无关。证明 $\mathbf{v}_1 + \mathbf{v}_2$, $\mathbf{v}_2 + \mathbf{v}_3$, $\mathbf{v}_1 + \mathbf{v}_3$ 也线性无关。

18. ★★★ 求 $W = \{(x, y, z, w) \in \mathbb{R}^4 : x + y + z + w = 0, \; x - y + z - w = 0\}$ 的一组基和维数。

19. ★★☆ $\mathbb{R}^3$ 中，两个线性无关的向量能否构成 $\mathbb{R}^3$ 的基？为什么？

20. ★★★ 设 $\dim V = n$，$\mathbf{v}_1, \ldots, \mathbf{v}_n$ 生成 $V$。证明它们线性无关。
