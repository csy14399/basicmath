# 第 1 章：向量空间（Vector Spaces）[Bridge]

## 章概览

在 Part 5 中，我们认识了**几何向量**——有方向和大小的箭头，可以相加、可以缩放。但向量远不止是箭头。多项式可以"相加"和"缩放"，函数可以"相加"和"缩放"，矩阵也可以——这些看似不同的对象，竟然服从**相同的代数规则**。线性代数的出发点就是这个深刻的洞察：把满足这些规则的一切对象统一到**向量空间**（vector space）的框架中。

本章从几何向量的直觉出发，提炼出向量空间的八条公理，然后探索线性组合、线性无关、基和维数——这些是线性代数最核心的概念。

## 前置知识

- **Part 1 第 1 章（逻辑）**：命题逻辑、量词——公理和定义的理解需要逻辑基础
- **Part 1 第 2 章（集合）**：集合、子集——向量空间和子空间是集合
- **Part 1 第 3 章（证明方法）**：反证法、数学归纳法——线性无关的判定经常使用反证法
- **Part 3（代数）**：多项式运算、方程求解——线性组合和线性无关的判定需要解方程
- **Part 5 第 5 章（向量）**：几何向量的加法、数乘——这是本章的直觉起点

## 学习成果

本章完成后你将能够：

- **陈述向量空间的八条公理**，理解为什么这些公理是"正确"的抽象
- **识别常见的向量空间**：$\mathbb{R}^n$、多项式空间、函数空间
- **判断一个子集是否构成子空间**（子空间判定法）
- **写出向量的线性组合**，计算向量组的张成空间
- **用定义判断向量组的线性无关性**
- **理解基和维数的概念**，找出向量空间的一组基
- **理解为什么任何两组基的元素数相同**
