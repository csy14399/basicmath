# 第 2 章：矩阵（Matrices）[Bridge]

## 章概览

如果向量是线性代数的**名词**，那么矩阵就是线性代数的**动词**——矩阵描述向量之间的线性变换，把输入向量映射为输出向量。本章系统介绍矩阵的定义和运算（加法、标量乘法、矩阵乘法），探讨特殊矩阵（单位矩阵、对角矩阵、对称矩阵），以及逆矩阵的概念。矩阵是后续两章（线性方程组、行列式）的核心计算工具。
