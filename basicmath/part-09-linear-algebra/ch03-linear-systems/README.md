# 第 3 章：线性方程组（Linear Systems）[Bridge]

## 章概览

线性方程组是数学中出现频率最高的问题之一——从中学的二元一次方程组到工程中的大规模数值计算，到处都有它的身影。本章用矩阵语言统一处理线性方程组，介绍最基本的算法——**Gauss 消元法**（Gaussian elimination），然后深入研究解的结构：什么时候有唯一解？什么时候无解？什么时候有无穷多解？这些问题的答案揭示了向量空间和矩阵的深层几何。

| [§2 解的结构](02-solution-structure.md) | 解的结构（solution structure）[Bridge] | 齐次与非齐次方程组、齐次解空间是子空间、通解 = 特解 + 齐次解、矩阵的秩、秩-零度定理、$\mathbb{R}^3$ 中的几何解释 |

## 前置知识

- **Ch01（向量空间）**：向量、线性组合、子空间——解空间是子空间
- **Ch02（矩阵）**：矩阵运算、矩阵方程 $A\mathbf{x} = \mathbf{b}$

## 学习成果

本章完成后你将能够：

- **将线性方程组转化为增广矩阵**
- **用 Gauss 消元法将矩阵化为行阶梯形和简化行阶梯形**
- **从行阶梯形读出方程组的解**（唯一解、无解、无穷多解）
- **区分齐次和非齐次方程组**，理解两者解的关系
- **计算矩阵的秩**
- **陈述秩-零度定理**并用于分析解的结构
