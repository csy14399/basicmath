# 第 3 章 线性方程组 — 思考者角落（Thinker's Corner）[Bridge]

> 本节超越教材核心内容，探索线性方程组在计算和应用中的更深层面。

---

## 1. 计算复杂度：Gauss 消元有多快？

### 运算次数

对 $n \times n$ 方程组，Gauss 消元需要约 $\frac{2}{3}n^3$ 次浮点运算（加法和乘法）。这是一个**多项式时间**算法——当 $n$ 翻倍时，运算量增长约 $8$ 倍。

| $n$ | 大约运算次数 |
|-----|-------------|
| $10$ | $667$ |
| $100$ | $666{,}667$ |
| $1{,}000$ | $6.67 \times 10^8$ |
| $10{,}000$ | $6.67 \times 10^{11}$ |

现代计算机每秒可以执行 $10^{10}$ 次浮点运算，所以 $n = 10{,}000$ 的方程组可以在一分钟内解决。

### 对比 Cramer 法则

Cramer 法则（Ch04）用行列式给出解的显式公式。但直接计算 $n$ 阶行列式需要约 $n!$ 次运算——$n = 20$ 时就是 $2.4 \times 10^{18}$，即使超级计算机也需要数年！

所以在实际计算中，**Gauss 消元远优于 Cramer 法则**（$O(n^3)$ vs $O(n \cdot n!)$）。Cramer 法则的价值在于理论，不在于计算。

## 2. 稀疏矩阵：现实中的大规模方程组

真实世界中的线性方程组往往有**稀疏矩阵**（sparse matrix）——绝大多数元素为零。例如：

- **电路分析**：每个节点只与少数其他节点相连
- **有限元分析**：网格中每个节点只与相邻节点耦合
- **Google PageRank**：每个网页只链接到少数其他网页

对于稀疏矩阵，有专门的算法利用零元素结构来加速计算，使得百万甚至十亿未知数的方程组都可以高效求解。

### 迭代法

对于非常大的稀疏系统，**直接法**（如 Gauss 消元）可能占用太多内存。**迭代法**（iterative methods）则从一个初始猜测出发，逐步逼近精确解：

- **Jacobi 迭代**：最简单的迭代法
- **Gauss–Seidel 迭代**：Jacobi 的改进
- **共轭梯度法**（Conjugate Gradient）：对对称正定矩阵极其高效
- **GMRES**：对一般矩阵的强大方法

这些方法是**数值线性代数**（numerical linear algebra）的核心内容，是科学计算和工程模拟的基础工具。

## 3. 最小二乘法：当方程组无解时怎么办？

在实际问题中，经常遇到**超定方程组**（overdetermined system）——方程比未知数多，通常无解。例如用 $100$ 个数据点拟合一条直线（$2$ 个参数）。

这时我们不追求精确解，而是追求**"最接近"的解**——使得残差 $\|A\mathbf{x} - \mathbf{b}\|^2$ 最小。这就是**最小二乘法**（least squares method）。

最小二乘解满足**正规方程**（normal equation）：

$$A^T A \mathbf{x} = A^T \mathbf{b}$$

这是一个方阵方程组——可以用 Gauss 消元求解！

最小二乘法在统计学（回归分析）、机器学习（线性回归）、信号处理和物理实验中无处不在。

## 4. 线性方程组与人工智能

深度学习中的神经网络训练本质上是一个优化问题，其中**梯度计算**涉及大量线性代数运算。反向传播算法（backpropagation）可以看作是在"计算图"上反向求解线性方程组。

更直接的联系：

- **线性回归** = 求解正规方程
- **主成分分析（PCA）** = 求解特征值问题（以 Gauss 消元为子步骤）
- **推荐系统** = 矩阵分解（交替使用最小二乘法）
- **自然语言处理** = 词嵌入矩阵的分解和运算

线性代数不仅是人工智能的数学基础——它就是人工智能的**计算引擎**。
