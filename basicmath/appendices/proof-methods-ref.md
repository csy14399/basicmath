# 附录 C：证明方法速查卡（Proof Methods Quick Reference）

本速查卡是[第一部分第 3 章（证明方法）](../part-01-foundations/ch03-proof-methods/README.md)的浓缩参考。遇到需要证明的命题时，快速查阅此卡以选择合适的证明策略。

---

## C.1 直接证明（Direct Proof）

**何时使用**：当你需要证明 $P \to Q$（若 $P$ 则 $Q$）的形式的命题，且从假设 $P$ 出发，可以通过一系列逻辑推导自然地得到 $Q$。

**结构模板**：

$$
\text{假设 } P \text{ 成立} \implies \text{推导步骤}_1 \implies \text{推导步骤}_2 \implies \cdots \implies Q \text{ 成立} \quad \square
$$

> **证明.** 假设 $P$ 成立。[由 $P$ 出发，经过若干推理步骤……] 因此 $Q$ 成立。$\square$

**一句话提示**：假设条件、推出结论——最直截了当的方法，优先尝试。

**详细学习**：[Part 1 Ch03 §1](../part-01-foundations/ch03-proof-methods/01-direct-proof.md)

---

## C.2 反证法（Proof by Contradiction）

**何时使用**：当直接从假设推导结论困难时，尤其适用于证明"不存在"类命题或结论涉及否定性断言的命题（如"$\sqrt{2}$ 是无理数"、"素数有无穷多个"）。

**结构模板**：

$$
\text{假设 } \neg Q \text{ 成立（即结论的否定）} \implies \cdots \implies \text{矛盾！} \implies Q \text{ 必须成立} \quad \square
$$

> **证明（反证法）.** 假设 $Q$ 不成立。[由此出发推导……] 得到矛盾（例如与已知定理矛盾、与假设 $P$ 矛盾、或推出 $0 = 1$）。因此假设错误，$Q$ 成立。$\square$

**一句话提示**：假设结论为假，推导出荒谬——"敌人的敌人是朋友"。

**详细学习**：[Part 1 Ch03 §2](../part-01-foundations/ch03-proof-methods/02-contradiction.md)

---

## C.3 逆否命题证明（Proof by Contrapositive）

**何时使用**：当证明 $P \to Q$ 困难，但从 $\neg Q$ 出发推导 $\neg P$ 更自然时。逻辑上 $P \to Q$ 与 $\neg Q \to \neg P$ 等价。

**结构模板**：

$$
P \to Q \equiv \neg Q \to \neg P
$$

> **证明（逆否命题）.** 我们证明逆否命题：假设 $\neg Q$ 成立。[推导……] 因此 $\neg P$ 成立。由逆否等价性，原命题 $P \to Q$ 成立。$\square$

**一句话提示**：正面走不通，就从结论的否定出发倒推——与反证法不同的是，这里不需要矛盾，只需到达 $\neg P$。

**详细学习**：[Part 1 Ch03 §2](../part-01-foundations/ch03-proof-methods/02-contradiction.md)

## C.4 数学归纳法——弱归纳（Weak / Simple Induction）

**何时使用**：当需要证明某个命题对所有自然数 $n \geq n_0$ 成立时（例如求和公式、不等式、整除性质）。

**结构模板**：

$$
\underbrace{P(n_0)}_{\text{基础步骤}} \quad + \quad \underbrace{\forall k \geq n_0,\; P(k) \to P(k+1)}_{\text{归纳步骤}} \quad \implies \quad \forall n \geq n_0,\; P(n)
$$

> **证明（数学归纳法）.**
>
> **基础步骤**：验证 $P(n_0)$ 成立。[直接计算或检验]
>
> **归纳步骤**：假设 $P(k)$ 对某个 $k \geq n_0$ 成立（**归纳假设**）。我们需要证明 $P(k+1)$ 成立。[利用归纳假设推导……] 因此 $P(k+1)$ 成立。
>
> 由数学归纳法原理，$P(n)$ 对所有 $n \geq n_0$ 成立。$\square$

**一句话提示**：推倒第一块多米诺骨牌，证明每块倒下时能带倒下一块——全部倒下。

**详细学习**：[Part 1 Ch03 §3](../part-01-foundations/ch03-proof-methods/03-induction.md)

---

## C.5 数学归纳法——强归纳（Strong / Complete Induction）

**何时使用**：当归纳步骤中，证明 $P(k+1)$ 需要利用 $P(n_0), P(n_0+1), \ldots, P(k)$ 中的多个（甚至全部）而非仅仅 $P(k)$ 时。典型应用：唯一质因数分解定理。

**结构模板**：

$$
P(n_0) \quad + \quad \forall k \geq n_0,\; \bigl[P(n_0) \wedge P(n_0+1) \wedge \cdots \wedge P(k) \to P(k+1)\bigr] \quad \implies \quad \forall n \geq n_0,\; P(n)
$$

> **证明（强归纳法）.**
>
> **基础步骤**：验证 $P(n_0)$ 成立（可能需验证多个基础情形）。
>
> **归纳步骤**：假设对所有 $n_0 \leq j \leq k$，$P(j)$ 均成立（**强归纳假设**）。证明 $P(k+1)$ 成立。[利用 $P(j)$（$j \leq k$）中所需的任意项推导……]
>
> 由强归纳法原理，$P(n)$ 对所有 $n \geq n_0$ 成立。$\square$

**一句话提示**：弱归纳只看"前一步"，强归纳看"前面所有步"——当一步不够时用强归纳。

**详细学习**：[Part 1 Ch03 §3](../part-01-foundations/ch03-proof-methods/03-induction.md)

## C.6 构造性证明（Constructive Proof）

**何时使用**：当需要证明"存在某个对象满足某性质"（$\exists x,\, P(x)$）时，直接显式地给出（构造出）这样的对象。

**结构模板**：

> **证明.** 取 $x = [\text{具体构造}]$。验证该 $x$ 满足 $P(x)$：[验证步骤……] 因此满足条件的 $x$ 存在。$\square$

**一句话提示**：要证明"存在"，最有力的方式就是直接"拿出来"。

**详细学习**：[Part 1 Ch03 §4](../part-01-foundations/ch03-proof-methods/04-constructive-counterexample.md)

---

## C.7 反例（Counterexample）

**何时使用**：当需要推翻一个全称命题"$\forall x,\, P(x)$"时，只需找到一个使 $P(x)$ 为假的具体 $x$。

**结构模板**：

> **反例.** 取 $x = [\text{具体值}]$。此时 $P(x)$ 不成立，因为 [解释]。因此"$\forall x,\, P(x)$"为假。$\square$

**一句话提示**：一只黑天鹅就够推翻"所有天鹅都是白色的"。

**详细学习**：[Part 1 Ch03 §4](../part-01-foundations/ch03-proof-methods/04-constructive-counterexample.md)

---

## C.8 穷举法/分情况讨论（Proof by Exhaustion / Cases）

**何时使用**：当命题中的对象只有有限多种可能情况时，逐一验证每种情况。也用于将一个复杂命题分解为若干互不相交的子情况。

**结构模板**：

> **证明.** 分以下情况讨论：
>
> **情况 1**：[条件]。[证明此情况下命题成立]
>
> **情况 2**：[条件]。[证明此情况下命题成立]
>
> ……
>
> **情况 $k$**：[条件]。[证明此情况下命题成立]
>
> 以上 $k$ 种情况穷尽了所有可能，因此命题成立。$\square$

**一句话提示**：拆分为若干种情形，各个击破——关键是保证"不遗漏、不重叠"。

**详细学习**：[Part 1 Ch03 §4](../part-01-foundations/ch03-proof-methods/04-constructive-counterexample.md)

---

## C.9 双重包含法（Double Inclusion / Mutual Containment）

**何时使用**：当需要证明两个集合相等 $A = B$ 时。将等式拆为两个子集关系：$A \subseteq B$ 和 $B \subseteq A$。

**结构模板**：

> **证明.** 我们证明 $A = B$，通过双重包含：
>
> **（$\subseteq$）** 设 $x \in A$。[推导……] 因此 $x \in B$，即 $A \subseteq B$。
>
> **（$\supseteq$）** 设 $x \in B$。[推导……] 因此 $x \in A$，即 $B \subseteq A$。
>
> 综合两个方向，$A = B$。$\square$

**一句话提示**：集合等式 = 两个方向的子集关系——"你包含我，我包含你"。

**详细学习**：[Part 1 Ch03 §1](../part-01-foundations/ch03-proof-methods/01-direct-proof.md)

---

## C.10 鸽巢原理（Pigeonhole Principle）

**何时使用**：当需要证明在某种分配中，至少有两个对象落入同一类别。更一般地，$n$ 个对象放入 $k$ 个容器（$n > k$），至少有一个容器包含两个以上的对象。

**结构模板**：

> **证明.** 共有 $n$ 个对象和 $k$ 个容器（$n > k$）。[说明分配方式……] 由鸽巢原理，至少有一个容器包含至少 $\lceil n/k \rceil$ 个对象。[由此推出所需结论]。$\square$

**一句话提示**：$n$ 只鸽子飞进 $k$ 个洞（$n > k$），必有一个洞里至少两只——简单得令人难以置信，威力却极大。

**详细学习**：[Part 1 Ch03 §4](../part-01-foundations/ch03-proof-methods/04-constructive-counterexample.md)

---

## C.11 无穷递降法（Infinite Descent）

**何时使用**：当需要证明某种正整数解不存在时。假设存在最小的正整数解，然后推导出一个更小的正整数解，产生矛盾（因为正整数不能无限减小）。本质上是反证法与自然数良序性的结合。

**结构模板**：

> **证明（无穷递降法）.** 假设存在满足条件的正整数解。在所有这样的解中，取最小的一组 $(a, b, \ldots)$（良序性保证最小元存在）。[由此构造出一组更小的正整数解 $(a', b', \ldots)$，满足 $a' < a$（或类似的"更小"关系）]。但这与 $(a, b, \ldots)$ 是最小解矛盾。因此满足条件的正整数解不存在。$\square$

**一句话提示**：假设有最小的正整数解，再造一个更小的——"最小"被打破，假设崩塌。

**详细学习**：[Part 1 Ch03 §3](../part-01-foundations/ch03-proof-methods/03-induction.md)

## C.12 证明方法选择决策流程图

面对一个需要证明的命题，以下文字流程图帮助你选择最合适的证明方法：

```
你要证明什么类型的命题？
│
├─ 形如 "P → Q"（若…则…）
│   │
│   ├─ 从 P 出发能自然推到 Q 吗？
│   │   ├─ 是 → 【直接证明】(C.1)
│   │   └─ 否 → 从 ¬Q 出发能推到 ¬P 吗？
│   │       ├─ 是 → 【逆否命题证明】(C.3)
│   │       └─ 否 → 【反证法】(C.2)
│   │
│   └─ P 和 Q 涉及自然数的性质吗？
│       ├─ 是，且结论是 "对所有 n ≥ n₀"
│       │   ├─ 归纳步骤只需 P(k) → P(k+1)？ → 【弱归纳】(C.4)
│       │   └─ 归纳步骤需要 P(j), j ≤ k？ → 【强归纳】(C.5)
│       └─ 否 → 继续用上面的判断
│
├─ 形如 "∃x, P(x)"（存在…使得…）
│   │
│   ├─ 能直接给出具体的 x 吗？
│   │   ├─ 是 → 【构造性证明】(C.6)
│   │   └─ 否 → 【反证法】(C.2)：假设不存在，推出矛盾
│   │
│   └─ 只需证明至少两个对象"重合"或"相同"？
│       └─ 【鸽巢原理】(C.10)
│
├─ 形如 "∀x, P(x) 为假"（推翻全称命题）
│   └─ 【反例】(C.7)：找一个 x 使 P(x) 为假
│
├─ 形如 "A = B"（两个集合相等）
│   └─ 【双重包含法】(C.9)：证明 A ⊆ B 且 B ⊆ A
│
├─ 形如 "不存在正整数解"
│   └─ 【无穷递降法】(C.11)
│
├─ 对象只有有限多种情况？
│   └─ 【穷举法/分情况讨论】(C.8)
│
└─ 以上都不匹配？
    ├─ 尝试回忆类似定理的证明方法
    ├─ 尝试画图、算几个特例寻找线索
    └─ 重新审视命题结构：能否将其转化为上述形式之一？
```

## C.13 常见错误提醒

| 错误类型 | 说明 |
|----------|------|
| 验证代替证明 | 验证了几个例子不等于证明了全称命题。$P(1), P(2), P(3)$ 全为真不能说明 $P(n)$ 对所有 $n$ 为真。 |
| 循环论证 | 在证明过程中使用了尚未证明的结论（假设了你要证明的东西）。 |
| 归纳法忘记基础步骤 | 没有基础步骤的归纳法是无效的。经典反例：试图证明"所有马同色"。 |
| 混淆逆命题与逆否命题 | $P \to Q$ 的逆命题 $Q \to P$ 与原命题不等价。逆否命题 $\neg Q \to \neg P$ 才与原命题等价。 |
| 反证法中矛盾不清 | 反证法要求明确指出矛盾所在——"与……矛盾"中的"……"必须是明确的已知事实。 |
| 分情况讨论不完备 | 必须确保所有情况被穷尽，否则证明不完整。 |
