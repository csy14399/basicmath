# 第 5 章：向量几何（Vector Geometry）

## 章概览

**向量**是同时具有大小和方向的量。风速、力、位移——这些物理量都天然地用向量描述。但向量远不止是物理学的工具：它是连接几何与代数的桥梁。有了向量语言，前几章中用坐标或综合方法"费力"证明的几何定理，往往可以用三五行代数运算优雅地完成。

本章从向量的基本定义和运算出发，系统学习**点积**（dot product）和**叉积**（cross product），并展示它们在几何问题中的强大应用。向量不仅是几何的语言，更是通往**线性代数**（Part 9）的大门——向量空间的概念将把我们从具体的 $\mathbb{R}^2$, $\mathbb{R}^3$ 带入一般的抽象空间。

## 学习成果

本章完成后你将能够：

- **理解向量的几何意义**：大小 + 方向，位置向量与自由向量的区别
- **熟练进行向量运算**：加法、标量乘法、线性组合
- **计算和应用点积**：求向量长度、夹角、正交性判定、投影
- **计算和应用叉积**（3D）：求法向量、平行四边形面积、三角形面积
- **理解混合积**：求平行六面体体积
- **用向量方法解决几何问题**：点到直线距离、面积计算、共线和共面判定
