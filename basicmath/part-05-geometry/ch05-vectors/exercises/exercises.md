# 第 5 章 向量几何 — 练习题

## §1 向量基础

1. ★☆☆ 设 $\vec{u} = (3, -1, 2)$, $\vec{v} = (-2, 4, 1)$。求 $\vec{u} + \vec{v}$, $\vec{u} - \vec{v}$, $3\vec{u} - 2\vec{v}$。

2. ★☆☆ 求 $\vec{v} = (1, -2, 2)$ 的模和单位向量。

3. ★☆☆ 设 $A(3, 1, -2)$, $B(1, -1, 4)$。求 $\overrightarrow{AB}$, $|\overrightarrow{AB}|$, 以及 $AB$ 的中点坐标。

4. ★★☆ 判断 $\vec{u} = (2, -6, 4)$ 和 $\vec{v} = (-3, 9, -6)$ 是否平行。

5. ★★☆ 将 $\vec{w} = (5, 7)$ 表示为 $\vec{u} = (1, 2)$ 和 $\vec{v} = (3, 1)$ 的线性组合。

6. ★★☆ 设 $A(1, 0, 0)$, $B(0, 2, 0)$, $C(0, 0, 3)$。求 $\triangle ABC$ 的重心和各边中点。

7. ★★☆ 点 $P$ 将线段 $AB$ 按 $2:3$ 内分。$A = (1, 5)$, $B = (6, 0)$。求 $P$ 的坐标。

8. ★★★ 用向量方法证明：平行四边形的对角线互相平分。

---

## §2 点积

1. ★☆☆ 求 $\vec{u} = (1, 3, -2)$ 和 $\vec{v} = (4, -1, 5)$ 的点积。

2. ★☆☆ 求 $\vec{u} = (2, 1)$ 和 $\vec{v} = (-1, 2)$ 的夹角。

3. ★★☆ 将 $\vec{u} = (4, 3)$ 投影到 $\vec{v} = (1, 0)$ 上。求标量投影和向量投影。

4. ★★☆ 将 $\vec{u} = (1, 2, 3)$ 投影到 $\vec{v} = (1, 1, 1)$ 上。求正交分解。

5. ★★☆ 求一个与 $\vec{u} = (1, 2, -3)$ 和 $\vec{v} = (2, -1, 0)$ 都正交的单位向量。

6. ★★☆ 力 $\vec{F} = (2, 5, -1)$ 使物体从 $A(1, 0, 3)$ 移到 $B(3, 4, 1)$。求功。

7. ★★☆ 求点 $(2, 3)$ 到直线 $3x + 4y - 5 = 0$ 的距离。用向量投影方法验证。

8. ★★★ 用向量方法证明：三角形内角之和等于 $180°$。（提示：设三边向量，用点积表示各角的余弦。）

9. ★★★ 设 $|\vec{u}| = 3$, $|\vec{v}| = 5$, $\vec{u} \cdot \vec{v} = -7$。求 $|2\vec{u} - \vec{v}|$。

10. ★★★ 证明平行四边形定律：$|\vec{u} + \vec{v}|^2 + |\vec{u} - \vec{v}|^2 = 2(|\vec{u}|^2 + |\vec{v}|^2)$。

## §3 叉积与混合积

1. ★☆☆ 求 $\vec{u} = (1, 0, 0)$ 和 $\vec{v} = (0, 1, 0)$ 的叉积。

2. ★☆☆ 求 $\vec{u} = (2, 3, 1)$ 和 $\vec{v} = (1, -1, 2)$ 的叉积。

3. ★★☆ 求三角形面积，顶点为 $A(1, 1, 0)$, $B(2, 0, 1)$, $C(0, 2, 1)$。

4. ★★☆ 求过三点 $A(1, 1, 1)$, $B(2, 3, 1)$, $C(3, 1, 2)$ 的平面方程。

5. ★★☆ 求 $\vec{u} = (1, 2, 3)$, $\vec{v} = (4, 5, 6)$, $\vec{w} = (7, 8, 9)$ 的混合积。这三个向量共面吗？

6. ★★☆ 验证 Lagrange 恒等式：对 $\vec{u} = (1, 2, 0)$, $\vec{v} = (3, 0, -1)$ 验证 $|\vec{u}\times\vec{v}|^2 = |\vec{u}|^2|\vec{v}|^2 - (\vec{u}\cdot\vec{v})^2$。

7. ★★★ 证明四面体 $ABCD$ 的体积公式：$V = \frac{1}{6}|\overrightarrow{AB} \cdot (\overrightarrow{AC} \times \overrightarrow{AD})|$。

8. ★★★ 设 $\vec{u} \times \vec{v} = (2, -1, 3)$ 且 $\vec{u} \cdot \vec{v} = 4$。$|\vec{u}| = 2$。求 $|\vec{v}|$。

9. ★★★ 求两条异面直线之间的距离。直线 1 过 $A(1,0,0)$ 方向 $\vec{d}_1 = (1,1,0)$，直线 2 过 $B(0,1,0)$ 方向 $\vec{d}_2 = (0,1,1)$。

10. ★★★ 证明：$\vec{u} \times (\vec{v} \times \vec{w}) = (\vec{u} \cdot \vec{w})\vec{v} - (\vec{u} \cdot \vec{v})\vec{w}$（向量三重积，BAC-CAB 公式）。
