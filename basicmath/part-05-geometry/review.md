## 1. 两条路径看几何

### 1.1 综合方法 vs 解析方法

Part 5 的核心叙事是**两种几何方法的对话**：

| | 综合方法（synthetic） | 解析方法（analytic） |
|--|---------------------|---------------------|
| 代表 | Euclid（Ch01） | Descartes（Ch02–Ch03） |
| 工具 | 公理、公设、逻辑推演 | 坐标、方程、代数计算 |
| 优势 | 几何直觉、结构美 | 计算力、普适性 |
| 典型问题 | "证明两角相等" | "求交点坐标" |

**变换方法**（Ch04）和**向量方法**（Ch05）则是第三、四条路径——它们融合了综合方法的几何直觉和解析方法的计算效率。


## 3. 同一个问题的多种方法

Part 5 的一个重要主题是：**同一个几何问题可以用不同的方法解决**。

### 3.1 例：证明三角形中线交于一点

| 方法 | 核心思路 | 优劣 |
|------|---------|------|
| 综合法（Ch01） | 用 Ceva 定理或面积比 | 需要辅助定理，但逻辑优美 |
| 坐标法（Ch02） | 设坐标，解方程组 | 计算直接但可能繁琐 |
| 向量法（Ch05） | $G = \frac{\vec{a}+\vec{b}+\vec{c}}{3}$ | 最简洁、最自然 |

### 3.2 例：求三角形面积

| 方法 | 公式 | 适用场景 |
|------|------|---------|
| 底 × 高 | $\frac{1}{2}bh$ | 已知底和高 |
| 坐标公式 | 行列式 | 2D 坐标已知 |
| Heron 公式 | $\sqrt{s(s-a)(s-b)(s-c)}$ | 只知三边长 |
| 叉积 | $\frac{1}{2}\|\overrightarrow{AB}\times\overrightarrow{AC}\|$ | 3D 坐标，最通用 |
| 正弦公式 | $\frac{1}{2}ab\sin C$ | 知两边和夹角 |

**优秀的几何思维者能在不同方法之间自如切换，选择最适合当前问题的工具。**

## 4. 核心定理索引

### Ch01 欧氏几何

| 定理 | 内容 |
|------|------|
| 三角形全等条件 | SSS, SAS, ASA, AAS |
| 三角形相似条件 | AA, SAS, SSS |
| 圆周角定理 | 同弧圆周角等于圆心角的一半 |
| 圆幂定理 | $PA \cdot PB = PC \cdot PD$ |
| Ptolemy 定理 | $AC \cdot BD = AB \cdot CD + AD \cdot BC$ |

### Ch02 解析几何

| 定理 | 内容 |
|------|------|
| 两直线平行 | $m_1 = m_2$ |
| 两直线垂直 | $m_1 \cdot m_2 = -1$ |
| 点到直线距离 | $d = \frac{\|ax_0+by_0+c\|}{\sqrt{a^2+b^2}}$ |

### Ch03 圆锥曲线

| 定理 | 内容 |
|------|------|
| 焦点-准线统一 | $\frac{PF}{d(P,\ell)} = e$：$e<1$ 椭圆，$e=1$ 抛物线，$e>1$ 双曲线 |
| 判别式分类 | $B^2-4AC$：$<0$ 椭圆，$=0$ 抛物线，$>0$ 双曲线 |
| 光学反射性质 | 椭圆：两焦点等角反射；抛物线：平行光汇聚到焦点 |

### Ch04 变换几何

| 定理 | 内容 |
|------|------|
| 等距变换分类 | 平移、旋转、反射、滑移反射（共四种） |
| 两次反射定理 | 平行线反射 = 平移，相交线反射 = 旋转 |
| 变换群 | 等距变换在复合下构成欧氏群 $E(2)$ |
| Erlangen 纲领 | 几何 = 变换群下不变量的研究 |

### Ch05 向量几何

| 定理 | 内容 |
|------|------|
| 点积几何形式 | $\vec{u}\cdot\vec{v} = \|\vec{u}\|\|\vec{v}\|\cos\theta$ |
| 正交性 | $\vec{u}\perp\vec{v} \iff \vec{u}\cdot\vec{v} = 0$ |
| Lagrange 恒等式 | $\|\vec{u}\times\vec{v}\|^2 = \|\vec{u}\|^2\|\vec{v}\|^2 - (\vec{u}\cdot\vec{v})^2$ |
| 混合积 = 体积 | $V_{\text{平行六面体}} = \|\vec{u}\cdot(\vec{v}\times\vec{w})\|$ |

## 7. 向量——几何与线性代数的桥梁

Part 5 最重要的"出口"是 Ch05 的向量。向量不仅是解决几何问题的工具，更是通往 Part 9（线性代数）的桥梁：

```
Part 5 几何                    Part 9 线性代数
─────────                    ──────────────
向量 (v₁, v₂, v₃)      →    一般向量空间 V
标准基 i, j, k           →    一般基和维度
线性组合                 →    张成空间、线性无关
点积                     →    内积空间
投影                     →    正交投影、Gram-Schmidt
叉积/混合积 = 行列式     →    n × n 行列式
旋转矩阵                 →    正交矩阵
变换的复合               →    矩阵乘法
保距性 (det = ±1)        →    行列式的几何意义
```

Part 5 提供了具体的几何直觉；Part 9 将把这些直觉提升为适用于任意维度的抽象理论。

## 10. Part 6 预览

Part 6（分析基础 / Analysis Preparation）将引入数学分析的核心概念——**极限、连续性和微积分初步**。几何为分析提供了丰富的直觉：

- **曲线的切线**（极限的几何动机）：圆锥曲线的切线问题直接引出导数
- **面积和体积**（积分的几何动机）：Ch01 的 Cavalieri 原理是积分思想的先声
- **弧长和曲率**：参数曲线的长度需要积分来计算
- **$\varepsilon$-$\delta$ 语言**：距离（向量的模）为极限的严格定义提供几何直觉

从 Part 5 到 Part 6 的过渡是从"静态几何"到"动态分析"的过渡——几何告诉你图形**是什么**，分析告诉你图形**如何变化**。
