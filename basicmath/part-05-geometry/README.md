# 第五部分：几何（Geometry）

## 本部分概览

几何是数学中最古老、最直观的分支——它研究的是**形状、空间与度量**。从古埃及的土地测量到古希腊的逻辑演绎，从笛卡尔的坐标革命到现代的变换群理论，几何的发展史就是数学思想不断进化的缩影。

如果说第一部分建立了逻辑框架，第二部分认识了数的世界，第三部分掌握了代数工具，第四部分研究了函数家族，那么第五部分要做的就是**用综合方法和解析方法两条路径来研究几何对象**。这里，直觉与严格并行：你既需要"看到"图形的性质，也需要用公理和代数来"证明"它。

本部分的叙事线如下：

1. **欧氏几何**——从公理出发，用纯粹的逻辑推演研究三角形、圆、面积与体积
2. **解析几何**——引入坐标，用代数方程描述几何对象
3. **圆锥曲线**——椭圆、双曲线、抛物线的统一理论
4. **几何变换**——平移、旋转、反射、缩放——从运动的角度理解几何
5. **向量几何**——用向量语言简洁地表达几何关系

本部分包含五章：

| 章 | 主题 | 内容 |
|----|------|------|
| [第 1 章：欧氏几何](ch01-euclidean/README.md) | 欧氏几何（Euclidean geometry） | 公理化方法、三角形（全等、相似、五心）、圆（圆周角、切线、幂）、面积与体积 |
| [第 2 章：解析几何](ch02-analytic/README.md) | 解析几何（analytic geometry） | 坐标系与直线、圆的方程 |
| [第 3 章：圆锥曲线](ch03-conics/README.md) | 圆锥曲线（conic sections） | 椭圆、双曲线、抛物线、统一定义与分类 |
| [第 4 章：几何变换](ch04-transformations/README.md) | 几何变换（geometric transformations） | 平移、旋转、反射、缩放、等距变换与相似变换 |
| [第 5 章：向量几何](ch05-vectors/README.md) | 向量几何（vector geometry） | 向量运算、点积、叉积、向量在几何中的应用 |

这五章的关系：第一章用综合方法（synthetic approach）建立几何的基本定理，不依赖坐标。第二章引入坐标系，将几何问题代数化——这是笛卡尔的伟大革命。第三章深入研究二次曲线（圆锥曲线），是解析几何的核心应用。第四章从变换的角度重新审视几何——Felix Klein 的 Erlangen 纲领认为"几何就是研究在某一变换群下不变的性质"。第五章用向量语言统一前面的结果，为线性代数（Part 9）做准备。

## 本部分的主题：综合与解析的双重视角

贯穿本部分的核心思想是**两种几何方法的对话**：

1. **综合方法**（Ch01）：不用坐标，直接从公理和已知定理推演——这是 Euclid 的方法，强调逻辑美和结构性。
2. **解析方法**（Ch02–Ch03）：引入坐标，把几何变成代数——这是 Descartes 的方法，强调计算力和普适性。
3. **变换视角**（Ch04）：几何不是关于"固定的图形"，而是关于"图形在运动中保持什么不变"——这是 Klein 的方法，揭示几何的深层结构。
4. **向量语言**（Ch05）：用向量统一前面的方法——既有综合方法的几何直觉，又有解析方法的计算效率。

这四种视角不是竞争关系，而是互补关系。优秀的几何思维者能在不同视角之间自如切换，选择最适合当前问题的工具。
