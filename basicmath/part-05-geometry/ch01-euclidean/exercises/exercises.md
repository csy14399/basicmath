# 第 1 章 欧氏几何 — 练习题

## §1 公理化方法（The Axiomatic Method）

1. ★☆☆ 列出 Euclid 的五条公设。哪一条与其他四条有本质不同？说明原因。

2. ★☆☆ 解释什么是"未定义术语"。为什么公理系统需要未定义术语？

3. ★☆☆ Playfair 公理的内容是什么？它与 Euclid 的第五公设有什么关系？

4. ★★☆ 解释一致性、独立性、完备性的含义。一个公理系统中，哪个性质是最基本的（即没有它整个系统就毫无意义）？

5. ★★☆ 在球面几何中（"直线"= 大圆），过一条"直线"外一点，可以引多少条"平行线"？这说明什么？

6. ★★☆ 如果有人声称"证明"了第五公设可以从前四条公设推出，你如何反驳？

7. ★★★ 以下命题哪些在欧氏几何中成立但在球面几何中不成立？
   (a) 两点确定一条直线
   (b) 三角形内角和为 $180°$
   (c) 存在平行线
   (d) 所有直角相等

## §2 三角形（Triangles）

1. ★☆☆ 在 $\triangle ABC$ 和 $\triangle DEF$ 中，$AB = DE = 5$，$BC = EF = 7$，$\angle B = \angle E = 60°$。证明 $\triangle ABC \cong \triangle DEF$。指出使用的全等条件。

2. ★☆☆ $\triangle ABC$ 中 $a = 8$, $b = 15$, $c = 17$。判断三角形类型（锐角/直角/钝角），并求面积。

3. ★☆☆ 求三角形三边为 $a = 13$, $b = 14$, $c = 15$ 的面积（用 Heron 公式）。

4. ★★☆ 在 $\triangle ABC$ 中，$\angle A = 36°$，$\angle B = 72°$。求 $\angle C$。证明 $\triangle ABC$ 是等腰三角形（指出哪两边相等）。

5. ★★☆ 证明：等边三角形的三条高线、三条中线、三条角平分线重合（每条线既是高线，也是中线，也是角平分线）。

6. ★★☆ $\triangle ABC$ 中，$\angle A$ 的角平分线交 $BC$ 于 $D$。已知 $AB = 10$，$AC = 6$，$BC = 8$。求 $BD$ 和 $DC$。

7. ★★☆ 证明：三角形任意一边的长度小于另外两边之和（三角不等式）。

8. ★★☆ $\triangle ABC$ 中，$D$ 和 $E$ 分别是 $AB$ 和 $AC$ 上的点，$DE \parallel BC$，$AD = 3$，$DB = 6$。若 $BC = 12$，求 $DE$。

9. ★★★ 证明中位线定理：三角形的中位线（连接两边中点的线段）平行于第三边且等于第三边的一半。

10. ★★★ 证明 Euler 线的存在：重心 $G$、外心 $O$、垂心 $H$ 共线。（提示：设 $M$ 是 $BC$ 的中点，证明 $O$, $G$, $H$ 在中线 $AM$ 上满足适当的比例关系。）

11. ★★★ 设 $\triangle ABC$ 的面积为 $S$，半周长为 $s$，内切圆半径为 $r$。证明 $S = rs$。

12. ★★☆ 在 $\triangle ABC$ 中，$AB = AC = 10$，$BC = 12$。求：
    (a) 面积
    (b) 外接圆半径 $R$（提示：正弦定理 $\frac{a}{\sin A} = 2R$）
    (c) 内切圆半径 $r$

## §3 圆（Circles）

1. ★☆☆ 在 $\odot O$ 中，弦 $AB$ 的圆心角为 $120°$。求弧 $AB$（优弧上）的圆周角。

2. ★☆☆ $\triangle ABC$ 内接于 $\odot O$，$\angle B = 40°$，$\angle C = 55°$。求 $\angle A$ 和弧 $BC$ 的圆心角。

3. ★★☆ $\odot O$ 半径为 $5$，弦 $AB = 6$。求圆心 $O$ 到弦 $AB$ 的距离。

4. ★★☆ 证明：若两条弦在圆中相等，则它们到圆心的距离相等。

5. ★★☆ 在 $\odot O$ 中，两条弦 $AB$ 和 $CD$ 交于点 $P$。$PA = 4$，$PB = 6$，$PC = 3$。求 $PD$。

6. ★★☆ 从圆外一点 $P$ 引两条割线，分别交圆于 $A, B$ 和 $C, D$（$A$ 和 $C$ 分别在 $P$ 与 $B$, $D$ 之间）。$PA = 3$，$PB = 12$，$PC = 4$。求 $PD$。

7. ★★☆ 从圆外一点 $P$ 引切线 $PT$（$T$ 为切点）和割线 $PAB$。已知 $PT = 8$，$PA = 4$。求弦 $AB$ 的长度。

8. ★★☆ 圆内接四边形 $ABCD$ 中，$\angle A = 80°$，$\angle B = 100°$。求 $\angle C$ 和 $\angle D$。

9. ★★★ 证明弦切角定理：切线与弦所成的角等于弦所对弧上的圆周角。

10. ★★★ 圆内接四边形 $ABCD$ 的边长分别为 $AB = 3$, $BC = 4$, $CD = 5$, $DA = 6$，对角线为 $AC$ 和 $BD$。利用 Ptolemy 定理建立 $AC$ 和 $BD$ 的一个关系。

11. ★★★ 证明：圆的切线长等于从外部点到切点的距离，且从同一外部点引的两条切线长相等。（从头开始证明，不引用前面的定理。）

## §4 面积与体积（Area and Volume）

1. ★☆☆ 计算以下图形的面积：
   (a) 底 $12$，高 $5$ 的平行四边形
   (b) 上底 $4$，下底 $10$，高 $6$ 的梯形
   (c) 半径 $7$ 的圆

2. ★☆☆ 计算以下立体的体积：
   (a) 底面积 $20$，高 $8$ 的棱柱
   (b) 底面半径 $3$，高 $10$ 的圆柱
   (c) 底面半径 $4$，高 $9$ 的圆锥

3. ★☆☆ 半径为 $6$ 的球的体积和表面积是多少？

4. ★★☆ 一个圆锥的体积为 $48\pi$，底面半径为 $4$。求其高。

5. ★★☆ 用 Cavalieri 原理解释为什么底面积和高都相同的三棱柱和三棱锥的体积之比为 $3:1$。

6. ★★☆ 正六面体（立方体）边长为 $a$。验证 Euler 公式 $V - E + F = 2$。计算其体积和表面积。

7. ★★☆ 一个半球（半径 $r$），在距底面高度 $t$ 处的截面面积是多少？推导并验证半球体积 $= \frac{2}{3}\pi r^3$。

8. ★★★ 证明：如果一个锥体的高为 $h$，底面积为 $A$，则在距顶点高度 $t$（$0 \leq t \leq h$）处的截面积为 $A \cdot \left(\frac{t}{h}\right)^2$。

9. ★★★ 正四面体边长为 $a$。求其体积和表面积。

10. ★★★ 正十二面体有多少条边和多少个顶点？验证 Euler 公式。
