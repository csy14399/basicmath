# 第 1 章 欧氏几何 — 挑战题（Challenge Problems）

以下挑战题综合运用欧氏几何的知识，难度超出常规练习。

---

## 挑战题 1：Morley 定理

> **定理**（Morley's theorem）
>
> 任意三角形的三个内角的三等分线的相邻交点构成一个正三角形。

**题目**：验证 Morley 定理对于等边三角形成立（这是平凡的），然后考虑 $30°$-$60°$-$90°$ 直角三角形的情况。

### 提示

对于等边三角形，所有角为 $60°$，三等分线将每角分为三个 $20°$ 角。利用对称性论证内三角形必然是正三角形。

### 解答

**等边三角形情况**：

三角形 $\triangle ABC$ 等边，$\angle A = \angle B = \angle C = 60°$。每个角被三等分为 $20°$。由三重旋转对称性（绕中心旋转 $120°$），三等分线的相邻交点构成的三角形具有三重对称性，因此是正三角形。✓

**$30°$-$60°$-$90°$ 三角形情况**：

设 $\angle A = 30°$（三等分为 $10°$），$\angle B = 60°$（三等分为 $20°$），$\angle C = 90°$（三等分为 $30°$）。

$\angle A$ 的三等分线将 $\angle A$ 分为三个 $10°$ 角，$\angle B$ 的三等分线分为三个 $20°$ 角，$\angle C$ 的分为三个 $30°$ 角。

取相邻三等分线的交点 $P$, $Q$, $R$（$P$ 是靠近 $AB$ 边的 $A$ 和 $B$ 的三等分线交点，$Q$ 是靠近 $BC$ 边的 $B$ 和 $C$ 的交点，$R$ 是靠近 $CA$ 边的 $C$ 和 $A$ 的交点）。

Morley 定理保证 $\triangle PQR$ 是正三角形，无论原三角形如何。完整证明相当复杂（涉及三角恒等式），这里只验证定理的陈述。

Morley 定理的一个著名证明（John Conway 的"后向证明"）是从正三角形 $\triangle PQR$ 出发，在外围构造出原三角形，从而证明任何三角形都有这个性质。

## 挑战题 2：Euler 不等式

证明：对任意三角形，外接圆半径 $R$ 和内切圆半径 $r$ 满足

$$R \geq 2r$$

等号当且仅当三角形是等边三角形。

### 提示

利用 $S = \frac{abc}{4R}$，$S = rs$，$s = \frac{a+b+c}{2}$ 和 AM-GM 不等式。

### 解答

由 $S = \frac{abc}{4R}$ 和 $S = rs$：

$$rs = \frac{abc}{4R}, \quad R = \frac{abc}{4rs} = \frac{abc}{4S \cdot \frac{S}{s}} = \frac{abc \cdot s}{4S^2}$$

等价地，需要证 $\frac{abc}{4S} \geq 2 \cdot \frac{S}{s}$，即 $\frac{abc \cdot s}{4S^2} \geq 2$，即 $abc \cdot s \geq 8S^2$。

用 Heron 公式 $S^2 = s(s-a)(s-b)(s-c)$，需要证

$$abc \cdot s \geq 8s(s-a)(s-b)(s-c)$$

$$abc \geq 8(s-a)(s-b)(s-c)$$

令 $x = s - a$，$y = s - b$，$z = s - c$（$x, y, z > 0$）。则 $a = y + z$，$b = x + z$，$c = x + y$。

需要证 $(y+z)(x+z)(x+y) \geq 8xyz$。

由 AM-GM 不等式：$y + z \geq 2\sqrt{yz}$，$x + z \geq 2\sqrt{xz}$，$x + y \geq 2\sqrt{xy}$。

三式相乘：$(y+z)(x+z)(x+y) \geq 8\sqrt{x^2y^2z^2} = 8xyz$。$\blacksquare$

等号条件：$x = y = z$，即 $s - a = s - b = s - c$，即 $a = b = c$（等边三角形）。

## 挑战题 3：正十七边形的可构造性

Gauss 在 19 岁时（1796 年）证明了正十七边形可以用尺规作图构造。这一发现与他对分圆多项式和 Fermat 素数的研究密切相关。

**题目**：
(a) 验证 $17$ 是 Fermat 素数（形如 $2^{2^n} + 1$ 的素数）。
(b) Gauss 证明了：正 $n$ 边形可以用尺规作图，当且仅当 $n = 2^k \cdot p_1 p_2 \cdots p_m$，其中 $k \geq 0$，$p_i$ 是互不相同的 Fermat 素数。利用此定理，判断哪些正 $n$ 边形（$n = 3, 4, 5, 6, 7, 8, 9, 10, 12, 15, 17, 20$）可以尺规作图。
(c) 已知的 Fermat 素数有哪些？下一个可以尺规作图的正奇数边形是哪个？

### 解答

**(a)** $17 = 2^{2^2} + 1 = 2^4 + 1 = 16 + 1 = 17$。✓ 它是素数（只能被 $1$ 和 $17$ 整除）。因此 $17$ 是 Fermat 素数（$n = 2$）。

**(b)** 已知 Fermat 素数：$F_0 = 3$，$F_1 = 5$，$F_2 = 17$，$F_3 = 257$，$F_4 = 65537$。

| $n$ | 分解 | 可构造？ |
|-----|------|----------|
| 3 | $3$（Fermat 素数） | ✓ |
| 4 | $2^2$ | ✓ |
| 5 | $5$（Fermat 素数） | ✓ |
| 6 | $2 \times 3$ | ✓ |
| 7 | $7$（不是 Fermat 素数） | ✗ |
| 8 | $2^3$ | ✓ |
| 9 | $3^2$（Fermat 素数重复） | ✗ |
| 10 | $2 \times 5$ | ✓ |
| 12 | $2^2 \times 3$ | ✓ |
| 15 | $3 \times 5$ | ✓ |
| 17 | $17$（Fermat 素数） | ✓ |
| 20 | $2^2 \times 5$ | ✓ |

**(c)** 已知的 Fermat 素数只有五个：$3, 5, 17, 257, 65537$（$F_0$ 到 $F_4$）。$F_5 = 2^{32} + 1 = 4294967297 = 641 \times 6700417$，不是素数。截至目前，没有发现更多的 Fermat 素数。

下一个可以尺规作图的正奇数边形（在 $17$ 之后）：$n = 3 \times 17 = 51$，或 $n = 5 \times 17 = 85$，或 $n = 257$（下一个 Fermat 素数）。最小的是 $n = 51$。但如果问的是正素数边形，则是 $n = 257$。
