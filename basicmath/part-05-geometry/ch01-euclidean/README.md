# 第 1 章：欧氏几何（Euclidean Geometry）

## 章概览

欧氏几何是人类历史上第一个完整的公理化理论体系。公元前 300 年左右，Euclid 在《几何原本》（*Elements*）中以五条公设为起点，通过纯粹的逻辑推演，建立了关于点、线、面的庞大定理网络。这种"从少数自明真理出发推导一切"的方法——**公理化方法**——不仅塑造了几何学，更深刻影响了整个数学乃至科学的思维方式。

本章从公理化方法出发，系统研究平面几何中最核心的对象：三角形与圆，最后拓展到面积与体积的计算。我们既重视几何直觉——"看到"图形的性质，也重视逻辑严格——"证明"这些性质为什么成立。

## 前置知识

- **Part 1 第 1 章（逻辑）**：命题逻辑、逻辑联结词——理解公理和定理的逻辑结构
- **Part 1 第 3 章（证明方法）**：直接证明、反证法——几何证明的核心工具
- **Part 2 第 1 章（数系）**：实数的基本性质——度量和计算的基础

## 学习成果

本章完成后你将能够：

- **理解公理化方法的精髓**：什么是公理、公设、定理，以及它们之间的逻辑关系
- **证明三角形全等与相似**：熟练运用 SSS, SAS, ASA, AAS, AA 等判定条件
- **分析三角形的特殊点与线**：中线、高线、角平分线，以及五心（重心、外心、内心、垂心、旁心）
- **掌握圆的核心定理**：圆周角定理、圆幂定理、Ptolemy 定理
- **推导面积与体积公式**：从基本原理出发理解（而非仅仅记忆）各种面积和体积公式
- **认识正多面体**：知道为什么恰好只有五种正多面体
