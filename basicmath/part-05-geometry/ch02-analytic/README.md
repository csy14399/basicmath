# 第 2 章：解析几何（Analytic Geometry）

## 章概览

解析几何是 René Descartes 在 1637 年开创的革命性方法——**用代数来研究几何**。核心思想是引入**坐标系**，将平面上的每个点用一对数 $(x, y)$ 表示，将几何图形（直线、圆、曲线）用代数方程来描述。这样，几何问题就被翻译成代数问题，可以用方程、不等式、公式来求解。

本章建立坐标系下的直线理论和圆的方程，为下一章（圆锥曲线）打下基础。解析几何不仅是一种计算工具，更代表了一种思维方式——**几何与代数的统一**。

- **判定两直线的平行与垂直关系**
- **计算点到直线的距离和两直线的夹角**
- **写出圆的标准方程和一般方程**
- **分析直线与圆的位置关系**
- **求圆的切线方程**
