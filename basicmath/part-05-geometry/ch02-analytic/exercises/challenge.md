## 挑战题 1：最短路径问题（反射原理）

在 $x$ 轴上方有两个点 $A(1, 3)$ 和 $B(5, 7)$。在 $x$ 轴上找一个点 $P$，使得 $|AP| + |PB|$ 最小。

### 提示

将 $A$ 关于 $x$ 轴做对称点 $A'$，则 $|AP| = |A'P|$。最短路径是 $A'B$ 的直线段与 $x$ 轴的交点。

### 解答

$A(1, 3)$ 关于 $x$ 轴的对称点 $A' = (1, -3)$。

对于 $x$ 轴上的任意点 $P$，$|AP| = |A'P|$（反射对称性）。因此

$$|AP| + |PB| = |A'P| + |PB| \geq |A'B|$$

等号成立当且仅当 $P$ 在线段 $A'B$ 上。

$|A'B| = \sqrt{(5-1)^2 + (7-(-3))^2} = \sqrt{16 + 100} = \sqrt{116} = 2\sqrt{29}$。

$A'B$ 的直线方程：$\frac{y - (-3)}{7 - (-3)} = \frac{x - 1}{5 - 1}$，即 $\frac{y + 3}{10} = \frac{x - 1}{4}$。

令 $y = 0$：$\frac{3}{10} = \frac{x-1}{4}$，$x = 1 + \frac{12}{10} = \frac{22}{10} = \frac{11}{5}$。

因此 $P = \left(\frac{11}{5}, 0\right)$，最小距离 $= 2\sqrt{29}$。

**注**：这个"反射原理"在物理光学中对应**反射定律**——光线从 $A$ 射到镜面（$x$ 轴）再反射到 $B$，走的是最短路径（Fermat 原理）。入射角等于反射角。

## 挑战题 2：Apollonius 圆

设 $A(0, 0)$，$B(6, 0)$。点 $P$ 满足 $\frac{|PA|}{|PB|} = 2$。证明 $P$ 的轨迹是一个圆，并求圆心和半径。

### 解答

设 $P(x, y)$。条件 $|PA| = 2|PB|$ 两边平方：

$$x^2 + y^2 = 4[(x-6)^2 + y^2]$$

$$x^2 + y^2 = 4(x^2 - 12x + 36 + y^2)$$

$$x^2 + y^2 = 4x^2 - 48x + 144 + 4y^2$$

$$0 = 3x^2 - 48x + 144 + 3y^2$$

$$x^2 + y^2 - 16x + 48 = 0$$

配方：$(x - 8)^2 + y^2 = 64 - 48 = 16$。

这是一个圆，圆心 $(8, 0)$，半径 $4$。$\blacksquare$

**Apollonius 圆的一般结论**：设 $A$, $B$ 为两定点，$P$ 满足 $\frac{|PA|}{|PB|} = k$（$k > 0$，$k \neq 1$），则 $P$ 的轨迹是一个圆（称为 **Apollonius 圆**）。当 $k = 1$ 时，轨迹退化为 $AB$ 的中垂线。

Apollonius 圆的圆心在直线 $AB$ 上，分别是 $AB$ 的内分点和外分点（按比 $k:1$ 分）的连线的中点。
