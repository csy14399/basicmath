## 1. Descartes 与 Fermat——解析几何的双重诞生

### 两位创始人

解析几何通常归功于 René **Descartes**（1596–1650），但 Pierre de **Fermat**（1601–1665）几乎在同一时间独立发展了同样的思想。

Descartes 在 1637 年出版了《方法论》（*Discours de la méthode*），其中的附录《几何学》（*La Géométrie*）系统地展示了如何用代数方程描述几何曲线。

Fermat 则在未发表的手稿中（约 1636 年）已经使用了坐标方法来研究曲线。他的方法在某些方面比 Descartes 更清晰——例如，Fermat 直接写出了直线和圆锥曲线的方程，而 Descartes 的处理方式更加晦涩。

### 两种风格

- **Descartes** 是哲学家，他的目标是展示一种**方法论**——"用代数的方法解决几何问题"。他的写作风格故意晦涩（他后来承认这是有意为之，"不想让理解太容易"）。
- **Fermat** 是律师和业余数学家，他的兴趣更纯粹——他只是在发展数学工具。但他很少发表自己的成果。

历史的讽刺：Fermat 可能更早、更清晰地发展了解析几何，但因为没有发表，荣誉归了 Descartes。坐标系被称为"笛卡尔坐标系"（Cartesian coordinates），而不是"费马坐标系"。

## 2. 从直线到曲线——方程的几何意义

### 方程与图形的双向翻译

解析几何的核心思想可以概括为一个双向翻译：

$$\text{几何对象} \quad \longleftrightarrow \quad \text{代数方程}$$

| 几何对象 | 代数方程 |
|---------|---------|
| 直线 | 一次方程 $ax + by + c = 0$ |
| 圆 | 特殊二次方程 $x^2 + y^2 + Dx + Ey + F = 0$ |
| 圆锥曲线 | 一般二次方程 $Ax^2 + Bxy + Cy^2 + Dx + Ey + F = 0$ |
| 三次曲线 | 三次方程 |
| ... | ... |

方程的**次数**（degree）与曲线的**复杂度**直接相关。这就是为什么直线是"最简单的"曲线——它对应最低次（一次）的方程。

### Bézout 定理

> **定理**（Bézout）
>
> 次数为 $m$ 的曲线与次数为 $n$ 的曲线在复射影平面上恰好有 $mn$ 个交点（计入重数和无穷远点）。

例如：
- 直线（$m=1$）与直线（$n=1$）：$1 \times 1 = 1$ 个交点（平行线在无穷远处相交）。
- 直线（$m=1$）与圆（$n=2$）：$1 \times 2 = 2$ 个交点。
- 圆（$m=2$）与圆（$n=2$）：$2 \times 2 = 4$ 个交点（有些可能是虚数或在无穷远处）。

## 3. 高维推广——解析几何的自然延伸

### 三维解析几何

平面上的点用 $(x, y)$ 表示；空间中的点用 $(x, y, z)$ 表示。

- 距离公式：$|AB| = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2 + (z_2-z_1)^2}$
- 平面方程（类比直线）：$ax + by + cz + d = 0$
- 球的方程（类比圆）：$(x-h)^2 + (y-k)^2 + (z-l)^2 = r^2$
- 直线更复杂：需要两个方程（两个平面的交线），或用参数方程

### $n$ 维空间

为什么要止步于三维？数学家定义 $n$ 维欧氏空间 $\mathbb{R}^n$，其中的点是 $n$ 元组 $(x_1, x_2, \ldots, x_n)$，距离公式自然推广为

$$d = \sqrt{\sum_{i=1}^n (x_i - y_i)^2}$$

虽然我们无法"看到"四维或更高维的空间，但解析几何的代数工具让我们可以像在二维和三维中一样进行计算。这就是解析方法相对于综合方法的一个巨大优势——**代数不受维度的限制**。

## 4. 距离的推广——度量空间

### 更一般的"距离"

在解析几何中，我们使用欧氏距离（Euclidean distance）。但"距离"可以有很多不同的定义，只要满足以下三条公理：

> **度量公理**（metric axioms）
>
> 1. $d(A, B) \geq 0$，等号当且仅当 $A = B$（正定性）
> 2. $d(A, B) = d(B, A)$（对称性）
> 3. $d(A, C) \leq d(A, B) + d(B, C)$（三角不等式）

其他常见距离：

- **曼哈顿距离**（Manhattan / taxicab distance）：$d = |x_2-x_1| + |y_2-y_1|$。名字来源于曼哈顿的网格状街道——出租车只能沿街道走，不能走对角线。
- **切比雪夫距离**（Chebyshev distance）：$d = \max(|x_2-x_1|, |y_2-y_1|)$。棋盘上国王一步能到达的最远距离。
- **$p$-范数距离**：$d = \left(|x_2-x_1|^p + |y_2-y_1|^p\right)^{1/p}$。当 $p=2$ 时是欧氏距离，$p=1$ 时是曼哈顿距离，$p\to\infty$ 时趋于切比雪夫距离。

不同的距离定义下，"圆"（到定点等距的点的集合）有不同的形状：欧氏距离下是通常的圆，曼哈顿距离下是正方形（旋转 $45°$），切比雪夫距离下也是正方形（不旋转）。

### 满足度量公理的"距离"定义了一个**度量空间**（metric space），这是拓扑学和分析学的基础概念。

## 5. 仿射几何与射影几何——超越 Euclid

### 仿射几何

如果我们忽略"距离"和"角度"，只关注直线、平行、比例等概念，就得到**仿射几何**（affine geometry）。在仿射几何中，圆和椭圆是"同一种东西"（它们可以通过仿射变换互相转化）。

### 射影几何

如果我们进一步添加"无穷远点"——每组平行线在无穷远处相交于一点——就得到**射影几何**（projective geometry）。在射影几何中，没有"平行线"的概念（任何两条直线都相交），圆和椭圆和抛物线和双曲线都是"同一种东西"（它们都是圆锥曲线，可以通过射影变换互相转化）。

这些推广看似抽象，但它们揭示了几何的深层结构——不同层次的几何，对应保持不同性质不变的变换群。这就是 Felix Klein 的 **Erlangen 纲领**（1872）的核心思想。

| 几何 | 保持的性质 | 变换群 |
|------|----------|--------|
| 欧氏几何 | 距离、角度 | 等距变换（旋转、平移、反射） |
| 相似几何 | 角度、比例 | 相似变换 |
| 仿射几何 | 平行性、比例 | 仿射变换 |
| 射影几何 | 共线性、交比 | 射影变换 |
| 拓扑学 | 连通性、连续性 | 同胚 |

从上到下，保持的性质越来越少，允许的变换越来越多，几何也越来越"灵活"。
