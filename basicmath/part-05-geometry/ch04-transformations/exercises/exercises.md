# 第 4 章 变换几何 — 练习题

## §1 平移与旋转

1. ★☆☆ 将四边形 $ABCD$（$A(0,0)$, $B(3,0)$, $C(3,2)$, $D(0,2)$）沿向量 $\vec{v} = (-2, 4)$ 平移。求像的顶点坐标。

2. ★☆☆ 将点 $P(1, 0)$ 绕原点逆时针旋转 $45°$。求像的坐标。

3. ★☆☆ 将点 $Q(0, 3)$ 绕原点旋转 $180°$。不用公式，直接由几何意义求答案。

4. ★★☆ 将点 $P(2, 1)$ 绕点 $C(1, 1)$ 逆时针旋转 $90°$。求像的坐标。

5. ★★☆ 求绕原点旋转 $30°$ 的旋转矩阵。然后验证：将 $(1, 0)$ 旋转后得到的点在单位圆上。

6. ★★☆ 证明：先沿 $\vec{v}_1 = (a_1, b_1)$ 平移，再沿 $\vec{v}_2 = (a_2, b_2)$ 平移，等价于沿 $\vec{v}_1 + \vec{v}_2$ 平移。（平移的复合是平移。）

7. ★★☆ 证明：$R_{\theta_1} \circ R_{\theta_2} = R_{\theta_1 + \theta_2}$（绕原点的旋转的复合仍是旋转，角度相加）。用矩阵乘法证明。

8. ★★★ 设 $P(3, 4)$ 先绕原点旋转 $\theta$，再沿 $(2, -1)$ 平移。如果像的 $y$ 坐标为 $0$，求 $\theta$（$0 \leq \theta < 2\pi$）。

## §2 反射

1. ★☆☆ 求以下各点关于指定轴的反射像：
   (a) $(3, 5)$ 关于 $x$ 轴
   (b) $(3, 5)$ 关于 $y$ 轴
   (c) $(3, 5)$ 关于 $y = x$

2. ★☆☆ 写出关于 $y = -x$ 的反射矩阵。

3. ★★☆ 求点 $(4, 1)$ 关于直线 $y = x + 1$ 的反射像。（提示：先平移使直线过原点。）

4. ★★☆ 证明反射是自逆变换：$M_\alpha^2 = I$。（用反射矩阵验证。）

5. ★★☆ 关于直线 $y = \frac{1}{\sqrt{3}}x$（即 $\alpha = 30°$）的反射矩阵是什么？将 $(1, 0)$ 代入验证。

6. ★★★ 两条平行线 $\ell_1: y = 1$ 和 $\ell_2: y = 4$。先关于 $\ell_1$ 反射，再关于 $\ell_2$ 反射。求复合变换的公式，验证它是平移。

7. ★★★ 两条直线 $\ell_1: y = 0$（$x$ 轴）和 $\ell_2: y = x$（夹角 $45°$）。求 $M_{\ell_2} \circ M_{\ell_1}$ 的矩阵，验证它是旋转 $90°$。

## §3 缩放与相似变换

1. ★☆☆ 以原点为中心、缩放因子 $k = \frac{1}{2}$ 缩放三角形 $\triangle PQR$（$P(4, 6)$, $Q(2, 0)$, $R(8, 2)$）。求像和面积之比。

2. ★★☆ 以 $(1, 1)$ 为中心、缩放因子 $k = 3$ 缩放点 $(2, 4)$。

3. ★★☆ 证明：均匀缩放保持角度不变。（提示：$D_k$ 保持向量方向不变。）

4. ★★☆ 先将点 $(3, 1)$ 绕原点旋转 $60°$，再以原点为中心缩放 $k = 2$。求像。

5. ★★★ 在复平面上，乘以复数 $w = re^{i\theta}$ 对应什么几何变换？（联系 Part 3 Ch04 复数。）

## §4 变换的复合与变换群

1. ★★☆ 计算矩阵乘积 $R_{60°} M_x$，判断结果是什么类型的变换。

2. ★★☆ 设 $T$ 是关于 $x$ 轴反射，$S$ 是绕原点旋转 $60°$。计算 $S \circ T$ 和 $T \circ S$，说明它们不同。

3. ★★☆ 正三角形有哪些对称变换？写出对称群的所有元素，并指明每个元素是旋转还是反射。

4. ★★★ 证明：如果 $T$ 是等距变换且 $T(O) = O$（固定原点），则 $T$ 要么是旋转，要么是反射。

5. ★★★ 设 $G$ 是矩形（非正方形，长 $\neq$ 宽）的对称群。$G$ 有几个元素？$G$ 与哪个已知群同构？

6. ★★★ 用旋转矩阵和反射矩阵构造正方形对称群 $D_4$ 的乘法表（$8 \times 8$ 表）。

7. ★★★ 证明：平面上的每个保向等距变换（$\det = +1$）要么是平移，要么是旋转。（提示：考虑不动点的个数。）
