# 第 4 章 变换几何 — 挑战题（Challenge Problems）

以下挑战题综合运用变换几何的知识，难度超出常规练习。

---

## 挑战题 1：用反射解决最短路径问题

**题目**：在河流的同一侧有两个村庄 $A(2, 5)$ 和 $B(8, 3)$，河流沿直线 $y = 0$（$x$ 轴）流过。要在河边建一个取水点 $P$，使 $|AP| + |PB|$ 最小。求 $P$ 的坐标和最短距离。

### 提示

将 $A$ 关于河流（$x$ 轴）取反射像 $A'$，则 $|AP| = |A'P|$。问题转化为使 $|A'P| + |PB|$ 最小。

### 解答

$A' = (2, -5)$（$A$ 关于 $x$ 轴的反射像）。

$|AP| + |PB| = |A'P| + |PB| \geq |A'B|$（三角不等式，等号当且仅当 $P$ 在 $A'B$ 上）。

$|A'B| = \sqrt{(8-2)^2 + (3-(-5))^2} = \sqrt{36 + 64} = \sqrt{100} = 10$。

$P$ 在 $A'B$ 与 $x$ 轴的交点。直线 $A'B$：$\frac{y - (-5)}{x - 2} = \frac{3 - (-5)}{8 - 2} = \frac{8}{6} = \frac{4}{3}$。

令 $y = 0$：$\frac{5}{x-2} = \frac{4}{3}$，$x - 2 = \frac{15}{4}$，$x = \frac{23}{4}$。

$$P = \left(\frac{23}{4}, 0\right), \quad \text{最短距离} = 10$$

这就是经典的**Heron 问题**（光的反射定律的几何版本）。

## 挑战题 2：变换群与壁纸群分类

**题目**：证明平面上恰好存在 **17 种** 本质不同的壁纸群（wallpaper groups），即平面上满足在两个线性无关方向上具有平移对称性的图案的对称群。列出其中至少 5 种，并说明各自的对称特征。

### 解答

完整证明需要较深的群论工具（详见 Thinker's Corner），这里给出分类的核心思路和 5 种代表。

**核心约束**：壁纸群 $G$ 中的旋转阶只能是 $1, 2, 3, 4, 6$（**晶体学限制定理**）。

证明要点：设旋转 $R_\theta \in G$，$G$ 包含沿 $\vec{a}$ 的平移 $T_{\vec{a}}$。则 $R_\theta T_{\vec{a}} R_\theta^{-1} = T_{R_\theta(\vec{a})}$ 也在 $G$ 中。$R_\theta(\vec{a})$ 和 $\vec{a}$ 生成的格子必须是离散的，这限制了 $\theta = \frac{2\pi}{n}$，$n \in \{1, 2, 3, 4, 6\}$。

**5 种代表壁纸群**：

| 记号 | 旋转阶 | 反射 | 滑移反射 | 代表图案 |
|------|--------|------|----------|----------|
| $p1$ | 1 | 无 | 无 | 斜向砖墙 |
| $p2$ | 2 | 无 | 无 | 交错 S 形 |
| $pm$ | 1 | 有（平行） | 无 | 垂直条纹 |
| $p4$ | 4 | 无 | 无 | 方格旋转 |
| $p6m$ | 6 | 有 | 有 | 蜂巢 |

17 种壁纸群的完整分类在 1891 年由 Fedorov（晶体学家）和 1897 年由 Schoenflies、Barlow 独立完成。

$\blacksquare$

（注：完整证明要求系统地枚举所有可能的旋转阶、反射轴方向、滑移反射的组合，并排除不相容的组合。）
