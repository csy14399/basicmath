# 第 4 章：变换几何（Geometric Transformations）

## 章概览

Felix Klein 在 1872 年提出的 **Erlangen 纲领** 给出了一个深刻洞见：**几何就是研究在某一变换群下不变的性质。** 欧氏几何研究的是在等距变换（平移、旋转、反射）下不变的性质（距离、角度）；相似几何研究的是在相似变换下不变的性质（角度、形状）；仿射几何、射影几何则对应更大的变换群。

本章从最基本的几何变换出发——平移、旋转、反射、缩放——逐步建立变换的分类体系。我们将看到：**变换不仅是研究几何的工具，更是理解对称性的语言。** 而变换在复合运算下构成的**群**结构（回想 Part 3 Ch05），正是这种对称性的精确数学表达。

## 学习成果

本章完成后你将能够：

- **用坐标公式描述四种基本变换**：平移、旋转、反射、缩放
- **写出旋转和反射的矩阵形式**
- **分类等距变换**：理解为什么等距变换只有四种（平移、旋转、反射、滑移反射）
- **理解相似变换**：保角但改变距离
- **计算变换的复合**：掌握复合顺序的重要性
- **理解变换与群论的联系**：变换在复合下构成群
