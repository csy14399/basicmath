# 第 3 章：圆锥曲线（Conic Sections）

## 章概览

圆锥曲线——**椭圆**、**双曲线**和**抛物线**——是二次曲线中最重要的三种。它们得名于古希腊数学家 Apollonius 的发现：用不同角度的平面去截一个圆锥面，所得的截线恰好是这三种曲线。两千多年后，Kepler 发现行星轨道是椭圆，Newton 证明这来自万有引力的平方反比律——圆锥曲线从纯粹的几何对象变成了理解宇宙运动的关键工具。

本章从每种曲线的几何定义出发，推导标准方程和基本性质，最后用**焦点-准线定义**和**一般二次方程**将三种曲线统一起来。
