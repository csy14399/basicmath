以下挑战题综合运用圆锥曲线的知识，难度超出常规练习。

## 挑战题 1：椭圆的光学性质的严格证明

证明：椭圆 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ 在点 $P(x_0, y_0)$ 处的切线与焦点连线 $PF_1$、$PF_2$ 的夹角相等（入射角 = 反射角）。

### 提示

先求椭圆在 $P$ 处的切线方程。然后计算切线与 $PF_1$、$PF_2$ 所成角的正切值，证明它们相等。

### 解答

椭圆在 $P(x_0, y_0)$ 处的切线方程为 $\frac{x_0 x}{a^2} + \frac{y_0 y}{b^2} = 1$。

切线的法向量为 $\vec{n} = \left(\frac{x_0}{a^2}, \frac{y_0}{b^2}\right)$。

$\vec{PF_1} = (-c - x_0, -y_0)$，$\vec{PF_2} = (c - x_0, -y_0)$。

法线方向上的投影给出入射角和反射角。更具体地，设切线方向为 $\vec{t} = \left(-\frac{y_0}{b^2}, \frac{x_0}{a^2}\right)$（法向量旋转 $90°$）。

入射角 $\alpha_1$ 的正切：$\tan\alpha_1 = \frac{\vec{PF_1} \cdot \vec{n}}{|\vec{PF_1} \times \vec{n}|}$（这里 $\times$ 表示二维叉积的绝对值）。

$\vec{PF_1} \cdot \vec{n} = \frac{(-c-x_0)x_0}{a^2} + \frac{(-y_0)y_0}{b^2} = -\frac{x_0(c+x_0)}{a^2} - \frac{y_0^2}{b^2}$。

由椭圆方程 $\frac{y_0^2}{b^2} = 1 - \frac{x_0^2}{a^2}$：

$= -\frac{x_0 c + x_0^2}{a^2} - 1 + \frac{x_0^2}{a^2} = -\frac{x_0 c}{a^2} - 1 = -\frac{x_0 c + a^2}{a^2}$。

由焦点半径：$|PF_1| = a + ex_0 = a + \frac{cx_0}{a} = \frac{a^2 + cx_0}{a}$。

因此 $\vec{PF_1} \cdot \vec{n} = -\frac{a \cdot |PF_1|}{a^2} = -\frac{|PF_1|}{a}$。

类似地，$\vec{PF_2} \cdot \vec{n} = \frac{|PF_2|}{a}$。

二维叉积 $\vec{PF_1} \times \vec{n} = (-c-x_0)\frac{y_0}{b^2} - (-y_0)\frac{x_0}{a^2} = -\frac{(c+x_0)y_0}{b^2} + \frac{x_0 y_0}{a^2}$。

$= y_0\left(\frac{x_0}{a^2} - \frac{c+x_0}{b^2}\right) = y_0 \cdot \frac{x_0 b^2 - (c+x_0)a^2}{a^2 b^2}$。

$= y_0 \cdot \frac{x_0(b^2 - a^2) - ca^2}{a^2 b^2} = y_0 \cdot \frac{-x_0 c^2 - ca^2}{a^2 b^2} = \frac{-cy_0(x_0 c + a^2)}{a^2 b^2} = \frac{-cy_0 \cdot a \cdot |PF_1|}{a^2 b^2}$。

$= \frac{-cy_0 |PF_1|}{ab^2}$。

$\tan\alpha_1 = \frac{|\vec{PF_1} \cdot \vec{n}|}{|\vec{PF_1} \times \vec{n}|} = \frac{|PF_1|/a}{|cy_0||PF_1|/(ab^2)} = \frac{b^2}{|cy_0|}$。

类似地，$\tan\alpha_2 = \frac{b^2}{|cy_0|}$。

因此 $\alpha_1 = \alpha_2$：入射角等于反射角。$\blacksquare$

## 挑战题 2：Dandelin 球——圆锥截线的优雅证明

Dandelin 球（Dandelin spheres）提供了一种优雅的方法来证明圆锥截线确实是焦点-准线定义下的圆锥曲线。

**题目**：描述 Dandelin 球的构造，并说明如何用它证明椭圆截面确实满足"到两定点距离之和为常数"。

### 解答

**构造**：考虑一个圆锥面（双叶），用一个平面 $\Pi$ 截之得到椭圆（假设截面角度合适）。

在圆锥面内部，截面 $\Pi$ 的两侧，分别内切一个球（称为 **Dandelin 球** $S_1$ 和 $S_2$）。每个球与圆锥面切于一个圆（$C_1$ 和 $C_2$），与截面 $\Pi$ 切于一个点（$F_1$ 和 $F_2$）。

**证明 $F_1$, $F_2$ 是焦点**：

设 $P$ 是截面上（即椭圆上）的任意一点。过 $P$ 作圆锥面的母线 $\ell$。

$\ell$ 与 $S_1$ 切于 $C_1$ 上的某点 $T_1$，与 $S_2$ 切于 $C_2$ 上的某点 $T_2$。

由切线长相等（从外部点到球的两条切线长相等）：

$|PF_1| = |PT_1|$（$P$ 到 $S_1$ 的两条切线：一条切于 $F_1$（在平面内），一条切于 $T_1$（在母线上））。

$|PF_2| = |PT_2|$（类似理由）。

$|PF_1| + |PF_2| = |PT_1| + |PT_2| = |T_1T_2|$。

$|T_1T_2|$ 是母线 $\ell$ 上从 $C_1$ 到 $C_2$ 之间的长度——这个长度对于圆锥面上的所有母线都相同（因为 $C_1$、$C_2$ 是以顶点为共同轴的两个"纬线圈"）。

因此 $|PF_1| + |PF_2| = \text{常数}$，$F_1$, $F_2$ 就是椭圆的焦点。$\blacksquare$

Dandelin 球的优美之处在于：它用纯粹的三维综合几何证明了椭圆的焦点性质，没有使用任何坐标或代数计算。

## 挑战题 3：抛物线的反射性质与 Fermat 原理

从物理学中的 **Fermat 原理**（光走最短时间路径）出发，证明抛物线的反射性质。

### 解答

**Fermat 原理**：光在均匀介质中走直线（最短路径）。反射时，光走的是使总路径长度最短（或驻定）的路径。

**设置**：抛物线 $y^2 = 4px$，焦点 $F(p, 0)$，准线 $\ell: x = -p$。

设一束平行于 $x$ 轴的光线射到抛物线上的点 $P$，需要证明反射光线过焦点 $F$。

**关键观察**：对于抛物线上的任意点 $P$，$|PF| = d(P, \ell)$。

设光线从远处（$x \to \infty$）沿平行于 $x$ 轴的方向射到 $P$，然后反射到焦点 $F$。

光程 $= (\text{从远处到 } P) + |PF| = (\text{从远处到 } P) + d(P, \ell)$。

从远处到 $P$ 的水平距离加上 $P$ 到准线的距离 $= P$ 到准线的距离加上准线以左无穷远的距离——总光程对所有 $P$ 是相同的！

换句话说：任何平行光线，无论射到抛物面的哪一点 $P$，从"无穷远 → $P$ → $F$"的总光程都相同。

由 Fermat 原理的等光程版本（等相位面）：所有平行光线经反射后汇聚到 $F$。

具体地，反射定律（入射角 $=$ 反射角）保证光程极值条件满足。由于 $|PF| = d(P, \ell)$，等光程面就是准线——一条直线——对应平行光束。因此反射后的光线确实汇聚到焦点。$\blacksquare$

这个证明的物理直觉极其清晰：**抛物线的准线就是入射平行光的等相位面**。
