# 第 3 章 圆锥曲线 — 练习题解答

## §1 椭圆

**1.** $a^2 = 16$, $b^2 = 9$, $a = 4$, $b = 3$, $c = \sqrt{16-9} = \sqrt{7}$。

焦点 $(\pm\sqrt{7}, 0)$。顶点 $(\pm 4, 0)$, $(0, \pm 3)$。$e = \frac{\sqrt{7}}{4}$。

---

**2.** $a^2 = 25$（对应 $y$），$b^2 = 4$（对应 $x$）。$a = 5$, $b = 2$, $c = \sqrt{25-4} = \sqrt{21}$。

分母较大的在 $y$ 上，焦点在 **$y$ 轴**上：$(0, \pm\sqrt{21})$。

---

**3.** 过 $(2, 0)$ 和 $(0, 3)$，焦点在 $x$ 轴。设 $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$（$a > b$）。

$(2, 0)$：$a^2 = 4$。$(0, 3)$：$b^2 = 9$。但 $b^2 = 9 > a^2 = 4$，焦点应在 $y$ 轴！

如果要求焦点在 $x$ 轴，需要 $a > b$，但这里 $a = 2 < b = 3$。矛盾。

重新设置：焦点在 $x$ 轴要求 $x$ 方向的分母更大。$(2, 0)$ 在 $x$ 轴上意味着 $a = 2$，但 $(0, 3)$ 在 $y$ 轴上意味着 $b = 3 > a = 2$。

因此在焦点在 $x$ 轴的约束下，此条件无法满足。如果允许焦点在 $y$ 轴：$\frac{x^2}{4} + \frac{y^2}{9} = 1$（焦点在 $y$ 轴）。

---

**4.** $c = 3$，$2a = 10 \Rightarrow a = 5$。$b^2 = a^2 - c^2 = 25 - 9 = 16$。

$\frac{x^2}{25} + \frac{y^2}{16} = 1$。

---

**5.** $a = 5$。$|PF_1| + |PF_2| = 2a = 10$。$|PF_1| = 2$，$|PF_2| = 8$。

---

**6.** $e = \frac{1}{2}$，$\frac{c}{a} = \frac{1}{2}$，$c = \frac{a}{2}$。$b^2 = a^2 - c^2 = a^2 - \frac{a^2}{4} = \frac{3a^2}{4}$。

设方程 $\frac{x^2}{a^2} + \frac{y^2}{\frac{3a^2}{4}} = 1$。代入 $(1, \frac{3}{2})$：

$\frac{1}{a^2} + \frac{\frac{9}{4}}{\frac{3a^2}{4}} = 1$，$\frac{1}{a^2} + \frac{3}{a^2} = 1$，$\frac{4}{a^2} = 1$，$a^2 = 4$。

$b^2 = 3$。方程：$\frac{x^2}{4} + \frac{y^2}{3} = 1$。

---

**7.** $a = 5$, $b = 3$, $c = 4$。设 $|PF_1| = r_1$, $|PF_2| = r_2$。

$r_1 + r_2 = 10$。$|F_1F_2| = 8$。$\angle F_1PF_2 = 90°$。

余弦定理：$|F_1F_2|^2 = r_1^2 + r_2^2 - 2r_1r_2\cos 90° = r_1^2 + r_2^2$。

$64 = r_1^2 + r_2^2 = (r_1+r_2)^2 - 2r_1r_2 = 100 - 2r_1r_2$。$r_1r_2 = 18$。

---

**8.** $|PF_1| = a + ex_0$（焦点半径）。$-a \leq x_0 \leq a$。

$|PF_1|$ 在 $x_0 = a$ 时最大：$|PF_1| = a + ea = a(1+e) = a + c$。

$|PF_1|$ 在 $x_0 = -a$ 时最小：$|PF_1| = a - ea = a(1-e) = a - c$。

类似地，$|PF_2| = a - ex_0$ 在 $x_0 = -a$ 时最大 $a+c$，在 $x_0 = a$ 时最小 $a-c$。$\blacksquare$

---

**9.** $a = 3$, $c = \sqrt{5}$。$F_1(-\sqrt{5}, 0)$。

$|PF_1| = a + ex_0 = 3 + \frac{\sqrt{5}}{3}x_0$。$-3 \leq x_0 \leq 3$。

最大：$x_0 = 3$，$|PF_1| = 3 + \sqrt{5}$。对应顶点 $(3, 0)$。

最小：$x_0 = -3$，$|PF_1| = 3 - \sqrt{5}$。对应顶点 $(-3, 0)$。

---

## §2 双曲线

**1.** $a^2 = 16$, $b^2 = 9$, $c = \sqrt{25} = 5$。

焦点 $(\pm 5, 0)$。渐近线 $y = \pm\frac{3}{4}x$。$e = \frac{5}{4}$。

---

**2.** $a^2 = 4$（$y$ 项为正），$b^2 = 12$。$c = \sqrt{4+12} = 4$。

焦点在 $y$ 轴：$(0, \pm 4)$。渐近线 $y = \pm\frac{a}{b}x = \pm\frac{2}{2\sqrt{3}}x = \pm\frac{1}{\sqrt{3}}x = \pm\frac{\sqrt{3}}{3}x$。

---

**3.** $c = 5$。渐近线 $y = \pm\frac{b}{a}x = \pm\frac{3}{4}x$，$\frac{b}{a} = \frac{3}{4}$，$b = \frac{3a}{4}$。

$c^2 = a^2 + b^2 = a^2 + \frac{9a^2}{16} = \frac{25a^2}{16} = 25$。$a^2 = 16$，$b^2 = 9$。

$\frac{x^2}{16} - \frac{y^2}{9} = 1$。

---

**4.** 渐近线 $y = \pm x$ 意味着 $a = b$。设方程 $\frac{x^2}{a^2} - \frac{y^2}{a^2} = 1$，即 $x^2 - y^2 = a^2$。

代入 $(2, 1)$：$4 - 1 = a^2 = 3$。方程：$x^2 - y^2 = 3$，即 $\frac{x^2}{3} - \frac{y^2}{3} = 1$。

但需要检查另一种情况 $\frac{y^2}{a^2} - \frac{x^2}{a^2} = 1$：代入 $(2,1)$：$1 - 4 = a^2 = -3 < 0$，不可能。

答案：$\frac{x^2}{3} - \frac{y^2}{3} = 1$。

---

**5.** $a = 2$, $c = 4$。$||PF_1| - |PF_2|| = 2a = 4$。

$|PF_1| = 3$：$|3 - |PF_2|| = 4$，$|PF_2| = 7$ 或 $|PF_2| = -1$（不可能）。

所以 $|PF_2| = 7$。

检查：如果到另一个焦点距离为 $3$，$||PF_1| - 3| = 4$，$|PF_1| = 7$ 或 $|PF_1| = -1$（不可能）。$|PF_1| = 7$。

答案：$7$。

---

**6.** $a = b$，$c = \sqrt{a^2 + a^2} = a\sqrt{2}$。$e = \frac{c}{a} = \sqrt{2}$。

---

**7.** 设 $|PF_1| = r_1$, $|PF_2| = r_2$。$|r_1 - r_2| = 2a$，$(r_1 - r_2)^2 = 4a^2$。

余弦定理：$|F_1F_2|^2 = r_1^2 + r_2^2 - 2r_1r_2\cos\angle F_1PF_2$。

$(2c)^2 = r_1^2 + r_2^2 - 2r_1r_2\cos\theta$。

$r_1^2 + r_2^2 = (r_1-r_2)^2 + 2r_1r_2 = 4a^2 + 2 \cdot \frac{b^4}{a^2}$。

$4c^2 = 4a^2 + \frac{2b^4}{a^2} - \frac{2b^4}{a^2}\cos\theta$。

$4(a^2+b^2) = 4a^2 + \frac{2b^4}{a^2}(1 - \cos\theta)$。

$4b^2 = \frac{2b^4}{a^2}(1 - \cos\theta)$。$1 - \cos\theta = \frac{4b^2 a^2}{2b^4} = \frac{2a^2}{b^2}$。

需要 $\cos\theta = 1 - \frac{2a^2}{b^2}$。如果 $\theta = 90°$，$\cos\theta = 0$，需要 $\frac{2a^2}{b^2} = 1$，即 $b^2 = 2a^2$。

这并非对所有双曲线成立。让我重新计算——题目给定 $r_1r_2 = \frac{b^4}{a^2}$，需要证 $\theta = 90°$。

$4c^2 = 4a^2 + \frac{2b^4}{a^2} - \frac{2b^4}{a^2}\cos\theta$。

如果 $\cos\theta = 0$：$4c^2 = 4a^2 + \frac{2b^4}{a^2}$。$4(a^2+b^2) = 4a^2 + \frac{2b^4}{a^2}$。$4b^2 = \frac{2b^4}{a^2}$。$2a^2 = b^2$。

因此当 $r_1r_2 = \frac{b^4}{a^2}$ 时，$\cos\theta = 0$ 当且仅当 $b^2 = 2a^2$，否则角度不一定为 $90°$。

实际上，更一般地：由余弦定理 $\cos\theta = \frac{r_1^2+r_2^2 - 4c^2}{2r_1r_2}$。

$r_1^2+r_2^2 = (r_1-r_2)^2+2r_1r_2 = 4a^2+\frac{2b^4}{a^2}$。

$\cos\theta = \frac{4a^2+\frac{2b^4}{a^2}-4(a^2+b^2)}{2 \cdot \frac{b^4}{a^2}} = \frac{\frac{2b^4}{a^2}-4b^2}{\frac{2b^4}{a^2}} = 1 - \frac{4b^2 \cdot a^2}{2b^4} = 1 - \frac{2a^2}{b^2}$。

当 $r_1r_2 = \frac{b^4}{a^2}$ 时，$\cos\theta = 1 - \frac{2a^2}{b^2}$。这等于 $0$ 当且仅当 $b^2 = 2a^2$。

因此题目的条件可能不够一般。但如果题目本意是给定 $r_1 \cdot r_2 = \frac{b^4}{a^2}$ 且 $b^2 = 2a^2$（即 $e = \sqrt{3}$），则 $\theta = 90°$。$\blacksquare$（在 $b^2 = 2a^2$ 的条件下。）

## §3 抛物线

**1.**

(a) $4p = 8$, $p = 2$。焦点 $(2, 0)$，准线 $x = -2$。

(b) $4p = 12$, $p = 3$。开口向下。焦点 $(0, -3)$，准线 $y = 3$。

(c) $4p = 6$, $p = \frac{3}{2}$。开口向左。焦点 $(-\frac{3}{2}, 0)$，准线 $x = \frac{3}{2}$。

---

**2.** 焦点 $(0, 3)$，开口向上。$p = 3$，$x^2 = 4py = 12y$。

---

**3.** $4p = 16$, $p = 4$。焦点 $(4, 0)$。$|PF| = x + 4 = 8$，$x = 4$。$y^2 = 64$，$y = \pm 8$。$P = (4, 8)$ 或 $(4, -8)$。

---

**4.** 点 $P(x, y)$ 在 $y^2 = 4x$ 上。到 $x = 5$ 的距离 $= |x - 5| = 5 - x$（因为 $x \geq 0 < 5$）。

最小化 $5 - x$ 等价于最大化 $x$。但不对——需要最小化 $5 - x$，即最大化 $x$。然而 $y^2 = 4x$ 表明 $x$ 无上界。

重新思考：$5 - x$ 对 $x \geq 0$ 递减。所以距离 $5 - x$ 在 $x$ 尽可能大时最小。但 $x$ 可以任意大……

实际上距离 $= |x - 5|$。当 $x < 5$ 时距离 $= 5 - x$；当 $x > 5$ 时距离 $= x - 5$。

抛物线上的点 $x \geq 0$。当 $x$ 从 $0$ 增到 $5$，距离从 $5$ 减到 $0$；当 $x$ 从 $5$ 增大，距离增大。最近的点在 $x = 5$：$y^2 = 20$，$P = (5, \pm 2\sqrt{5})$，距离 $= 0$。

但这不对——距直线 $x = 5$ 的距离是水平距离，而点在抛物线上 $x = 5$ 时距离确实是 $0$。

实际上题意可能是：距**直线** $x = 5$ 的最近点。答案是 $(5, 2\sqrt{5})$ 和 $(5, -2\sqrt{5})$，距离 $= 0$（点在直线上方/下方但水平距离为零）。

但如果原题求的是到点 $(5, 0)$ 的最近距离，或者求 $|PF| - |x - 5|$ 等其他表述，答案不同。按字面理解，抛物线上到 $x = 5$ 最近的点就是 $x = 5$（距离 $= 0$）的点。

如果题意是"不在直线上"的最近点，则答案可能意指求焦点距离最近：$p = 1$，焦点 $(1, 0)$。利用 $|PF| = x + 1$，最小化 $d = \sqrt{(x-5)^2 + y^2} = \sqrt{(x-5)^2 + 4x}$。$d^2 = x^2 - 6x + 25$，$\frac{d(d^2)}{dx} = 2x - 6 = 0$，$x = 3$。$P = (3, \pm 2\sqrt{3})$，$d = \sqrt{9 - 18 + 25} = 4$。

答案：$(3, 2\sqrt{3})$ 或 $(3, -2\sqrt{3})$，最短距离 $= 4$。

---

**5.** $p = 1$，焦点 $F(1, 0)$。$|AF| = x_A + 1 = 3$，$x_A = 2$。

焦点弦满足 $x_A x_B = p^2 = 1$，$x_B = \frac{1}{2}$。$|BF| = x_B + 1 = \frac{3}{2}$。

---

**6.** $y = 2(x^2 - 2x) + 5 = 2(x-1)^2 + 3$。

$(x-1)^2 = \frac{1}{2}(y - 3)$。$4p = \frac{1}{2}$，$p = \frac{1}{8}$。

顶点 $(1, 3)$。焦点 $(1, 3 + \frac{1}{8}) = (1, \frac{25}{8})$。准线 $y = 3 - \frac{1}{8} = \frac{23}{8}$。

---

**7.** 设 $A(x_1, y_1)$, $B(x_2, y_2)$ 在 $y^2 = 4px$ 上。$|AF| = x_1 + p$，$|BF| = x_2 + p$。

$\frac{1}{|AF|} + \frac{1}{|BF|} = \frac{1}{x_1+p} + \frac{1}{x_2+p} = \frac{(x_1+p)+(x_2+p)}{(x_1+p)(x_2+p)}$

分子 $= x_1 + x_2 + 2p$。

分母 $= x_1x_2 + p(x_1+x_2) + p^2$。由焦点弦性质 $x_1x_2 = p^2$：

分母 $= p^2 + p(x_1+x_2) + p^2 = p(x_1+x_2+2p)$（等等，重算）。

分母 $= x_1x_2 + p(x_1+x_2) + p^2 = p^2 + p(x_1+x_2) + p^2$... 这里 $x_1x_2 = p^2$，所以分母 $= p^2 + p(x_1+x_2) + p^2$？不对。

重新：$(x_1+p)(x_2+p) = x_1x_2 + p(x_1+x_2) + p^2 = p^2 + p(x_1+x_2) + p^2$？

$x_1x_2 = p^2$（这是已知的焦点弦性质），所以 $(x_1+p)(x_2+p) = p^2 + p(x_1+x_2) + p^2$。

不——$(x_1+p)(x_2+p) = x_1x_2 + px_1 + px_2 + p^2 = p^2 + p(x_1+x_2) + p^2 = 2p^2 + p(x_1+x_2)$。

不对。$x_1x_2 = p^2$，所以 $(x_1+p)(x_2+p) = p^2 + p(x_1+x_2) + p^2 = p^2 + p(x_1+x_2) + p^2$。

这里的计算有误。正确地：$(x_1+p)(x_2+p) = x_1x_2 + p(x_1+x_2) + p^2$。

代入 $x_1x_2 = p^2$：$= p^2 + p(x_1+x_2) + p^2 = 2p^2 + p(x_1+x_2) = p[2p + (x_1+x_2)]$。

分子 $= x_1+x_2+2p$。

$\frac{1}{|AF|} + \frac{1}{|BF|} = \frac{x_1+x_2+2p}{p(x_1+x_2+2p)} = \frac{1}{p}$。$\blacksquare$

## §4 圆锥曲线的统一

**1.**

(a) $A = 3$, $B = 0$, $C = 5$。$\Delta = -60 < 0$。椭圆。

(b) $A = 1$, $B = 0$, $C = -4$。$\Delta = 16 > 0$。双曲线。

(c) $A = 0$, $B = 0$, $C = 1$。$\Delta = 0$。抛物线。

(d) $A = 1$, $B = 0$, $C = 1$。$\Delta = -4 < 0$。椭圆（实际是圆：$A = C$, $B = 0$）。

---

**2.** $e = \frac{2}{3} < 1$：椭圆。$e = 1.5 > 1$：双曲线。

---

**3.** $\frac{|PF|}{d(P, \ell)} = \frac{1}{2}$。$F(1, 0)$，$\ell: x = 4$。

$\sqrt{(x-1)^2+y^2} = \frac{1}{2}|x-4|$。平方后：

$4[(x-1)^2+y^2] = (x-4)^2$

$4x^2-8x+4+4y^2 = x^2-8x+16$

$3x^2+4y^2 = 12$

$\frac{x^2}{4}+\frac{y^2}{3} = 1$。椭圆。

---

**4.** $F(0, 0)$，$\ell: y = -2$，$e = 1$。

$\sqrt{x^2+y^2} = |y+2| = y+2$（$P$ 在准线上方）。

$x^2+y^2 = y^2+4y+4$。$x^2 = 4y+4 = 4(y+1)$。

顶点 $(0, -1)$（准线与焦点的中点）。

---

**5.** $9(x^2+2x) - 16(y^2-4y) = 199$。

$9(x+1)^2 - 9 - 16(y-2)^2 + 64 = 199$。

$9(x+1)^2 - 16(y-2)^2 = 144$。

$\frac{(x+1)^2}{16} - \frac{(y-2)^2}{9} = 1$。双曲线，中心 $(-1, 2)$。

---

**6.** $A = 1$, $B = 4$, $C = 4$。$\Delta = 16 - 16 = 0$。抛物线。

$x^2+4xy+4y^2 = (x+2y)^2$。方程：$(x+2y)^2 - 2x + y = 0$。

令 $u = x + 2y$，需要另一个变量。令 $v = 2x - y$（选择使变换矩阵行列式非零）。

则 $x = \frac{u+2v}{5}$，$y = \frac{2u-v}{5}$。

$-2x + y = -2 \cdot \frac{u+2v}{5} + \frac{2u-v}{5} = \frac{-2u-4v+2u-v}{5} = \frac{-5v}{5} = -v$。

方程变为 $u^2 - v = 0$，即 $v = u^2$。这是标准抛物线。$\blacksquare$

---

**7.** $|PF_2| = a - ex_0$（焦点半径，§1 定理 2）。

$d(P, \ell) = \frac{a^2}{c} - x_0 = \frac{a^2 - cx_0}{c}$。

$\frac{|PF_2|}{d(P,\ell)} = \frac{a - ex_0}{\frac{a^2-cx_0}{c}} = \frac{(a-ex_0)c}{a^2-cx_0} = \frac{(a-\frac{c}{a}x_0)c}{a^2-cx_0} = \frac{c(\frac{a^2-cx_0}{a})}{a^2-cx_0} = \frac{c}{a} = e$。$\blacksquare$
