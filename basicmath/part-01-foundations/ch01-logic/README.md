# 第 1 章：逻辑（Logic）

## 章概览

逻辑是数学的语言。

数学家用自然语言交流思想，但自然语言充满了歧义。"或"到底是"二选一"还是"至少一个"？"如果你考满分，我就买手机给你"——如果你没考满分但还是买了，这算违约吗？"所有的鸟都会飞"——企鹅怎么办？

数学逻辑（mathematical logic）的目的，就是提供一套精确的、无歧义的语言来表达和验证推理。命题逻辑处理命题之间的逻辑关系（"并且"、"或者"、"如果...那么..."），谓词逻辑则进一步引入量词（"对所有"、"存在"），让我们能够讨论数学对象的性质。

本章建立的逻辑语言将贯穿整本教材的每一页。当你在后续章节看到一个定理的陈述和证明时，你其实是在阅读用逻辑语言写成的论证。

## 本章完成后你将能够

- **判断命题真假**：识别一个句子是否是命题，并在给定条件下判断其真值
- **构建真值表**：为任意复合命题构建完整的真值表
- **运用逻辑等价律**：使用 De Morgan 律、逆否命题等等价律简化和变换命题
- **理解量词**：正确使用全称量词 $\forall$ 和存在量词 $\exists$，并能否定含量词的命题
- **翻译日常语言为形式逻辑**：将自然语言的数学陈述系统地翻译为谓词逻辑公式
