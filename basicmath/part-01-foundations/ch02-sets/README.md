# 第 2 章：集合论（Set Theory）

## 章概览

集合论是现代数学的基础语言。

如果说逻辑（第 1 章）给了我们推理的工具，那么集合论给了我们描述数学对象的工具。几乎所有的数学概念——数、函数、空间、结构——都可以用集合的语言来定义。当数学家说"考虑实数集 $\mathbb{R}$"或"令 $f: A \to B$ 是一个函数"时，他们都在使用集合论的语言。

集合论的故事始于 19 世纪末。Georg Cantor（1845–1918）在研究三角级数的收敛性时，发现需要一种精确描述"无穷多个对象的汇集"的语言。他创立了朴素集合论（naive set theory），引入了集合、子集、并集、交集等概念，并做出了数学史上最惊人的发现之一：**无穷有不同的大小**。自然数集和实数集虽然都是无穷集合，但实数"更多"——Cantor 用精巧的对角线论证证明了这一点。

Cantor 的工作震撼了数学界，也引发了深刻的危机。Russell 悖论（1901）揭示了朴素集合论的逻辑缺陷，迫使数学家重新审视集合的概念。最终，Zermelo-Fraenkel 公理系统（ZFC）为集合论提供了坚实的基础，使之成为现代数学大厦的基石。

本章从朴素但实用的角度出发，建立集合论的核心概念。我们不拘泥于公理化的形式主义（那属于数理逻辑课程的范畴），而是着重培养用集合语言思考和表达数学的能力。

## 前置知识

- **[第 1 章 逻辑](../ch01-logic/README.md)**：命题逻辑（联结词、真值表、逻辑等价）和谓词逻辑（量词 $\forall$, $\exists$、谓词、否定量词命题）。集合论的定义和证明大量使用逻辑语言——例如，子集的定义就是一个全称量化的蕴含命题。

## 本章完成后你将能够

- **理解集合的基本概念**：识别和构造集合，区分元素、子集、幂集等不同层次的"属于/包含"关系
- **熟练运用集合运算**：计算并集、交集、补集、差集、对称差，并利用集合恒等式进行化简
- **掌握关系的数学描述**：将"关系"形式化为笛卡尔积的子集，判断关系的性质（自反、对称、传递等）
- **理解等价关系与划分的对应**：认识到等价关系自然地将集合分成不重叠的等价类
- **从集合论角度理解函数**：将函数视为特殊的关系，理解单射、满射、双射的精确含义
- **初步理解无穷的层次**：理解可数与不可数的区别，欣赏 Cantor 对角线论证的精妙
