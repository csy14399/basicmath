## 挑战题 1：$\mathcal{P}(\mathbb{N})$ 与 $\mathbb{R}$ 等势

**问题**：证明 $\mathbb{N}$ 的幂集与实数集等势：$|\mathcal{P}(\mathbb{N})| = |\mathbb{R}|$。

### 提示

- $\mathcal{P}(\mathbb{N})$ 与 $\{0, 1\}^\mathbb{N}$（所有无穷 $0$-$1$ 序列的集合）之间存在自然的双射（子集 $\leftrightarrow$ 特征函数）。
- $\{0, 1\}^\mathbb{N}$ 与 $[0, 1]$ 之间有密切关系（二进制小数展开）。
- 注意：不是所有实数的二进制展开都是唯一的（如 $0.0111\ldots = 0.1000\ldots$），所以直接构造双射有微妙之处。可以使用 Schröder-Bernstein 定理来回避这个问题。

### 解答大纲

**策略**：证明 $|\mathcal{P}(\mathbb{N})| \leq |\mathbb{R}|$ 和 $|\mathbb{R}| \leq |\mathcal{P}(\mathbb{N})|$，然后由 Schröder-Bernstein 定理得出 $|\mathcal{P}(\mathbb{N})| = |\mathbb{R}|$。

**步骤 1**：$\mathcal{P}(\mathbb{N}) \approx \{0, 1\}^\mathbb{N}$。

对每个子集 $A \subseteq \mathbb{N}$，定义特征函数 $\chi_A: \mathbb{N} \to \{0, 1\}$：$\chi_A(n) = 1$ 当且仅当 $n \in A$。映射 $A \mapsto \chi_A$ 是双射。

**步骤 2**：构造单射 $\{0, 1\}^\mathbb{N} \hookrightarrow \mathbb{R}$。

给定序列 $(b_0, b_1, b_2, \ldots) \in \{0, 1\}^\mathbb{N}$，定义实数 $x = \sum_{n=0}^{\infty} \frac{2b_n + 1}{10^{n+1}}$。

这将每个 $0$-$1$ 序列映射到 $[0, 1]$ 中的一个实数，且只使用数字 $1$ 和 $3$（分别对应 $b_n = 0$ 和 $b_n = 1$）。由于十进制中只使用 $1$ 和 $3$，不会产生重复表示的问题。不同序列映射到不同实数，所以这是单射。

因此 $|\{0, 1\}^\mathbb{N}| \leq |\mathbb{R}|$，即 $|\mathcal{P}(\mathbb{N})| \leq |\mathbb{R}|$。

**步骤 3**：构造单射 $\mathbb{R} \hookrightarrow \mathcal{P}(\mathbb{N})$。

先证 $|\mathbb{R}| = |(0, 1)|$（通过双射 $f(x) = \frac{1}{1 + e^{-x}}$）。

然后对每个 $x \in (0, 1)$，取其唯一的不以无穷个 $1$ 结尾的二进制展开 $x = 0.b_1 b_2 b_3 \ldots$（当有两种展开时，选择不以 $111\ldots$ 结尾的那个）。定义 $g(x) = \{n \in \mathbb{N}^+ \mid b_n = 1\} \in \mathcal{P}(\mathbb{N}^+) \approx \mathcal{P}(\mathbb{N})$。

由于我们选择了唯一的展开方式，$g$ 是单射。

因此 $|\mathbb{R}| \leq |\mathcal{P}(\mathbb{N})|$。

**步骤 4**：由 Schröder-Bernstein 定理，$|\mathcal{P}(\mathbb{N})| = |\mathbb{R}|$。$\blacksquare$

## 挑战题 2：$(0, 1)$ 与 $\mathbb{R}$ 的显式双射

**问题**：构造一个从开区间 $(0, 1)$ 到全体实数 $\mathbb{R}$ 的**显式双射**。

### 提示

- 考虑三角函数或分式变换。
- 需要一个在 $(0, 1)$ 上有定义、值域为 $\mathbb{R}$ 的严格单调函数。

### 解答大纲

**方法 1（正切函数）**：

定义 $f: (0, 1) \to \mathbb{R}$：

$$f(x) = \tan\left(\pi x - \frac{\pi}{2}\right)$$

**分析**：

- $f$ 是 $\tan$ 函数在区间 $(-\pi/2, \pi/2)$ 上的复合。当 $x$ 从 $0$ 增加到 $1$ 时，$\pi x - \pi/2$ 从 $-\pi/2$ 增加到 $\pi/2$。
- $\tan$ 在 $(-\pi/2, \pi/2)$ 上是严格递增的，值域为 $\mathbb{R}$。
- 因此 $f$ 是严格递增函数，从 $(0, 1)$ 到 $\mathbb{R}$。

**单射**：严格递增函数是单射。设 $f(x_1) = f(x_2)$。则 $\tan(\pi x_1 - \pi/2) = \tan(\pi x_2 - \pi/2)$。由于 $\tan$ 在 $(-\pi/2, \pi/2)$ 上是严格单调的（因此是单射），$\pi x_1 - \pi/2 = \pi x_2 - \pi/2$，即 $x_1 = x_2$。✓

**满射**：对任意 $y \in \mathbb{R}$，由于 $\tan$ 在 $(-\pi/2, \pi/2)$ 上的值域是 $\mathbb{R}$，存在唯一的 $\theta \in (-\pi/2, \pi/2)$ 使得 $\tan\theta = y$。令 $x = (\theta + \pi/2)/\pi$，则 $x \in (0, 1)$ 且 $f(x) = y$。✓

**逆函数**：$f^{-1}(y) = \frac{1}{\pi}\arctan(y) + \frac{1}{2}$。$\blacksquare$

**方法 2（分式变换）**：

定义 $g: (0, 1) \to \mathbb{R}$：

$$g(x) = \frac{2x - 1}{x(1 - x)}$$

$g$ 在 $(0, 1)$ 上连续、严格递增，$\lim_{x \to 0^+} g(x) = -\infty$, $\lim_{x \to 1^-} g(x) = +\infty$。

由中间值定理，$g$ 的值域为 $\mathbb{R}$。由严格递增，$g$ 是单射。因此 $g$ 是双射。

验证严格递增：$g'(x) = \frac{2x^2 - 2x + 1}{x^2(1-x)^2}$。分子 $2x^2 - 2x + 1$ 的判别式 $\Delta = 4 - 8 = -4 < 0$，且首项系数为正，所以 $2x^2 - 2x + 1 > 0$ 对所有 $x$ 成立。分母 $x^2(1-x)^2 > 0$ 在 $(0, 1)$ 上成立。因此 $g'(x) > 0$，$g$ 严格递增。$\blacksquare$

## 挑战题 3：希尔伯特旅馆（Hilbert's Hotel）

**问题**：

希尔伯特旅馆是一座有可数无穷多个房间的旅馆，房间编号为 $1, 2, 3, \ldots$。旅馆已经客满（每个房间恰好住了一位客人）。

**(a)** 一位新客人到来。证明旅馆仍然可以接待这位新客人（不需要任何人退房）。描述具体的安排方案。

**(b)** 一辆载有可数无穷多位新客人的大巴到来（客人编号为 $1, 2, 3, \ldots$）。证明旅馆仍然可以接待所有新客人。

**(c)** 可数无穷多辆大巴到来，每辆大巴载有可数无穷多位客人。证明旅馆仍然可以接待所有新客人。

**(d)** 解释以上结果与集合论中哪些定理对应。

### 提示

- (a) 让每位现有客人搬到下一个房间。
- (b) 利用偶数和奇数。
- (c) 利用 $\mathbb{N} \times \mathbb{N}$ 的可数性（Cantor 配对函数）。

### 解答大纲

**(a)** 一位新客人。

令现在住在房间 $n$ 的客人搬到房间 $n + 1$（对所有 $n \geq 1$）。房间 $1$ 空出，新客人入住房间 $1$。

这对应双射 $f: \mathbb{N}^+ \to \mathbb{N}^+ \setminus \{0\}$... 更准确地说：

定义新的分配：原先住在房间 $n$ 的客人 → 房间 $n + 1$。新客人 → 房间 $1$。

形式化：$\{1, 2, 3, \ldots\}$（原客人）$\cup \{\text{新客人}\}$ 到 $\{1, 2, 3, \ldots\}$（房间）的双射：新客人 $\mapsto 1$，原客人 $n \mapsto n + 1$。

这证明了 $|\mathbb{N}^+| = |\mathbb{N}^+ \cup \{*\}|$，即可数集加一个元素后仍然可数。$\blacksquare$

**(b)** 可数无穷位新客人。

令原先住在房间 $n$ 的客人搬到房间 $2n$。这空出了所有奇数编号的房间：$1, 3, 5, 7, \ldots$

将大巴上编号为 $k$ 的新客人安排到房间 $2k - 1$。

形式化：原客人 $n \mapsto 2n$，新客人 $k \mapsto 2k - 1$。

这是 $\mathbb{N}^+ \cup \mathbb{N}^+$（两份可数集的并）到 $\mathbb{N}^+$ 的双射，证明了两个可数集的并仍然可数。$\blacksquare$

**(c)** 可数无穷辆大巴，每辆载可数无穷位客人。

将所有需要安排的人组织为二维索引：大巴 $i$ 上的客人 $j$（加上原住客可视为"大巴 $0$"上的客人）。

需要构造 $\mathbb{N} \times \mathbb{N} \to \mathbb{N}^+$ 的双射。使用 Cantor 配对函数或对角线排列法。

**对角线排列法**：将 $(i, j)$ 按 $i + j$ 的值分组，同组内按 $i$ 从小到大排列：

$$(0,0), (1,0), (0,1), (2,0), (1,1), (0,2), (3,0), (2,1), (1,2), (0,3), \ldots$$

这给出了 $\mathbb{N} \times \mathbb{N}$ 的一个列举，对应双射 $\mathbb{N} \times \mathbb{N} \to \mathbb{N}$。

将大巴 $i$ 上的客人 $j$ 安排到对应的房间号。

这证明了 $|\mathbb{N} \times \mathbb{N}| = |\mathbb{N}|$，即可数个可数集的并仍然可数。$\blacksquare$

**(d)** 对应关系：

| 情境 | 集合论定理 |
|------|-----------|
| (a) 接待 1 位新客人 | $\aleph_0 + 1 = \aleph_0$（可数集加有限元素仍可数） |
| (b) 接待可数无穷位新客人 | $\aleph_0 + \aleph_0 = \aleph_0$（两个可数集的并可数） |
| (c) 接待可数无穷辆大巴的客人 | $\aleph_0 \cdot \aleph_0 = \aleph_0$（$\mathbb{N} \times \mathbb{N}$ 可数） |

希尔伯特旅馆的"悖论"不是真正的矛盾——它只是无穷集合的直觉违反有限经验的一个生动例子。一个可数无穷集可以与自身的真子集等势，这是 Dedekind 无限的定义特征。

## 挑战题 4：Cantor-Bernstein 定理的应用

**问题**：不直接构造双射，用 Schröder-Bernstein 定理证明 $|(0, 1)| = |[0, 1]|$。

### 提示

- 构造单射 $(0, 1) \hookrightarrow [0, 1]$（显然——恒等映射）。
- 构造单射 $[0, 1] \hookrightarrow (0, 1)$（线性变换压缩到子区间）。

### 解答大纲

**单射 1**：$f: (0, 1) \to [0, 1]$，$f(x) = x$（恒等嵌入，即包含映射）。显然是单射。✓

**单射 2**：$g: [0, 1] \to (0, 1)$，$g(x) = \frac{1}{4} + \frac{x}{2}$。

$g$ 的值域为 $[1/4, 3/4] \subset (0, 1)$。$g$ 是线性函数，严格递增，因此是单射。✓

由 Schröder-Bernstein 定理，存在双射 $(0, 1) \to [0, 1]$。因此 $|(0, 1)| = |[0, 1]|$。$\blacksquare$

**注**：直接构造双射 $(0, 1) \to [0, 1]$ 需要更多技巧（因为需要处理端点 $0$ 和 $1$）。Schröder-Bernstein 定理让我们绕过了这个困难。一种直接构造如下：

选择可数集 $S = \{0, 1, 1/2, 1/3, 1/4, \ldots\} \subset [0, 1]$。定义 $h: [0, 1] \to (0, 1)$：

$$h(x) = \begin{cases} 1/(n+2), & \text{若 } x = 1/n,\, n \in \mathbb{N}^+ \\ 1/2, & \text{若 } x = 0 \\ 1/3, & \text{若 } x = 1 \\ x, & \text{若 } x \notin S \end{cases}$$

即将 $0 \mapsto 1/2$, $1 \mapsto 1/3$, $1/n \mapsto 1/(n+2)$，其余点不动。可以验证这是一个双射。
