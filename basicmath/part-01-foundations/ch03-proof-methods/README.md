# 第 3 章：证明方法（Proof Methods）

## 章概览

证明是数学的灵魂。

前两章建立了数学推理的语言——逻辑（第 1 章）告诉我们什么是合法的推理，集合论（第 2 章）给了我们描述数学对象的工具。但仅有语言和对象还不够：数学的核心活动是**证明**（proof）。一个数学命题，无论看起来多么合理，在被严格证明之前，都只是一个**猜想**（conjecture）。

证明不是简单的"验证几个例子"。验证 $1 + 3 = 4$、$1 + 3 + 5 = 9$、$1 + 3 + 5 + 7 = 16$ 并不能证明"前 $n$ 个奇数之和等于 $n^2$"——它可能对前一万个 $n$ 成立，但在第一万零一个处失败。证明要求我们对**所有**情况给出严密的论证。

本章教授最常用的证明方法。这不是一门抽象的"关于证明的理论"，而是一门实践技能——就像学游泳不能只看书，学证明也必须亲自动手。每一节都包含大量完整的证明示例，每一个例题都展示了证明的完整过程。

学完本章，你将掌握一套证明工具箱，足以应对后续章节中遇到的绝大多数证明任务。

## 前置知识

- **[第 1 章 逻辑](../ch01-logic/README.md)**：命题逻辑（联结词、蕴含、逻辑等价、逆否命题）和谓词逻辑（全称量词 $\forall$、存在量词 $\exists$、否定的处理）。证明的每一步都是一次逻辑推理——不理解逻辑就无法理解证明。
- **[第 2 章 集合论](../ch02-sets/README.md)**：集合的基本概念（子集、并集、交集、补集）和关系。本章的许多证明示例涉及集合性质，集合等式的元素法证明本身就是直接证明的典型应用。

## 本章完成后你将能够

- **理解证明的本质**：区分"验证几个例子"与"严格证明"，认识到证明是从公理和已知定理出发的逻辑推理链
- **运用直接证明**：对 $P \to Q$ 形式的命题，假设 $P$ 为真，通过逻辑推理得出 $Q$
- **运用反证法**：当直接证明困难时，假设结论为假，推导出矛盾，从而确立结论为真
- **运用数学归纳法**：对涉及自然数的命题，通过验证基础步骤和证明归纳步骤来完成证明
- **构造性地证明存在性**：通过显式给出满足条件的对象来证明"存在"类命题
- **用反例推翻全称命题**：理解一个反例就足以推翻"对所有…都成立"的断言
- **识别证明策略**：面对一个需要证明的命题，能够判断哪种证明方法最合适
