## §1 直接证明（Direct Proof）

**练习 1.1** ★☆☆
证明：若 $m$ 和 $n$ 都是奇数，则 $m + n$ 是偶数。

**练习 1.2** ★☆☆
证明：若 $m$ 是偶数且 $n$ 是奇数，则 $mn$ 是偶数。

**练习 1.3** ★☆☆
证明：若整数 $a \mid b$ 且 $a \mid c$，则对任意整数 $m, n$，$a \mid (mb + nc)$。

**练习 1.4** ★★☆
证明：两个有理数之和是有理数。

**练习 1.5** ★★☆
证明：若 $n$ 是整数，则 $n^3 - n$ 是偶数。
（提示：$n^3 - n = n(n-1)(n+1)$，三个连续整数之积。）

**练习 1.6** ★★☆
证明：对任意实数 $a, b$，$|ab| = |a| \cdot |b|$。
（提示：分情况讨论 $a, b$ 的正负。）

**练习 1.7** ★★☆
证明集合等式：对任意集合 $A, B$，$(A \cup B) \setminus B = A \setminus B$。
（使用元素法。）

**练习 1.8** ★★☆
证明：若 $a, b, c$ 是整数且 $a \mid b$，则 $a \mid (bc)$。

**练习 1.9** ★★★
证明：对任意实数 $a, b, c$，
$$a^2 + b^2 + c^2 \geq ab + bc + ca$$
（提示：考虑 $(a-b)^2 + (b-c)^2 + (c-a)^2$。）

**练习 1.10** ★★★
证明集合等式（De Morgan 律）：对任意集合 $A, B$ 以及全集 $U$，
$$\overline{A \cup B} = \overline{A} \cap \overline{B}$$
其中 $\overline{X} = U \setminus X$ 表示 $X$ 关于 $U$ 的补集。

**练习 1.11** ★★★
证明：若 $x$ 是正实数且 $x + \frac{1}{x} = 2$，则 $x = 1$。
（提示：在直接证明中，利用 $(x - 1)^2 = 0$。）

## §2 反证法（Proof by Contradiction）

**练习 2.1** ★☆☆
用反证法证明：不存在最小的正实数。

**练习 2.2** ★☆☆
用反证法证明：若 $n^2$ 是奇数，则 $n$ 是奇数。

**练习 2.3** ★★☆
用反证法证明：$\sqrt{5}$ 是无理数。
（提示：仿照 $\sqrt{2}$ 的证明。需要用到引理：若 $5 \mid n^2$，则 $5 \mid n$。）

**练习 2.4** ★★☆
用反证法证明：若 $a$ 和 $b$ 是实数且 $a$ 是无理数，则 $a - b$ 是无理数或 $b$ 是无理数。

**练习 2.5** ★★☆
用逆否法证明：若 $n^3 + 5$ 是奇数，则 $n$ 是偶数。

**练习 2.6** ★★☆
证明：$\sqrt{2} + \sqrt{3}$ 是无理数。
（提示：假设 $\sqrt{2} + \sqrt{3} = r \in \mathbb{Q}$，则 $\sqrt{3} - \sqrt{2} = \frac{1}{r}$，相加得 $2\sqrt{3} = r + \frac{1}{r}$。）

**练习 2.7** ★★☆
用反证法证明：若 $a, b \in \mathbb{R}$ 且 $a \neq b$，则 $a$ 和 $b$ 之间存在有理数。
（提示：利用 Archimedean 性质——对任意正实数 $\epsilon$，存在正整数 $n$ 使得 $1/n < \epsilon$。）

**练习 2.8** ★★★
证明：$\log_{10} 2$ 是无理数。

**练习 2.9** ★★★
用反证法证明：对任意正整数 $n$，$\sqrt{n}$ 要么是整数，要么是无理数（没有中间状态）。
（提示：假设 $\sqrt{n} = p/q$ 是非整数有理数，$\gcd(p, q) = 1$，$q \geq 2$。推出矛盾。）

**练习 2.10** ★★★
证明：不存在有理数 $r$ 使得 $r^2 = 6$。

## §3 数学归纳法（Mathematical Induction）

**练习 3.1** ★☆☆
用归纳法证明：对所有正整数 $n$，$\sum_{i=1}^{n}(2i - 1) = n^2$（前 $n$ 个奇数之和等于 $n^2$）。

**练习 3.2** ★☆☆
用归纳法证明：对所有非负整数 $n$，$\sum_{i=0}^{n} 3^i = \frac{3^{n+1} - 1}{2}$。

**练习 3.3** ★★☆
用归纳法证明：对所有正整数 $n$，$n^3 + 2n$ 能被 $3$ 整除。

**练习 3.4** ★★☆
用归纳法证明：对所有正整数 $n$，$7^n - 1$ 能被 $6$ 整除。

**练习 3.5** ★★☆
用归纳法证明 Bernoulli 不等式：对所有非负整数 $n$ 和实数 $x \geq -1$，
$$(1 + x)^n \geq 1 + nx$$

**练习 3.6** ★★☆
用归纳法证明：对所有正整数 $n$，
$$\frac{1}{1 \cdot 2} + \frac{1}{2 \cdot 3} + \frac{1}{3 \cdot 4} + \cdots + \frac{1}{n(n+1)} = \frac{n}{n+1}$$

**练习 3.7** ★★★
用强归纳法证明：每个正整数都可以表示为若干个不同的 $2$ 的幂之和（即二进制表示的存在性）。

**练习 3.8** ★★★
用归纳法证明：$2^n > n^2$ 对所有 $n \geq 5$ 成立。

**练习 3.9** ★★★
指出以下"归纳证明"中的错误：

"定理"：所有正整数都相等。

"证明"：令 $P(n)$ 为命题"在任何包含 $n$ 个正整数的集合中，所有元素相等"。

基础步骤：$P(1)$——只有一个元素的集合中，所有元素（就是那一个）当然相等。

归纳步骤：假设 $P(k)$ 成立。考虑一个包含 $k + 1$ 个正整数的集合 $\{a_1, a_2, \ldots, a_{k+1}\}$。去掉 $a_{k+1}$ 得到 $\{a_1, \ldots, a_k\}$，由 $P(k)$，$a_1 = a_2 = \cdots = a_k$。去掉 $a_1$ 得到 $\{a_2, \ldots, a_{k+1}\}$，由 $P(k)$，$a_2 = \cdots = a_{k+1}$。因此 $a_1 = a_2 = \cdots = a_{k+1}$。

**练习 3.10** ★★★
用归纳法证明：$n$ 个点的完全图（每两个点之间有一条边）共有 $\frac{n(n-1)}{2}$ 条边。

**练习 3.11** ★★★
用良序原理证明：若 $a, b$ 为正整数，则存在正整数 $d$ 使得 $d = \gcd(a, b)$ 且 $d$ 可以表示为 $d = ax + by$（$x, y \in \mathbb{Z}$）。
（提示：令 $S = \{ax + by \mid x, y \in \mathbb{Z},\, ax + by > 0\}$，取 $S$ 的最小元。）

## §4 构造性证明与反例（Constructive Proofs & Counterexamples）

**练习 4.1** ★☆☆
找反例：对所有实数 $x$，$x^2 \neq x$。

**练习 4.2** ★☆☆
找反例：若 $a \mid (bc)$，则 $a \mid b$ 或 $a \mid c$。

**练习 4.3** ★☆☆
构造一个无理数 $x$ 使得 $x^2$ 是有理数。

**练习 4.4** ★★☆
反驳命题：对所有集合 $A, B, C$，若 $A \cap B = A \cap C$，则 $B = C$。

**练习 4.5** ★★☆
构造一个从正偶数集到正整数集的双射。

**练习 4.6** ★★☆
用鸽巢原理证明：在任意 $27$ 个英文单词中，至少有两个以相同的字母开头。

**练习 4.7** ★★☆
用鸽巢原理证明：在 $n + 1$ 个正整数中（每个不超过 $2n$），必有两个数互相整除。
（提示：将每个数写成 $2^s \cdot t$（$t$ 为奇数），按 $t$ 分类。$1$ 到 $2n$ 之间的奇数只有 $n$ 个。）

**练习 4.8** ★★★
构造一个从 $\mathbb{N} \times \mathbb{N}$ 到 $\mathbb{N}$ 的双射。
（提示：考虑对角线遍历或使用 Cantor 配对函数 $f(m, n) = \frac{(m + n)(m + n + 1)}{2} + m$。）

**练习 4.9** ★★★
用鸽巢原理证明：对任意 $n$ 个整数 $a_1, a_2, \ldots, a_n$，存在 $i, j$（$1 \leq i \leq j \leq n$）使得 $a_i + a_{i+1} + \cdots + a_j$ 是 $n$ 的倍数。
（提示：考虑前缀和 $S_k = a_1 + \cdots + a_k$ 的 $\bmod n$ 值。）

**练习 4.10** ★★★
反驳或证明：存在连续的 $100$ 个正整数，其中没有一个是质数。
（提示：考虑 $101! + 2, 101! + 3, \ldots, 101! + 101$。）
