# 第一部分：数学基础（Foundations）

## 本部分概览

数学是一座宏伟的大厦，而逻辑、集合论和证明方法就是这座大厦的地基。没有地基，一切上层建筑——代数、几何、分析——都无从谈起。

本部分包含三章：

| 章 | 主题 | 内容 |
|----|------|------|
| [第 1 章：逻辑](ch01-logic/README.md) | 数理逻辑（mathematical logic） | 命题逻辑、谓词逻辑——数学推理的语言 |
| [第 2 章：集合论](ch02-sets/README.md) | 集合论（set theory） | 集合运算、关系、函数的集合论定义——数学对象的容器 |
| [第 3 章：证明方法](ch03-proof-methods/README.md) | 证明技术（proof techniques） | 直接证明、反证法、数学归纳法、构造性证明——数学论证的工具箱 |

这三章的关系是层层递进的：逻辑提供语言，集合论提供对象，证明方法提供工具。掌握这三者之后，你就拥有了阅读和书写数学的基本能力。

## 学习路线

```
Ch01 逻辑 → Ch02 集合论 → Ch03 证明方法
```

三章必须按顺序学习：

- **第 1 章（逻辑）** 是起点，不依赖任何前置知识。逻辑为后续所有内容提供推理语言。
- **第 2 章（集合论）** 依赖第 1 章的逻辑联结词和量词，用逻辑语言定义集合运算。
- **第 3 章（证明方法）** 综合运用逻辑和集合论的工具，系统学习各种证明技术。

## 预估总学习时间

**约 20–25 小时**，分配如下：

| 章 | 预估时间 |
|----|----------|
| 第 1 章：逻辑 | 5–6 小时 |
| 第 2 章：集合论 | 7–9 小时 |
| 第 3 章：证明方法 | 8–10 小时 |

## 前置知识

**无。** 这是整本教材的起点。你只需要识字、会基本算术，以及——最重要的——愿意严格地思考。

## 本部分完成后你将能够

- **理解并运用命题逻辑**：判断命题真假，构建真值表，运用逻辑等价律化简命题
- **理解并运用谓词逻辑**：使用全称量词和存在量词精确表达数学命题，正确否定含量词的命题
- **掌握集合论的基本工具**：进行集合运算（并、交、补、差、笛卡尔积），理解关系和函数的集合论定义
- **独立进行数学证明**：运用直接证明、反证法、数学归纳法、构造性证明等方法，独立完成中等难度的数学证明
- **阅读数学文献**：具备阅读后续各章（以及其他数学教材）的基本能力
