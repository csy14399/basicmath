## 挑战题 1：函数方程

设 $f: \mathbb{R} \to \mathbb{R}$ 满足 $f(xf(y) + x) = xy + f(x)$ 对所有 $x, y \in \mathbb{R}$ 成立。求 $f$。

### 提示

- 令 $x = 0$ 和 $y = 0$ 分别代入，获取 $f(0)$ 的信息。
- 令 $x = 1$ 获得 $f$ 的表达式线索。

### 解答

**步骤 1**：令 $x = 0$：$f(0 \cdot f(y) + 0) = 0 \cdot y + f(0)$，即 $f(0) = f(0)$（恒真，无信息）。

**步骤 2**：令 $y = 0$：$f(xf(0) + x) = f(x)$，即 $f(x(f(0) + 1)) = f(x)$。

若 $f(0) + 1 \neq 1$（即 $f(0) \neq 0$），则 $f$ 是周期函数，但原方程右边 $xy + f(x)$ 包含线性项 $xy$，这与周期性矛盾（令 $x = 1$：$f(f(y) + 1) = y + f(1)$，$f$ 的值域包含所有实数且是线性增长的）。因此 $f(0) = 0$。

**步骤 3**：由 $f(0) = 0$，令 $x = 1$：$f(f(y) + 1) = y + f(1)$。设 $c = f(1)$，则 $f(f(y) + 1) = y + c$。

**步骤 4**：令 $y = -c$（在步骤 3 中）：$f(f(-c) + 1) = 0$。由 $f(0) = 0$，若 $f$ 是单射则 $f(-c) + 1 = 0$，即 $f(-c) = -1$。

**步骤 5**：在原方程中令 $y = -c$：$f(xf(-c) + x) = -cx + f(x)$，即 $f(-x + x) = f(0) = 0 = -cx + f(x)$，因此 $f(x) = cx$ 对所有 $x$。

**步骤 6**：代回原方程验证：$f(x \cdot cy + x) = c(cxy + x) = c^2 xy + cx$，而 $xy + f(x) = xy + cx$。因此 $c^2 = 1$，$c = \pm 1$。

**结论**：$f(x) = x$ 或 $f(x) = -x$。

验证 $f(x) = x$：$f(xy + x) = xy + x = xy + f(x)$。✓

验证 $f(x) = -x$：$f(-xy + x) = -(-xy + x) = xy - x$，而 $xy + f(x) = xy - x$。✓

## 挑战题 2：迭代与不动点

设 $f(x) = \frac{x}{1 + x}$（$x > 0$）。定义 $f$ 的 $n$ 次迭代 $f^{(n)}$ 为 $f$ 复合自身 $n$ 次：$f^{(1)} = f$，$f^{(n)} = f \circ f^{(n-1)}$。

(a) 计算 $f^{(2)}(x)$、$f^{(3)}(x)$。

(b) 猜测 $f^{(n)}(x)$ 的一般公式并用数学归纳法证明。

(c) 求 $\lim_{n \to \infty} f^{(n)}(x)$（$x > 0$）。

### 解答

**(a)**

$$f^{(2)}(x) = f\left(\frac{x}{1+x}\right) = \frac{\frac{x}{1+x}}{1 + \frac{x}{1+x}} = \frac{\frac{x}{1+x}}{\frac{1+2x}{1+x}} = \frac{x}{1 + 2x}$$

$$f^{(3)}(x) = f\left(\frac{x}{1+2x}\right) = \frac{\frac{x}{1+2x}}{1 + \frac{x}{1+2x}} = \frac{x}{1 + 3x}$$

**(b)** 猜测 $f^{(n)}(x) = \frac{x}{1 + nx}$。

**归纳证明**：$n = 1$ 时 $f^{(1)}(x) = \frac{x}{1+x}$，成立。

设 $f^{(k)}(x) = \frac{x}{1 + kx}$。则

$$f^{(k+1)}(x) = f\left(\frac{x}{1+kx}\right) = \frac{\frac{x}{1+kx}}{1 + \frac{x}{1+kx}} = \frac{x}{1 + kx + x} = \frac{x}{1 + (k+1)x}$$

归纳完成。$\blacksquare$

**(c)** 对 $x > 0$：$f^{(n)}(x) = \frac{x}{1 + nx} = \frac{1}{\frac{1}{x} + n} \to 0$ 当 $n \to \infty$。

迭代的"不动点"是方程 $f(x) = x$ 的解：$\frac{x}{1+x} = x$ $\implies$ $x = x + x^2$ $\implies$ $x^2 = 0$ $\implies$ $x = 0$。所有正数轨道都趋向不动点 $0$。

## 挑战题 3：函数的对称与周期

设 $f$ 满足 $f(a + x) = f(a - x)$（关于 $x = a$ 对称）和 $f(b + x) = -f(b - x)$（关于 $(b, 0)$ 反对称），其中 $b > a$。

(a) 证明 $f$ 是周期函数。

(b) 求最小正周期的一个上界。

(c) 若另外已知 $f(a) = 1$，求 $f(b)$。

### 解答

**(a)** 由 $f(a + x) = f(a - x)$ 令 $x \to x - a$：$f(x) = f(2a - x)$ ……(I)

由 $f(b + x) = -f(b - x)$ 令 $x \to x - b$：$f(x) = -f(2b - x)$ ……(II)

由 (I)：$f(2a - x) = f(x)$。在 (II) 中用 $2a - x$ 替换 $x$：

$f(2a - x) = -f(2b - (2a - x)) = -f(2b - 2a + x)$

结合 $f(2a - x) = f(x)$：$f(x) = -f(2b - 2a + x)$ ……(III)

在 (III) 中用 $x + 2(b-a)$ 替换 $x$：

$f(x + 2(b-a)) = -f(2b - 2a + x + 2(b-a)) = -f(x + 4(b-a))$

而 (III) 直接给出 $f(x + 2(b-a)) = -f(x)$。因此

$-f(x) = -f(x + 4(b-a))$，即 $f(x) = f(x + 4(b-a))$。

$f$ 是周期函数，$T = 4(b - a)$ 是一个周期。$\blacksquare$

**(b)** 最小正周期不超过 $4(b - a)$。

**(c)** 在 (II) 中令 $x = b$：$f(b) = -f(2b - b) = -f(b)$，因此 $2f(b) = 0$，$f(b) = 0$。
