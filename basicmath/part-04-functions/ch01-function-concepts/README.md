# 第 1 章：函数概念（Function Concepts）

## 章概览

在 Part 1 的集合论中，我们已经从最抽象的层面认识了函数——它是满足特定条件的二元关系。但那时的定义是"骨架"，现在我们要为它注入"血肉"。

本章要做的是**从集合论的抽象定义过渡到函数的具体分析**。我们将学习如何精确地描述一个函数的"行为特征"——它在哪里增大、在哪里减小？它有没有上界？它关于某个轴对称吗？它的图像会不会周期性地重复？我们还将学习如何"组合"两个函数（复合函数）和"反转"一个函数（反函数），这两个操作是函数论的基本工具。

## 学习成果

本章完成后你将能够：

- **精确描述函数的定义域和值域**：区分定义域、陪域和值域的概念
- **判断和证明函数的单调性、有界性、奇偶性和周期性**
- **计算复合函数并确定其定义域**
- **判断函数是否可逆，并求出反函数**
- **理解反函数图像与原函数图像的对称关系**
- **为后续章节的具体函数研究奠定概念基础**
