## 1. 函数概念的历史演变

### 从运动到对应

"函数"这个词（Latin: *functio*）首次出现在数学中是 Leibniz（1694 年）的作品中，但他用它仅仅指代曲线上的某些几何量（如斜率、曲率）。

**Euler**（18 世纪）将函数理解为"由变量和常量组成的解析表达式"。在他看来，$f(x) = x^2 + \sin x$ 是函数，但

$$f(x) = \begin{cases} x, & x \geq 0 \\ -x, & x < 0 \end{cases}$$

不是"真正的"函数——因为它由两个不同的表达式定义。这在今天看来很奇怪，因为我们将这个函数简单地写为 $f(x) = |x|$。

**Fourier**（19 世纪初）在研究热传导时发现，"任意"函数——哪怕是完全不规则的——都可以用三角级数（Fourier 级数）表示。这迫使数学家重新思考"函数"到底是什么。

**Dirichlet**（1837 年）给出了现代函数定义的雏形：函数是两个变量之间的**任意对应关系**，不要求由单一公式给出。他构造的 Dirichlet 函数 $D(x)$（有理数取 $1$、无理数取 $0$）就是一个无法用任何公式表达的函数——它颠覆了 Euler 时代的函数概念。

**Bourbaki 学派**（20 世纪）最终将函数定义为满足特定条件的集合论关系，完成了从直觉到形式的旅程。

### 教训

函数概念的演变告诉我们：数学定义不是一成不变的。当新的例子和新的需求出现时，旧定义会被修正和推广。从 Euler 的"解析表达式"到 Dirichlet 的"任意对应"，再到 Bourbaki 的集合论定义，每一次推广都使数学能够处理更广泛的现象。

## 2. 病态函数（Pathological Functions）

### Dirichlet 函数

我们在正文中已经遇到了 Dirichlet 函数

$$D(x) = \begin{cases} 1, & x \in \mathbb{Q} \\ 0, & x \notin \mathbb{Q} \end{cases}$$

这个函数在每一点都不连续。它挑战了"函数应该是'合理'的"这一直觉。

### Thomae 函数（爆米花函数）

一个更精巧的例子是 Thomae 函数（1875 年）：

$$T(x) = \begin{cases} \frac{1}{q}, & x = \frac{p}{q} \in \mathbb{Q}，\text{其中 } \gcd(p,q) = 1, q > 0 \\ 0, & x \notin \mathbb{Q} \end{cases}$$

惊人的事实：$T(x)$ 在所有**无理数**处连续，在所有**有理数**处不连续。

**直觉**：在无理数 $\alpha$ 附近，有理数 $\frac{p}{q}$ 要接近 $\alpha$，需要很大的 $q$，这使得 $T\left(\frac{p}{q}\right) = \frac{1}{q}$ 很小。因此在 $\alpha$ 附近 $T$ 的值都接近 $0 = T(\alpha)$。

### 处处连续但处处不可微的函数

Weierstrass（1872 年）构造了函数

$$W(x) = \sum_{n=0}^{\infty} a^n \cos(b^n \pi x)$$

其中 $0 < a < 1$，$b$ 为正奇数，$ab > 1 + \frac{3}{2}\pi$。这个函数处处连续但在任何一点都没有导数。它粉碎了"连续函数应该处处（或几乎处处）可微"的信念。

## 3. 不动点理论

### 不动点

函数 $f$ 的**不动点**（fixed point）是满足 $f(x) = x$ 的点。几何上，不动点就是函数图像与直线 $y = x$ 的交点。

### Brouwer 不动点定理（一维情形）

> 设 $f: [a, b] \to [a, b]$ 是连续函数。则 $f$ 至少有一个不动点。

**证明思路**：令 $g(x) = f(x) - x$。$g(a) = f(a) - a \geq 0$（因为 $f(a) \in [a,b]$），$g(b) = f(b) - b \leq 0$（因为 $f(b) \in [a,b]$）。由介值定理（将在 Part 6 严格讨论），存在 $c \in [a,b]$ 使得 $g(c) = 0$，即 $f(c) = c$。

这个定理看似简单，但其高维推广（Brouwer 不动点定理的一般形式）是拓扑学的深刻结果，在博弈论（Nash 均衡的存在性）和经济学中有重要应用。

### 压缩映射原理

> 设 $(X, d)$ 是完备度量空间，$f: X \to X$ 是压缩映射（存在 $0 < c < 1$ 使得 $d(f(x), f(y)) \leq c \cdot d(x, y)$）。则 $f$ 恰好有一个不动点，且从任意初始点出发的迭代序列都收敛到这个不动点。

这个定理的证明是构造性的：取任意 $x_0$，定义 $x_{n+1} = f(x_n)$，序列 $\{x_n\}$ 收敛到唯一不动点。它在微分方程、数值分析中有广泛应用。

## 4. 函数空间——当函数本身成为"点"

在现代数学中，一个深刻的思想转变是：**函数本身可以视为一个"点"**，函数的集合构成一个"空间"。

例如，所有从 $[0, 1]$ 到 $\mathbb{R}$ 的连续函数组成的集合 $C[0, 1]$ 可以定义"距离"：

$$d(f, g) = \max_{x \in [0,1]} |f(x) - g(x)|$$

这样 $C[0, 1]$ 成为一个**度量空间**。在这个空间中，"两个函数很接近"意味着它们的图像在每一点都很接近。函数列的"收敛"意味着一串函数的图像逐渐趋向某个极限函数的图像。

这种视角——将函数空间视为几何对象——是泛函分析（functional analysis）的基础，在量子力学、偏微分方程、优化理论中无处不在。

## 5. 一个哲学问题：函数是规则还是对应？

考虑两个"函数"：

$$f(x) = (x+1)^2 - 2x - 1$$

$$g(x) = x^2$$

作为表达式，它们看起来不同。但化简后 $f(x) = x^2 + 2x + 1 - 2x - 1 = x^2 = g(x)$。

**$f$ 和 $g$ 是同一个函数吗？**

在现代数学的集合论定义下，答案是**是的**——函数由其**图像**（集合 $\{(x, f(x))\}$）决定，不由给出它的表达式决定。只要 $f(x) = g(x)$ 对所有 $x$ 成立，$f$ 和 $g$ 就是同一个函数。

但在计算机科学和类型论（type theory）中，答案可能是**不同的**。两个函数可能有不同的计算过程（算法），即使它们在所有输入上给出相同的输出。**外延等价**（extensional equality，输出相同）和**内涵等价**（intensional equality，定义相同）之间的区别，是数学基础和计算机科学中的一个深刻问题。
