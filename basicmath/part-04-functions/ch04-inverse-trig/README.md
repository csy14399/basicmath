# 第 4 章：反三角函数（Inverse Trigonometric Functions）

## 章概览

在 Part 4 第 3 章中，我们系统地学习了三角函数——它们将角度（或弧度）映射为实数。但在实际问题中，我们经常遇到**逆向**需求：已知三角函数值，求角度。例如，已知 $\sin\theta = 0.6$，$\theta$ 是多少？

然而，三角函数是**周期函数**，因此不是单射——同一个函数值对应无穷多个角度。为了定义"反函数"，我们必须**限制定义域**，使三角函数在受限区间上成为双射。由此诞生的 $\arcsin$、$\arccos$、$\arctan$ 等函数，就是本章的主角。

反三角函数不仅在三角方程求解中不可或缺，更是微积分中重要的**反导数**来源（例如 $\int \frac{dx}{\sqrt{1-x^2}} = \arcsin x + C$），在物理学的角度计算和信号处理中也广泛应用。
