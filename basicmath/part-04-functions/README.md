# 第四部分：函数（Functions）

## 本部分概览

函数是数学中最核心的概念之一。如果说第一部分建立了逻辑推理的框架，第二部分认识了数的世界，第三部分掌握了代数工具，那么第四部分要做的就是**研究变量之间的依赖关系——函数**。

函数是连接代数与分析的桥梁。在代数中，我们解方程、化简表达式；在分析（微积分）中，我们研究函数的极限、连续性、可微性。要进入分析的大门，首先需要对函数的各大家族了如指掌。

本部分的叙事线如下：

1. **函数概念**——从集合论的抽象定义到具体性质，建立"函数思维"
2. **指数函数与对数函数**——增长与衰减的数学语言
3. **三角函数**——周期现象的数学语言
4. **反三角函数**——三角函数的"逆向操作"
5. **参数方程与极坐标**——超越直角坐标的描述方式

本部分包含五章：

| 章 | 主题 | 内容 |
|----|------|------|
| [第 1 章：函数概念](ch01-function-concepts/README.md) | 函数概念（function concepts） | 函数的深化定义、性质（单调性、有界性、奇偶性、周期性）、复合函数与反函数 |
| [第 2 章：指数函数与对数函数](ch02-exponential-log/README.md) | 指数与对数（exponential & logarithmic） | 指数的推广、指数函数、自然底数 $e$、对数定义与运算法则、对数函数图像与应用 |
| [第 3 章：三角函数](ch03-trigonometric/README.md) | 三角函数（trigonometric functions） | 弧度制、单位圆定义、六个三角函数、图像与变换、三角恒等式 |
| 第 4 章：反三角函数 | 反三角函数（inverse trigonometric） | arcsin、arccos、arctan 的定义、图像、性质与应用 |

这五章的关系：第一章建立函数的一般理论，为后续各章提供概念框架。第二章和第三章分别研究两大核心函数家族——指数/对数函数描述增长与衰减，三角函数描述周期与振荡。第四章利用反函数的一般理论（第一章）专门研究三角函数的逆，解决"已知函数值求角度"的问题。第五章拓展描述曲线的方式，为后续几何（Part 5）和微积分（Part 6–8）做准备。

## 本部分的主题：函数家族作为数学的工作马

贯穿本部分的核心思想是**具体函数家族的深入理解**：

1. **概念阶段**（Ch01）：什么是函数？函数有哪些一般性质？如何组合和"反转"函数？
2. **家族研究**（Ch02–Ch03）：指数/对数函数和三角函数是数学中使用频率最高的函数家族。它们分别刻画了"增长/衰减"和"周期/振荡"这两类最基本的自然现象。
3. **逆向思维**（Ch04）：反函数将"已知输入求输出"翻转为"已知输出求输入"，这在方程求解和微积分中至关重要。
4. **描述拓展**（Ch05）：参数方程和极坐标提供了更灵活的曲线描述方式，某些曲线在极坐标下有极其优雅的表达。

这些函数不仅是抽象的数学对象，更是科学和工程的工作马（workhorses）——从人口增长模型到电路分析，从天体运动到信号处理，它们无处不在。
