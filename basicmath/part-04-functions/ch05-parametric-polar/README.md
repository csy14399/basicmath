# 第 5 章：参数方程与极坐标（Parametric Equations & Polar Coordinates）

## 章概览

到目前为止，我们描述曲线的方式都是**直角坐标方程** $y = f(x)$ 或 $F(x, y) = 0$。然而，很多重要的曲线（如摆线、心形线、玫瑰线）用直角坐标方程表达非常复杂甚至不可能，却可以用**参数方程**或**极坐标**优雅地描述。

本章引入两种新的曲线描述方式：**参数方程**通过引入一个"中间变量"（参数）来分别表达 $x$ 和 $y$；**极坐标**则用距离原点的距离 $r$ 和与正 $x$ 轴的夹角 $\theta$ 来定位平面上的点。这两种工具极大地扩展了我们描述和分析曲线的能力，是微积分中弧长、面积和曲率计算的重要准备。
