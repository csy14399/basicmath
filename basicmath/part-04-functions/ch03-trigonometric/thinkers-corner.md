## 1. 三角学的历史——从天文学到纯数学

### 古代起源

三角学（trigonometry）的名字来源于希腊语 *trigonon*（三角形）和 *metron*（测量），但它的实际起源是**天文学**。

古希腊天文学家 **Hipparchus**（约公元前 190–120 年）被称为"三角学之父"。他编制了最早的**弦表**（table of chords）——本质上是 $2\sin(\theta/2)$ 的值表——用于计算天体的位置。

**Ptolemy**（约公元 100–170 年）在他的巨著《天文学大成》（*Almagest*）中，进一步完善了弦表并推导了等价于我们今天的和角公式的结果。

### 印度和阿拉伯的贡献

关键的概念飞跃发生在印度。公元五世纪的印度数学家 **Aryabhata** 首次引入了**半弦**（jyā-ardha，"half-chord"）的概念——这就是我们今天所说的 $\sin\theta$。之前的希腊人使用的是**全弦**（chord），即 $2\sin(\theta/2)$。

阿拉伯翻译者将梵语 *jyā* 音译为 *jība*，后来被误读为 *jaib*（阿拉伯语"口袋"的意思）。拉丁翻译者将 *jaib* 翻译为 *sinus*（拉丁语"口袋"或"弯曲"）——这就是 "sine" 的词源！整个命名过程是一个从梵语到阿拉伯语到拉丁语的误解链。

### 欧洲的发展

**Regiomontanus**（1436–1476）写了第一本独立于天文学的三角学教科书《论各种三角形》。

**Euler**（18 世纪）将三角函数从几何工具提升为**分析函数**——他用无穷级数定义 $\sin x$ 和 $\cos x$，发现了 $e^{ix} = \cos x + i\sin x$，彻底改变了三角学的面貌。

## 2. Fourier 分析——三角函数的统治力

### Fourier 的惊人宣言

1807 年，法国数学家 **Jean-Baptiste Joseph Fourier** 在研究热传导时提出了一个大胆的主张：**任何**（合理的）函数都可以表示为正弦和余弦的无穷级数（Fourier 级数）：

$$f(x) = \frac{a_0}{2} + \sum_{n=1}^{\infty}\left(a_n\cos nx + b_n\sin nx\right)$$

这个主张在当时引起了巨大争议——Lagrange 和其他数学家强烈反对。经过一个多世纪的严格化工作（Dirichlet、Riemann、Lebesgue 等人的贡献），Fourier 的直觉被证明基本正确。

### 应用无处不在

Fourier 分析是现代科学和工程的基石：

- **声音处理**：任何声波都可以分解为不同频率的正弦波的叠加。MP3 压缩就是利用这个原理，丢弃人耳不敏感的频率分量。
- **图像处理**：JPEG 压缩使用离散余弦变换（DCT），本质上是 Fourier 分析的变体。
- **量子力学**：波函数在位置空间和动量空间之间的转换就是 Fourier 变换。
- **数论**：Riemann zeta 函数的研究大量使用 Fourier 分析。

"三角函数无处不在"并非夸张——通过 Fourier 分析，它们成为了理解所有周期现象的通用语言。

## 3. $\sin x / x$ 的极限——微积分的起点

三角学与微积分的第一个接触点是极限

$$\lim_{x \to 0} \frac{\sin x}{x} = 1$$

（$x$ 用弧度衡量。如果用角度制，结果是 $\frac{\pi}{180}$——这就是为什么弧度制是"自然的"。）

### 几何证明思路

对 $0 < x < \pi/2$，在单位圆中比较三个面积：

1. **三角形 OAP** 的面积：$\frac{1}{2}\sin x$
2. **扇形 OAP** 的面积：$\frac{1}{2}x$
3. **三角形 OAT** 的面积（$T$ 是切线与 $x$ 轴的交点）：$\frac{1}{2}\tan x$

$$\frac{1}{2}\sin x < \frac{1}{2}x < \frac{1}{2}\tan x$$

除以 $\frac{1}{2}\sin x > 0$：

$$1 < \frac{x}{\sin x} < \frac{1}{\cos x}$$

取倒数：$\cos x < \frac{\sin x}{x} < 1$。

当 $x \to 0$ 时 $\cos x \to 1$，由夹逼定理得 $\frac{\sin x}{x} \to 1$。

### 为什么这个极限重要

这个极限是推导 $\sin$ 和 $\cos$ 的导数公式的基础：

$$\frac{d}{dx}\sin x = \lim_{h \to 0}\frac{\sin(x+h) - \sin x}{h} = \lim_{h \to 0}\frac{2\cos(x+h/2)\sin(h/2)}{h}$$

$$= \lim_{h \to 0}\cos\left(x+\frac{h}{2}\right)\cdot\frac{\sin(h/2)}{h/2} = \cos x \cdot 1 = \cos x$$

没有 $\lim_{x \to 0}\frac{\sin x}{x} = 1$，就没有 $(\sin x)' = \cos x$，也就没有整个三角函数的微积分理论。

## 4. 三角函数的解析定义——超越几何

在高等数学中，三角函数可以不依赖几何，直接通过**幂级数**定义：

$$\sin x = \sum_{n=0}^{\infty}\frac{(-1)^n x^{2n+1}}{(2n+1)!} = x - \frac{x^3}{6} + \frac{x^5}{120} - \cdots$$

$$\cos x = \sum_{n=0}^{\infty}\frac{(-1)^n x^{2n}}{(2n)!} = 1 - \frac{x^2}{2} + \frac{x^4}{24} - \cdots$$

这些级数对所有 $x \in \mathbb{R}$ 收敛。从这些定义出发，可以**纯代数地**推导出所有三角恒等式（不需要任何几何！）。

例如，$\sin^2 x + \cos^2 x = 1$ 可以通过将两个级数的平方相加，然后证明结果恰好是 $1$ 来得到。

更重要的是，幂级数定义自然地扩展到**复数**自变量：$\sin z$ 和 $\cos z$（$z \in \mathbb{C}$）。此时 Euler 公式 $e^{iz} = \cos z + i\sin z$ 成为一个自然的等式，而非需要"解释"的神秘关系。

## 5. 不可能的三等分——角度与代数的碰撞

### 古典问题

古希腊数学家提出了一个问题：给定一个角 $\theta$，能否仅用尺规（直尺和圆规）将它三等分？

对某些特殊角（如 $90°$），答案是肯定的。但一般情况下呢？

### 代数的判决

1837 年，**Pierre Wantzel** 证明了**一般角的三等分不可能用尺规完成**。

证明的关键将几何问题转化为代数问题。三等分角 $60°$（即构造 $20°$ 的角）等价于构造 $\cos 20°$。由三倍角公式：

$$\cos 60° = 4\cos^3 20° - 3\cos 20° = \frac{1}{2}$$

令 $c = \cos 20°$：$8c^3 - 6c - 1 = 0$。

Wantzel 证明这个三次方程在有理数域上不可约（没有有理根），因此 $\cos 20°$ 不能通过有理运算和开平方根得到——而尺规作图恰好只能做到这些。

这是一个美丽的例子，展示了**代数如何解决几何问题**——有时是通过证明某件事不可能来解决的。

## 6. $\pi$ 的超越性与 $\sin$ 的零点

$\sin x$ 的零点是 $x = n\pi$（$n \in \mathbb{Z}$）。这个事实与 $\pi$ 的超越性有深刻的联系。

1882 年 Lindemann 证明 $\pi$ 是超越数，其证明的核心是 Hermite 证明 $e$ 超越性的方法的推广。结合 Euler 公式 $e^{i\pi} = -1$，$\pi$ 的超越性意味着：

如果 $\alpha$ 是非零代数数（整系数多项式的根），则 $e^\alpha$ 是超越数（**Lindemann-Weierstrass 定理**的特例）。

因此 $e^{i\pi} = -1$（代数数）意味着 $i\pi$ 不能是非零代数数——由于 $i$ 是代数数，$\pi$ 必须是超越数。

这个推理链条的优雅之处在于：指数函数、三角函数、复数和数论在此交汇。
