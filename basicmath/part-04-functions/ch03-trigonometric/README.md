# 第 3 章：三角函数（Trigonometric Functions）

## 章概览

三角函数是数学中第二大核心函数家族（与指数/对数并列）。如果说指数函数描述的是"增长与衰减"，那么三角函数描述的是**周期与振荡**——从简谐运动到电磁波，从声音的频率分析到天体的轨道运动，三角函数无处不在。

本章从三角函数的几何起源（单位圆）出发，系统研究六个三角函数的性质和图像，最后建立完整的三角恒等式体系。三角恒等式不仅是代数技巧的练兵场，更是后续微积分（三角换元、Fourier 分析）的必要准备。
