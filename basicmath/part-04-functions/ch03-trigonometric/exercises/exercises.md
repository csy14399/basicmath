# 第 3 章 三角函数 — 练习题

## §1 三角函数的几何起源（Geometric Origin）

1. ★☆☆ 将下列角度转换为弧度：
   (a) $150°$    (b) $-45°$    (c) $720°$    (d) $15°$

2. ★☆☆ 将下列弧度转换为角度：
   (a) $\frac{5\pi}{3}$    (b) $\frac{7\pi}{4}$    (c) $-\frac{\pi}{3}$    (d) $\frac{11\pi}{6}$

3. ★☆☆ 不查表，求下列值：
   (a) $\sin\frac{3\pi}{4}$    (b) $\cos\frac{5\pi}{3}$    (c) $\tan\frac{5\pi}{6}$    (d) $\sin(-\frac{\pi}{6})$

4. ★☆☆ 已知 $\sin\theta = \frac{5}{13}$，$\theta$ 在第一象限。求其余五个三角函数值。

5. ★★☆ 已知 $\tan\theta = -\frac{7}{24}$，$\theta$ 在第二象限。求 $\sin\theta$ 和 $\cos\theta$。

6. ★★☆ 化简 $\frac{\sin\theta \cdot \sec\theta}{\tan\theta}$。

7. ★★☆ 证明 $(\sin\theta + \cos\theta)^2 = 1 + \sin 2\theta$。

8. ★★☆ 半径为 $10$ cm 的圆中，一段弧长为 $15$ cm。求对应的圆心角（弧度）和扇形面积。

9. ★★★ 证明：对所有 $\theta$，$\frac{\tan\theta - \sin\theta}{\sin^3\theta} = \frac{\sec\theta}{1 + \cos\theta}$。

## §2 三角函数的性质与图像（Properties and Graphs）

1. ★☆☆ 写出以下函数的周期：
   (a) $y = \sin 3x$    (b) $y = \cos\frac{x}{2}$    (c) $y = \tan 2x$

2. ★☆☆ 确定 $y = 4\sin(2x - \frac{\pi}{3}) + 1$ 的振幅、周期、相移和中线。

3. ★★☆ 比较 $\sin 1$，$\sin 2$，$\sin 3$ 的大小（注意是弧度制）。

4. ★★☆ 求函数 $f(x) = 2\sin x + 3\cos x$ 的最大值和最小值。

5. ★★☆ $y = \sin x$ 在 $[0, \pi]$ 上的最大值和取到最大值的 $x$ 值。$y = \sin(2x + \frac{\pi}{6})$ 在 $[0, \frac{\pi}{2}]$ 上的最大值和取到最大值的 $x$ 值。

6. ★★☆ 画出 $y = |\sin x|$ 的图像。它的最小正周期是多少？

7. ★★★ 设 $f(x) = \sin x + |\sin x|$。画出 $f$ 的图像，并求其最小正周期。

8. ★★★ 求满足以下条件的余弦函数 $y = A\cos(Bx + C) + D$（$A > 0, B > 0$）：最大值 $7$，最小值 $1$，周期 $6$，在 $x = 1$ 时取最大值。

## §3 三角恒等式（Trigonometric Identities）

1. ★☆☆ 用和差角公式求精确值：
   (a) $\cos 15°$    (b) $\sin\frac{7\pi}{12}$    (c) $\tan 75°$

2. ★☆☆ 已知 $\sin\alpha = \frac{4}{5}$（$\alpha$ 在第一象限），$\cos\beta = -\frac{12}{13}$（$\beta$ 在第二象限）。求 $\sin(\alpha + \beta)$ 和 $\cos(\alpha - \beta)$。

3. ★★☆ 用二倍角公式求 $\sin\frac{\pi}{8}$ 的精确值。

4. ★★☆ 化简 $\frac{1 - \cos 2x}{\sin 2x}$。

5. ★★☆ 证明 $\frac{\sin 3\alpha}{\sin\alpha} - \frac{\cos 3\alpha}{\cos\alpha} = 2$。

6. ★★☆ 用和差化积化简 $\cos 3x - \cos 7x$。

7. ★★☆ 用积化和差计算 $\sin 75° \cos 15°$。

8. ★★☆ 解方程 $2\cos^2 x - 3\cos x + 1 = 0$（求 $[0, 2\pi)$ 中的所有解）。

9. ★★★ 解方程 $\sin x + \sqrt{3}\cos x = \sqrt{3}$（求 $[0, 2\pi)$ 中的所有解）。

10. ★★★ 证明 $\tan 20° + \tan 40° + \tan 20°\tan 40° = \sqrt{3} - 1 + \tan 20°\tan 40°$，进而求 $\tan 20° + \tan 40° + \sqrt{3}\tan 20°\tan 40°$ 的值。

11. ★★★ 证明：$\sin^2\alpha + \sin^2\beta - \sin^2\alpha\sin^2\beta + \cos^2\alpha\cos^2\beta = 1$。

12. ★★★ 设 $\alpha + \beta = \frac{\pi}{4}$。证明 $(1 + \tan\alpha)(1 + \tan\beta) = 2$。
