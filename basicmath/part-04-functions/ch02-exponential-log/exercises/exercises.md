# 第 2 章 指数函数与对数函数 — 练习题

## §1 指数函数（Exponential Functions）

1. ★☆☆ 化简下列表达式：
   (a) $\frac{3^5 \cdot 3^{-2}}{3^4}$
   (b) $(2^3)^{-2} \cdot 4^3$
   (c) $\left(\frac{27}{8}\right)^{-2/3}$

2. ★☆☆ 不使用计算器，比较下列各组数的大小：
   (a) $2^{3.5}$ 和 $2^{3.6}$
   (b) $0.5^{-3}$ 和 $0.5^{-4}$
   (c) $3^{0.7}$ 和 $4^{0.5}$

3. ★★☆ 解方程 $9^x - 4 \cdot 3^x + 3 = 0$。

4. ★★☆ 解不等式 $\left(\frac{1}{2}\right)^{x-1} \geq 4$。

5. ★★☆ 设 $f(x) = \frac{a^x - 1}{a^x + 1}$（$a > 0$，$a \neq 1$）。证明 $f$ 是奇函数。

6. ★★☆ 描述函数 $g(x) = -2^{x+1} + 3$ 的图像特征（单调性、截距、渐近线）。

7. ★★★ 设 $f(x) = a^x + a^{-x}$（$a > 1$）。证明 $f$ 是偶函数，且在 $[0, +\infty)$ 上严格递增。

8. ★★★ 证明：对所有正整数 $n$，$\left(1 + \frac{1}{n}\right)^n < \left(1 + \frac{1}{n+1}\right)^{n+1}$（即定义 $e$ 的序列单调递增）。提示：用 AM-GM 不等式。

## §2 对数函数（Logarithmic Functions）

1. ★☆☆ 计算：
   (a) $\log_4 64$
   (b) $\log_{1/3} 81$
   (c) $\ln e^5 - \ln e^{-2}$

2. ★☆☆ 展开为 $\log_a x$、$\log_a y$、$\log_a z$ 的线性组合：
   (a) $\log_a\left(\frac{x^2 y}{z^3}\right)$
   (b) $\log_a\sqrt[3]{\frac{x}{yz^2}}$

3. ★☆☆ 用换底公式计算 $\log_8 32$。

4. ★★☆ 解方程 $\log_3(x^2 - 2x) = 1$。

5. ★★☆ 解方程 $\ln(x+3) + \ln(x-1) = \ln(x+7)$。

6. ★★☆ 解不等式 $\log_{1/2}(3x - 1) < -2$。

7. ★★☆ 设 $\log_2 3 = a$，$\log_2 5 = b$。用 $a, b$ 表示 $\log_2 45$ 和 $\log_6 10$。

8. ★★☆ 证明：$\log_2 3 > \log_3 5$（提示：比较它们与某个共同的数的大小关系）。

9. ★★★ 已知 $\log_a 2 = m$，$\log_a 3 = n$。用 $m, n$ 表示 $\log_a \sqrt[3]{12}$。

10. ★★★ 设 $f(x) = \log_a \frac{1 + x}{1 - x}$（$|x| < 1$，$a > 0$，$a \neq 1$）。证明 $f$ 满足 $f(x) + f(y) = f\left(\frac{x + y}{1 + xy}\right)$（$|x|, |y| < 1$）。
