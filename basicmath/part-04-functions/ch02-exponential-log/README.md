# 第 2 章：指数函数与对数函数（Exponential and Logarithmic Functions）

## 章概览

指数和对数是数学中最重要的函数家族之一。指数函数描述**增长与衰减**——从人口增长到放射性衰变，从复利计算到信号衰减，指数函数无处不在。对数函数作为指数函数的反函数，将乘法化为加法、将幂运算化为乘法，是简化计算的强大工具。

本章的核心叙事是：从最基本的"重复乘法"（$a^n$）出发，逐步将指数的概念从自然数推广到整数、有理数、最终到实数，建立起指数函数 $f(x) = a^x$。然后通过反函数的概念引出对数函数 $\log_a x$，建立对数运算法则，最后认识自然底数 $e$ 的特殊地位。
