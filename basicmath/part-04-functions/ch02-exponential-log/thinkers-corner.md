## 1. 对数的发明——数学史上最伟大的计算工具

### Napier 的"人工数"

**约翰·纳皮尔**（John Napier, 1550–1617）是苏格兰贵族和业余数学家。在计算机出现之前的时代，天文学家需要处理大量的乘法和除法运算（如行星轨道计算），这些运算极为繁琐且容易出错。

1614 年，Napier 发表了《奇妙的对数表的描述》（*Mirifici Logarithmorum Canonis Descriptio*），引入了一种革命性的计算方法：**将乘法转化为加法**。

Napier 的原始对数与我们今天使用的定义略有不同。他的想法基于两条运动的比较：一条匀速直线运动和一条速度与位移成比例的运动（本质上是指数衰减）。

### 从对数表到计算尺

Napier 之后，**Henry Briggs**（1561–1630）将对数改为以 $10$ 为底，编制了详尽的对数表。这些对数表被科学家和工程师使用了超过三百年。

**计算尺**（slide rule）是对数思想的物理实现——两把对数刻度的尺子并排滑动，就能完成乘法和除法。直到 20 世纪 70 年代电子计算器普及之前，计算尺是工程师的必备工具。1969 年阿波罗登月任务中，宇航员的装备清单上就包含一把计算尺。

### 数学遗产

Laplace 曾说：对数"通过缩短计算的劳动，使天文学家的寿命延长了一倍"。Napier 的发明不仅是一个数学工具，更是科学革命的推动力之一。

## 2. $e$ 的超越性

### 超越数的概念

我们在正文中提到 $e$ 是无理数。事实上，$e$ 是一个**超越数**（transcendental number）——它不是任何具有整系数的非零多项式的根。

**Charles Hermite** 在 1873 年证明了 $e$ 的超越性。这是数学史上第一个被证明为超越的"自然出现"的数（之前 Liouville 在 1844 年构造了人工的超越数）。

九年后（1882 年），**Ferdinand von Lindemann** 证明了 $\pi$ 的超越性，从而解决了古希腊的"化圆为方"问题——不可能用尺规作图将圆变为等面积的正方形。

### $e$ 的无理性证明

$e$ 的无理性证明相对简洁。以下是 Euler（1737 年）给出的经典证明：

假设 $e = p/q$（$p, q$ 为正整数）。由 $e = \sum_{n=0}^{\infty} \frac{1}{n!}$：

$$q! \cdot e = q! \cdot \sum_{n=0}^{\infty} \frac{1}{n!} = \sum_{n=0}^{q} \frac{q!}{n!} + \sum_{n=q+1}^{\infty} \frac{q!}{n!}$$

第一部分 $\sum_{n=0}^{q} \frac{q!}{n!}$ 是整数（因为 $n \leq q$ 时 $\frac{q!}{n!}$ 是整数）。

若 $e = p/q$，则 $q! \cdot e = (q-1)! \cdot p$ 也是整数。因此第二部分

$$R = \sum_{n=q+1}^{\infty} \frac{q!}{n!}$$

也必须是整数。但

$$R = \frac{1}{q+1} + \frac{1}{(q+1)(q+2)} + \frac{1}{(q+1)(q+2)(q+3)} + \cdots$$

$$< \frac{1}{q+1} + \frac{1}{(q+1)^2} + \frac{1}{(q+1)^3} + \cdots = \frac{1/(q+1)}{1 - 1/(q+1)} = \frac{1}{q} \leq 1$$

且 $R > 0$。因此 $0 < R < 1$，$R$ 不是整数。矛盾。故 $e$ 是无理数。$\blacksquare$

## 3. 从 Euler 公式看指数函数

### $e^{ix}$ 与三角函数

Euler 公式是数学中最深刻的联系之一：

$$e^{i\theta} = \cos\theta + i\sin\theta$$

这个公式将指数函数和三角函数统一到了一个框架中。从 Taylor 级数的角度看：

$$e^{ix} = \sum_{n=0}^{\infty} \frac{(ix)^n}{n!} = \sum_{k=0}^{\infty} \frac{(-1)^k x^{2k}}{(2k)!} + i \sum_{k=0}^{\infty} \frac{(-1)^k x^{2k+1}}{(2k+1)!} = \cos x + i\sin x$$

特别地，当 $\theta = \pi$ 时：

$$e^{i\pi} = -1$$

即 **Euler 恒等式**：$e^{i\pi} + 1 = 0$。

这个等式被誉为"数学中最美的公式"——它将五个最基本的数学常数（$0, 1, e, i, \pi$）和三种最基本的运算（加法、乘法、幂运算）用一个优雅的等式连接起来。

### 指数函数的统一视角

在 Euler 公式的视角下，指数函数和三角函数不再是两种不相关的函数——它们是同一个函数 $e^z$（复变量指数函数）的不同切面：

$$\cos\theta = \text{Re}(e^{i\theta}) = \frac{e^{i\theta} + e^{-i\theta}}{2}$$

$$\sin\theta = \text{Im}(e^{i\theta}) = \frac{e^{i\theta} - e^{-i\theta}}{2i}$$

这些公式（将在 Part 4 Ch03 的三角函数章节和 Part 3 Ch04 的复数代数中再次出现）揭示了一个深刻的统一性。

## 4. 对数的"自然性"——为什么是 $e$？

### 面积解释

考虑双曲线 $y = 1/x$ 下方、从 $x = 1$ 到 $x = t$（$t > 0$）的面积：

$$A(t) = \int_1^t \frac{1}{x}\,dx$$

这个面积函数恰好等于 $\ln t$！$e$ 就是使得这个面积恰好等于 $1$ 的数：

$$\int_1^e \frac{1}{x}\,dx = 1$$

### 微分方程解释

在所有形如 $f(x) = a^x$ 的指数函数中，$e^x$ 是唯一满足

$$f'(0) = 1$$

的。更一般地，$\frac{d}{dx} a^x = a^x \ln a$，当 $a = e$ 时 $\ln a = 1$，导数简化为 $e^x$。

初始值问题 $f'(x) = f(x)$，$f(0) = 1$ 的唯一解就是 $f(x) = e^x$。这使得 $e$ 成为微积分中最自然的底数。

## 5. 对数与信息论

### 信息的度量

Claude Shannon 在 1948 年创立信息论时，用**对数**来度量信息量：

$$H = -\sum_{i} p_i \log_2 p_i$$

这是**信息熵**（entropy）的定义。$\log_2$ 的使用使得信息以**比特**（bit）为单位——一个等概率的二选一问题包含 $\log_2 2 = 1$ 比特的信息。

选择 $\log_2$ 而不是其他底数的对数，是因为二进制是计算机的基础。如果使用 $\ln$，信息单位就是**纳特**（nat）；使用 $\log_{10}$，单位是**哈特莱**（hartley）。

对数在信息论中的出现不是偶然的——它反映了信息的**加法性质**：两个独立事件的信息量之和等于联合事件的信息量（$\log(p_1 p_2) = \log p_1 + \log p_2$）。
