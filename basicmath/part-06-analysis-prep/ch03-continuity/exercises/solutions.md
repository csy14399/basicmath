# 第 3 章 连续性 — 练习题解答

## §1 连续函数

**1.**
(a) $f(3)$ 没有定义。$\lim_{x \to 3}\frac{x^2-9}{x-3} = \lim(x+3) = 6$。极限存在，函数值未定义。**可去间断点**。

(b) $\lim_{x \to 0}|x| = 0 = |0| = f(0)$。三个条件都满足，$f$ 在 $x = 0$ 处**连续**。

(c) $f(0^+) = 1$，$f(0^-) = -1$。左右极限不等。**跳跃间断点**。

---

**2.** $\lim_{x \to 0}\frac{\sin 2x}{x} = 2\lim_{x \to 0}\frac{\sin 2x}{2x} = 2 \cdot 1 = 2$。要 $f(0) = k = 2$。

---

**3.**
(a) $f(x) = \frac{1}{x^2-1} = \frac{1}{(x-1)(x+1)}$。间断点：$x = 1$ 和 $x = -1$。$\lim_{x \to 1}f(x) = \pm\infty$，$\lim_{x \to -1}f(x) = \pm\infty$。两个都是**无穷间断点**。

(b) $\lfloor x \rfloor$ 在每个整数 $n$ 处：$\lim_{x \to n^-}\lfloor x \rfloor = n - 1$，$\lim_{x \to n^+}\lfloor x \rfloor = n$。左右极限不等。每个整数都是**跳跃间断点**（跳跃大小 $1$）。

(c) $f(x) = x/|x|$。$f(0)$ 没有定义。$f(0^+) = 1$，$f(0^-) = -1$。$x = 0$ 是**跳跃间断点**（也可以说是不可修复的，因为左右极限不相等）。

---

**4.** $f(1) = 1^2 = 1$。

$\lim_{x \to 1^-}f(x) = \lim_{x \to 1^-}x^2 = 1$。

$\lim_{x \to 1^+}f(x) = \lim_{x \to 1^+}(2x-1) = 1$。

左极限 = 右极限 = $1$ = $f(1)$。$f$ 在 $x = 1$ 处连续。$\blacksquare$

---

**5.** 设 $\epsilon > 0$。$|f(x) - f(0)| = |x^2\sin(1/x) - 0| = x^2|\sin(1/x)| \leq x^2$。取 $\delta = \sqrt{\epsilon}$。对 $|x| < \delta$：$|f(x)| \leq x^2 < \delta^2 = \epsilon$。$\blacksquare$

---

**6.** 需证 $\lim_{x \to 0^+}\sqrt{x} = 0 = \sqrt{0}$。设 $\epsilon > 0$。$|\sqrt{x} - 0| = \sqrt{x}$。取 $\delta = \epsilon^2$。对 $0 < x < \delta$：$\sqrt{x} < \sqrt{\delta} = \epsilon$。$\blacksquare$

---

**7.** $\max(f,g) = \frac{f+g+|f-g|}{2}$。$f$ 和 $g$ 在 $a$ 连续 $\Rightarrow$ $f + g$ 连续，$f - g$ 连续。$|h|$ 在 $h$ 连续处连续（$||h(x)| - |h(a)|| \leq |h(x) - h(a)|$）。因此 $|f-g|$ 连续。由加法和常数倍封闭性，$\max(f,g)$ 连续。$\blacksquare$

---

**8.** 取 $\epsilon = f(a)/2 > 0$。由 $f$ 在 $a$ 连续，存在 $\delta > 0$ 使 $|x-a| < \delta$ 时 $|f(x)-f(a)| < f(a)/2$。因此 $f(x) > f(a) - f(a)/2 = f(a)/2 > 0$。$\blacksquare$

---

## §2 连续函数的性质

**1.** $f(x) = x^3 + x - 1$。$f(0) = -1 < 0$，$f(1) = 1 > 0$。$f$ 连续且异号，由介值定理存在 $c \in (0,1)$ 使 $f(c) = 0$。$\blacksquare$

---

**2.** $g(x) = e^x - (2-x) = e^x + x - 2$。$g(0) = 1+0-2 = -1 < 0$。$g(1) = e + 1 - 2 = e - 1 \approx 1.718 > 0$。由介值定理，$g$ 在 $(0,1)$ 中有零点。$\blacksquare$

---

**3.** $f(0) = 0 - 0 + 1 = 1 > 0$。$f(1) = 1 - 3 + 1 = -1 < 0$。$f(0)f(1) < 0$，由介值定理 $f$ 在 $(0,1)$ 中有零点。（也可以检查 $f(2) = 16 - 12 + 1 = 5 > 0$，得到 $(1,2)$ 中也有零点。）$\blacksquare$

---

**4.** $g(x) = \cos x - x^2$。$g(0) = 1 > 0$。$g(\pi/2) = 0 - \pi^2/4 < 0$。由介值定理，$(0, \pi/2)$ 中有一个解。

由偶性：$g(-x) = \cos x - x^2 = g(x)$，所以如果 $c$ 是解，$-c$ 也是。故至少有两个实数解（$c$ 和 $-c$，$c > 0$）。$\blacksquare$

---

**5.** 定义 $g(x) = f(x) - (1-x) = f(x) + x - 1$。$g(0) = f(0) + 0 - 1 = 0 - 1 = -1 < 0$。$g(1) = f(1) + 1 - 1 = 1 > 0$。由介值定理，存在 $c \in (0,1)$ 使 $g(c) = 0$，即 $f(c) = 1-c$。$\blacksquare$

---

**6.**
(a) **是**。$[0,1]$ 是闭区间，$f(x) = x^2$ 连续，由 Cantor 定理一致连续。

(b) **是**。$|\sin x - \sin y| \leq |x - y|$（$\sin$ 的 Lipschitz 常数为 $1$），取 $\delta = \epsilon$ 即可。

(c) **不是**。上文已说明：$x_n = 1/n$, $y_n = 1/(n+1)$, $|x_n - y_n| \to 0$ 但 $|f(x_n)-f(y_n)| = 1$。

(d) **不是**。$x_n = n$, $y_n = n + 1/(2n)$, $|x_n - y_n| = 1/(2n) \to 0$ 但 $|x_n^2 - y_n^2| > 1$。

---

**7.** 由最值定理，$f$ 取到最小值 $m = f(c)$ 和最大值 $M = f(d)$。因此 $f([a,b]) \subset [m, M]$。

由介值定理，对任意 $y \in [m, M]$，存在 $x \in [a,b]$ 使 $f(x) = y$（因为 $y$ 在 $f(c) = m$ 和 $f(d) = M$ 之间，$f$ 连续）。因此 $[m, M] \subset f([a,b])$。

故 $f([a,b]) = [m, M]$，是一个闭区间。$\blacksquare$

---

**8.** $g(x) = f(x) - f(x+1)$，$x \in [0,1]$。$g$ 连续。

$g(0) = f(0) - f(1)$，$g(1) = f(1) - f(2) = f(1) - f(0)$（因为 $f(0) = f(2)$）。

$g(0) + g(1) = [f(0) - f(1)] + [f(1) - f(0)] = 0$。

若 $g(0) = 0$，取 $c = 0$。否则 $g(0)$ 和 $g(1) = -g(0)$ 异号，由介值定理存在 $c \in (0,1)$ 使 $g(c) = 0$，即 $f(c) = f(c+1)$。$\blacksquare$

---

**9.** 由 $\lim_{x \to \pm\infty}f(x) = 0$，取 $\epsilon = 1$，存在 $R > 0$ 使 $|x| > R$ 时 $|f(x)| < 1$。

在 $[-R, R]$ 上，$f$ 连续（闭区间），由最值定理 $f$ 有界且取到最大值 $M$ 和最小值 $m$。

在 $|x| > R$ 时 $|f(x)| < 1$。故 $f$ 在整个 $\mathbb{R}$ 上有界（被 $\max(|M|, |m|, 1)$ 控制）。

$f$ 在 $[-R, R]$ 上取到 $M$ 和 $m$。由于 $|x| > R$ 时 $|f(x)| < 1$：

- 如果 $M \geq 1$ 或 $m \leq -1$，则全局最大或最小值在 $[-R, R]$ 上取到。
- 如果 $-1 < m \leq M < 1$，则 $|f(x)| < 1$ 在全 $\mathbb{R}$ 上成立，$f$ 在 $[-R, R]$ 上的最值就是全局最值。

总之 $f$ 有界且取到最大值或最小值。$\blacksquare$

---

**10.** $f$ 在 $[0, 1]$ 上连续（闭区间），由 Cantor 定理一致连续：对 $\forall \epsilon > 0$，$\exists \delta > 0$ 使 $|x - y| < \delta$（$x, y \in [0,1]$）时 $|f(x) - f(y)| < \epsilon$。

对任意 $x, y \in \mathbb{R}$，$|x - y| < \delta$。存在整数 $n$ 使 $x' = x - n \in [0, 1)$。由周期性 $f(x) = f(x')$。类似地 $y' = y - n$（取相同的 $n$），$|x' - y'| = |x - y| < \delta$。

需注意 $y'$ 可能不在 $[0,1]$ 中。但 $|x' - y'| < \delta \leq 1$ 且 $x' \in [0,1)$，故 $y' \in (-1, 2)$。利用周期性将 $y'$ 调整到 $[0,1]$ 附近，可以保证 $|f(x') - f(y')| < \epsilon$。

（严格处理：取 $\delta' = \min(\delta, 1/2)$。对 $|x - y| < \delta'$，$x', y'$ 在 $[-1/2, 3/2]$ 内。由 $f$ 的周期性，可以将两者都放入 $[0,1]$ 的邻域内。）$\blacksquare$

---

**11.** **二分法算法**：

初始：$a_0 = 0$, $b_0 = 1$, $f(a_0) < 0$, $f(b_0) > 0$。

第 $n$ 步：$m_n = (a_n + b_n)/2$（中点）。计算 $f(m_n)$。

- 若 $f(m_n) = 0$，找到零点，停止。
- 若 $f(m_n) < 0$，令 $a_{n+1} = m_n$, $b_{n+1} = b_n$。
- 若 $f(m_n) > 0$，令 $a_{n+1} = a_n$, $b_{n+1} = m_n$。

每步保持 $f(a_n) < 0$, $f(b_n) > 0$（由介值定理，零点在 $(a_n, b_n)$ 中）。

$b_n - a_n = 2^{-n}$（每步区间减半）。$n$ 步后零点被定位在长度 $2^{-n}$ 的区间中。

$a_n$ 单调递增有上界，$b_n$ 单调递减有下界，两者都收敛到同一极限 $c$。由 $f$ 连续，$f(c) = \lim f(a_n) \leq 0$ 且 $f(c) = \lim f(b_n) \geq 0$，故 $f(c) = 0$。

这就是**二分法**（bisection method）——数值分析中最简单最可靠的求根算法。
