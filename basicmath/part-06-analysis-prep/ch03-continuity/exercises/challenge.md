# 第 3 章 连续性 — 挑战题（Challenge Problems）

以下挑战题深入探索连续函数的性质，难度超出常规练习。

---

## 挑战题 1：Darboux 性质与导数

介值定理告诉我们连续函数有**介值性**（intermediate value property / Darboux property）：函数值不能"跳过"中间值。

**题目**：

(a) 构造一个**不连续**但有介值性的函数。

(b) [信息] 导数 $f'$ 总是有介值性的（即使 $f'$ 不连续）——这就是 **Darboux 定理**。这说明并非所有有介值性的函数都是连续的，但所有导数都有介值性。

### 解答

**(a)** 考虑 $f(x) = \sin(1/x)$（$x \neq 0$），$f(0) = 0$。

$f$ 在 $x = 0$ 处不连续（振荡间断点）。但 $f$ 有介值性：在任何包含 $0$ 的区间 $(a, b)$（$a < 0 < b$）中，$\sin(1/x)$ 取到 $[-1, 1]$ 中的所有值（因为 $1/x$ 在 $0$ 附近扫过所有足够大的值）。

更极端的例子：Conway 的 base-13 函数（每个区间上取到所有实数值）满足介值性但处处不连续——但这个构造远超本书范围。

**(b)** Darboux 定理的陈述：设 $f$ 在 $[a,b]$ 上可导。若 $f'(a) < \gamma < f'(b)$（或 $f'(a) > \gamma > f'(b)$），则存在 $c \in (a,b)$ 使 $f'(c) = \gamma$。

证明思路：考虑 $g(x) = f(x) - \gamma x$。$g'(a) < 0$ 且 $g'(b) > 0$。$g$ 在 $[a,b]$ 上连续，取到最小值。最小值点 $c$ 不在端点（因为 $g'(a) < 0$ 意味着 $g$ 在 $a$ 附近递减，$g'(b) > 0$ 意味着 $g$ 在 $b$ 附近递增），故 $c \in (a,b)$，$g'(c) = 0$，$f'(c) = \gamma$。

## 挑战题 2：Baire 类一函数

**题目**：设 $f_n$ 是 $[0, 1]$ 上的连续函数序列，且 $f_n(x) \to f(x)$ 对每个 $x \in [0,1]$ 成立（逐点收敛）。

(a) $f$ 一定连续吗？给出反例。

(b) [信息] 逐点极限 $f$ 虽然不一定连续，但它不会"太不连续"。这类函数叫做 **Baire 类一函数**（Baire class one function），它们的不连续点集是一个**第一纲集**（meager set / first category set），从某种意义上说这是一个"小"集合。

### 解答

**(a)** 不一定。反例：$f_n(x) = x^n$ 在 $[0, 1]$ 上。每个 $f_n$ 连续。

逐点极限：

$$f(x) = \lim_{n \to \infty}x^n = \begin{cases}0 & 0 \leq x < 1 \\ 1 & x = 1\end{cases}$$

$f$ 在 $x = 1$ 处不连续（跳跃间断点）。

这个例子说明：逐点极限不保持连续性。保持连续性的是**一致收敛**（uniform convergence）——对所有 $x$ 同时收敛。这是大学分析课程的重要主题。

## 挑战题 3：连续函数的零点集

**题目**：设 $f$ 在 $\mathbb{R}$ 上连续。定义 $Z(f) = \{x \in \mathbb{R} : f(x) = 0\}$（$f$ 的零点集）。

(a) 证明 $Z(f)$ 是闭集。（提示：证明 $Z(f)$ 的补集是开集，或者用序列判据。）

(b) 举例说明 $Z(f)$ 可以是空集、有限集、可数无穷集或不可数集。

(c) $Z(f)$ 可以是开集吗？（即是否存在连续函数 $f$ 使得 $Z(f)$ 既开又闭但不是 $\mathbb{R}$ 也不是空集？）

### 解答

**(a)** 用序列判据。设 $\{x_n\} \subset Z(f)$ 且 $x_n \to c$。即 $f(x_n) = 0$ 对所有 $n$。由 $f$ 连续，$f(c) = \lim f(x_n) = \lim 0 = 0$。故 $c \in Z(f)$。$Z(f)$ 包含其所有极限点，故是闭集。$\blacksquare$

**(b)**
- **空集**：$f(x) = 1$。$Z(f) = \varnothing$。
- **有限集**：$f(x) = x(x-1)(x-2)$。$Z(f) = \{0, 1, 2\}$。
- **可数无穷集**：$f(x) = \sin(\pi x)$。$Z(f) = \mathbb{Z}$。
- **不可数集**：$f(x) = 0$。$Z(f) = \mathbb{R}$。或者 $f(x) = \max(0, x - 1)\max(0, -x)$，$Z(f) = (-\infty, 0] \cup [1, +\infty)$。

**(c)** 在 $\mathbb{R}$ 的标准拓扑中，如果 $Z(f)$ 既开又闭且不是 $\mathbb{R}$ 也不是空集，则 $\mathbb{R}$ 不连通——但 $\mathbb{R}$ 是连通的。所以 $Z(f)$ 作为闭集不能同时是开集（除非是 $\varnothing$ 或 $\mathbb{R}$）。

等等，这需要更仔细地考虑。$Z(f)$ 是闭集，但可以是 $[0,1]$ 这样的闭区间——它不是开集。$Z(f)$ 可以是 $\mathbb{R}$ 或 $\varnothing$，此时它既开又闭。

但 $Z(f)$ 不可能是像 $(0, 1)$ 这样的开集而不是闭集——因为 (a) 证明了 $Z(f)$ 总是闭集。

所以问题应该是：$Z(f)$ 能否是像 $\mathbb{R} \setminus \{0\}$ 这样的开集？答案是否——因为 $Z(f)$ 是闭集，而 $\mathbb{R} \setminus \{0\}$ 不是闭集。
