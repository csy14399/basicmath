# 第 3 章：连续性（Continuity）

## 章概览

直觉上，连续函数就是"没有跳跃、没有裂缝、可以一笔画出"的函数。但直觉不够——数学需要精确定义。利用上一章建立的极限语言，本章给出连续性的严格定义，系统分类间断点的类型，然后证明连续函数的两个深刻性质——**介值定理**和**最值定理**。

这两个定理的证明依赖实数的**完备性**——它们在有理数系 $\mathbb{Q}$ 上不成立。这揭示了实数与有理数之间的深层差异，也兑现了我们在 Part 2 中暂时接受的完备性承诺。

本章最后简要介绍**一致连续**的概念，为将来分析学课程做铺垫。

- **理解最值定理的陈述和证明思路**
