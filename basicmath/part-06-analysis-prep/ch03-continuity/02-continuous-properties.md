# §2 连续函数的性质（Properties of Continuous Functions）

**前置知识**：[本章 §1 连续函数](01-continuity.md)（连续的定义、间断点分类）、[Part 2 第 1 章 数系](../../part-02-numbers/ch01-number-systems/README.md)（实数的完备性、上确界原理）、[Part 6 第 1 章 §2 数列的极限](../ch01-sequences/02-sequence-limits.md)（单调有界定理、Bolzano-Weierstrass 定理）

**全景图**：本节证明连续函数在闭区间上的两个最深刻的性质——**介值定理**和**最值定理**。这两个定理看似"显然"，但它们的证明依赖实数的**完备性**——在有理数系上，这些定理都不成立。介值定理的证明将兑现我们在 Part 2 中暂时接受的完备性承诺。本节最后简要介绍**一致连续**的概念，作为通往大学分析学的桥梁。

**预估学习时间**：约 4–6 小时

## 动机

连续函数有什么"好处"？直觉告诉我们：

1. **没有跳跃 $\Rightarrow$ 中间值都取到**：如果 $f(a) = -1$ 且 $f(b) = 1$，那么 $f$ 在 $a$ 和 $b$ 之间一定在某处等于 $0$（因为它不能"跳过" $0$）。
2. **连续函数在有界闭区间上取到最大值和最小值**：它不会"跑到无穷"也不会"无限接近某个值但取不到"。

第一条直觉导向**介值定理**，第二条导向**最值定理**。它们不只是有用的计算工具——它们揭示了实数系的深层结构。

## 1. 介值定理（Intermediate Value Theorem）

> [兑现] 在 Part 2 Ch01 §3 中我们暂时接受了实数的完备性（每个非空有上界的实数子集有上确界）。现在我们看到完备性的一个重要推论：介值定理。这个定理在有理数系 $\mathbb{Q}$ 上不成立——"连续"的有理数值函数可以"跳过"无理数。

### 1.1 定理陈述

> **定理 1**（介值定理 / Intermediate Value Theorem, IVT）
>
> 设 $f$ 在闭区间 $[a, b]$ 上连续，且 $f(a) \neq f(b)$。则对 $f(a)$ 和 $f(b)$ 之间的任意实数 $\gamma$，存在 $c \in (a, b)$ 使得 $f(c) = \gamma$。

特别地（零值定理）：

> **推论**（零值定理 / Bolzano 定理）
>
> 设 $f$ 在 $[a, b]$ 上连续，且 $f(a)$ 和 $f(b)$ 异号（$f(a) \cdot f(b) < 0$）。则存在 $c \in (a, b)$ 使得 $f(c) = 0$。

![介值定理示意图](../../images/p06-ch03-intermediate-value.png)

### 1.2 证明

> **证明**（使用上确界原理）
>
> 不妨设 $f(a) < \gamma < f(b)$（$f(a) > \gamma > f(b)$ 的情况对 $-f$ 应用即可）。
>
> 定义集合：
>
> $$S = \{x \in [a, b] : f(x) < \gamma\}$$
>
> **$S$ 非空**：$a \in S$（因为 $f(a) < \gamma$）。
>
> **$S$ 有上界**：$b$ 是上界（$S \subset [a, b]$）。
>
> 由上确界原理，$S$ 有上确界。设 $c = \sup S$。我们证明 $f(c) = \gamma$。
>
> **$f(c) < \gamma$ 不可能**：
>
> 假设 $f(c) < \gamma$。令 $\eta = \gamma - f(c) > 0$。由 $f$ 在 $c$ 处连续，存在 $\delta > 0$ 使得 $|x - c| < \delta$ 时 $|f(x) - f(c)| < \eta$，即 $f(x) < f(c) + \eta = \gamma$。
>
> 因此对 $x \in (c, c + \delta) \cap [a, b]$，$f(x) < \gamma$，即 $x \in S$。这意味着 $S$ 中有大于 $c$ 的元素，与 $c = \sup S$ 矛盾。
>
> **$f(c) > \gamma$ 不可能**：
>
> 假设 $f(c) > \gamma$。令 $\eta = f(c) - \gamma > 0$。由连续性，存在 $\delta > 0$ 使得 $|x - c| < \delta$ 时 $f(x) > f(c) - \eta = \gamma$。
>
> 因此 $(c - \delta, c + \delta) \cap [a, b]$ 中的所有点 $x$ 满足 $f(x) > \gamma$，即 $x \notin S$。这意味着 $c - \delta$ 也是 $S$ 的上界（$S$ 中的所有元素 $\leq c - \delta$），与 $c = \sup S$ 是**最小**上界矛盾（$c - \delta < c$）。
>
> 由排中律，$f(c) = \gamma$。
>
> 又因为 $f(a) < \gamma$ 且 $f(b) > \gamma$，$c \neq a$ 且 $c \neq b$，故 $c \in (a, b)$。$\blacksquare$

### 1.3 为什么需要完备性？

在有理数系 $\mathbb{Q}$ 上，介值定理不成立。

**反例**：定义 $f : \mathbb{Q} \to \mathbb{Q}$ 为 $f(x) = x^2 - 2$。

- $f(1) = -1 < 0$
- $f(2) = 2 > 0$
- $f$ 在 $\mathbb{Q}$ 上连续（多项式）

但不存在 $c \in \mathbb{Q}$ 使得 $f(c) = 0$（因为 $c = \sqrt{2} \notin \mathbb{Q}$）。

在 $\mathbb{Q}$ 上，函数可以"跳过"无理数——有理数的"空隙"使得连续函数不必取到所有中间值。

### 1.4 应用

> **例题 1**：证明方程 $x^5 + 3x - 1 = 0$ 至少有一个实根。

**解**：设 $f(x) = x^5 + 3x - 1$。$f$ 是多项式，在 $\mathbb{R}$ 上连续。

$f(0) = -1 < 0$，$f(1) = 1 + 3 - 1 = 3 > 0$。

由介值定理，存在 $c \in (0, 1)$ 使得 $f(c) = 0$。$\blacksquare$

> **例题 2**：证明每个奇数次多项式至少有一个实根。

> **证明**
>
> 设 $p(x) = a_n x^n + \cdots + a_0$，$n$ 为奇数，$a_n \neq 0$。不妨设 $a_n > 0$（否则考虑 $-p$）。
>
> 当 $x \to +\infty$：$p(x) = a_n x^n(1 + \cdots) \to +\infty$。特别地，存在 $b > 0$ 使得 $p(b) > 0$。
>
> 当 $x \to -\infty$：$p(x) = a_n x^n(1 + \cdots) \to -\infty$（因为 $n$ 为奇数，$x^n \to -\infty$）。特别地，存在 $a < 0$ 使得 $p(a) < 0$。
>
> 由介值定理，存在 $c \in (a, b)$ 使得 $p(c) = 0$。$\blacksquare$

**注意**：偶数次多项式不一定有实根（如 $x^2 + 1$）。

> **例题 3**：证明方程 $x = \cos x$ 有解。

**解**：设 $f(x) = x - \cos x$。$f$ 在 $\mathbb{R}$ 上连续。

$f(0) = 0 - \cos 0 = -1 < 0$。

$f(\pi/2) = \pi/2 - \cos(\pi/2) = \pi/2 - 0 = \pi/2 > 0$。

由介值定理，存在 $c \in (0, \pi/2)$ 使得 $f(c) = 0$，即 $c = \cos c$。$\blacksquare$

**注**：介值定理只告诉我们解的**存在性**，不告诉我们解的**具体值**。$x = \cos x$ 的解（Dottie 数）$c \approx 0.7391$ 没有已知的封闭形式表达式。

## 2. 最值定理（Extreme Value Theorem）

### 2.1 定理陈述

> **定理 2**（最值定理 / Extreme Value Theorem, EVT）
>
> 设 $f$ 在闭区间 $[a, b]$ 上连续。则 $f$ 在 $[a, b]$ 上取到最大值和最小值：存在 $c, d \in [a, b]$ 使得
>
> $$f(c) \leq f(x) \leq f(d) \quad \forall x \in [a, b]$$

即 $f(c) = \min_{[a,b]}f$，$f(d) = \max_{[a,b]}f$。

![最值定理示意图](../../images/p06-ch03-extreme-value.png)

### 2.2 为什么需要闭区间？

**三个反例展示闭区间条件的必要性**：

(a) **开区间上连续函数可以没有最大值**：$f(x) = x$ 在 $(0, 1)$ 上。$\sup f = 1$，但 $f$ 取不到 $1$（$1 \notin (0,1)$）。

(b) **不连续函数在闭区间上可以没有最大值**：$f(x) = \begin{cases}x & x \in [0, 1) \\ 0 & x = 1\end{cases}$。$\sup f = 1$（$x$ 可以任意接近 $1$），但 $f$ 取不到 $1$。

(c) **连续函数在无界闭集上可以没有最大值**：$f(x) = x$ 在 $[0, +\infty)$ 上。没有最大值。

因此最值定理需要三个条件：**连续 + 闭区间 + 有界区间**，缺一不可。

### 2.3 证明概要 [Bridge]

> **证明**（使用 Bolzano-Weierstrass 定理）
>
> 分两步证明：先证 $f$ 有上界，再证 $f$ 取到上确界。
>
> **第一步：$f$ 在 $[a,b]$ 上有界。**
>
> 反证法。假设 $f$ 无上界。则对每个正整数 $n$，存在 $x_n \in [a,b]$ 使得 $f(x_n) > n$。数列 $\{x_n\}$ 在 $[a,b]$ 中，有界。由 **Bolzano-Weierstrass 定理**，$\{x_n\}$ 有收敛子列 $x_{n_k} \to c \in [a,b]$。
>
> 由 $f$ 在 $c$ 处连续，$f(x_{n_k}) \to f(c)$（有限值）。但 $f(x_{n_k}) > n_k \to \infty$，矛盾。故 $f$ 有上界。类似可证有下界。
>
> **第二步：$f$ 取到最大值。**
>
> 设 $M = \sup\{f(x) : x \in [a,b]\}$（由第一步，$M$ 有限）。由上确界的定义，对每个 $n$，存在 $x_n \in [a,b]$ 使得 $M - 1/n < f(x_n) \leq M$。
>
> 数列 $\{x_n\}$ 有界（$[a,b]$ 中），由 Bolzano-Weierstrass 定理有收敛子列 $x_{n_k} \to d \in [a,b]$。
>
> 由 $f$ 连续：$f(d) = \lim f(x_{n_k})$。又 $M - 1/n_k < f(x_{n_k}) \leq M$，由夹逼定理 $f(x_{n_k}) \to M$。
>
> 故 $f(d) = M$，即 $f$ 在 $d$ 处取到最大值 $M$。
>
> 最小值的证明对 $-f$ 应用上述结果即可。$\blacksquare$

### 2.4 Bolzano-Weierstrass 定理

上面的证明用到了 Bolzano-Weierstrass 定理（在第一章的思考者角落中提到过）：

> **定理 3**（Bolzano-Weierstrass 定理）[Bridge]
>
> $\mathbb{R}$ 中的每个有界数列都有收敛的子列。

此定理等价于实数的完备性。它的证明使用**区间套原理**：将 $[a,b]$ 二等分，至少一半包含 $\{x_n\}$ 的无穷多项；再二等分，再取无穷多项的一半……这个过程产生一个嵌套的闭区间序列，其长度趋于零，由区间套原理它们的交集恰好是一个点——这个点就是收敛子列的极限。

## 3. 一致连续简介 [Bridge]

### 3.1 回顾点态连续

$f$ 在 $a$ 处连续的 $\epsilon$-$\delta$ 定义：

$$\forall \epsilon > 0, \; \exists \delta > 0, \; \forall x: \; |x - a| < \delta \Rightarrow |f(x) - f(a)| < \epsilon$$

这里 $\delta$ 可以依赖于 $\epsilon$ **和** $a$。对于不同的点 $a$，可能需要不同的 $\delta$。

### 3.2 一致连续的定义

> **定义 1**（一致连续 / Uniform Continuity）
>
> 函数 $f$ 在集合 $D$ 上**一致连续**，如果：
>
> $$\forall \epsilon > 0, \; \exists \delta > 0, \; \forall x, y \in D: \; |x - y| < \delta \Rightarrow |f(x) - f(y)| < \epsilon$$
>
> 这里 $\delta$ 只依赖于 $\epsilon$，**不依赖于** $x, y$ 的具体选取。

### 3.3 点态连续与一致连续的对比

| | 点态连续 | 一致连续 |
|--|---------|---------|
| $\delta$ 依赖于 | $\epsilon$ 和点 $a$ | 仅 $\epsilon$ |
| 含义 | 在每个点局部可控 | 在整个定义域全局可控 |
| 一致 $\Rightarrow$ 点态 | — | ✓ |
| 点态 $\Rightarrow$ 一致 | 不一定 | — |

**一致连续 $\Rightarrow$ 点态连续**（显然：一致连续的 $\delta$ 对每个点都适用）。

**点态连续 $\not\Rightarrow$ 一致连续**（一般情况）。

### 3.4 不一致连续的例子

> **例题 4**：$f(x) = 1/x$ 在 $(0, 1)$ 上连续但不一致连续。

**解**：取 $x_n = 1/n$，$y_n = 1/(n+1)$。$|x_n - y_n| = \dfrac{1}{n(n+1)} \to 0$，但 $|f(x_n) - f(y_n)| = |n - (n+1)| = 1$。

因此不存在 $\delta > 0$ 使得 $|x - y| < \delta$ 时 $|f(x) - f(y)| < 1/2$（取 $\epsilon = 1/2$）。$f$ 不一致连续。

直觉：当 $x$ 接近 $0$ 时，$f(x) = 1/x$ 变化越来越剧烈——同样的 $\Delta x$ 导致越来越大的 $\Delta f$。没有一个"全局的" $\delta$ 能在所有点处同时控制变化。

### 3.5 闭区间上连续 $\Rightarrow$ 一致连续

> **定理 4**（Cantor 定理 / Heine-Cantor 定理）[Bridge]
>
> 若 $f$ 在**闭区间** $[a, b]$ 上连续，则 $f$ 在 $[a, b]$ 上一致连续。

这个定理说明：对于闭区间上的连续函数，点态连续和一致连续等价。它不在开区间上成立（如上例 $1/x$ 在 $(0,1)$ 上）。

> **证明概要**
>
> 反证法。假设 $f$ 在 $[a,b]$ 上不一致连续，则存在 $\epsilon_0 > 0$ 使得对每个 $1/n$，都有 $x_n, y_n \in [a,b]$ 满足 $|x_n - y_n| < 1/n$ 但 $|f(x_n) - f(y_n)| \geq \epsilon_0$。
>
> $\{x_n\}$ 有界，由 Bolzano-Weierstrass 定理有子列 $x_{n_k} \to c \in [a,b]$。由 $|y_{n_k} - x_{n_k}| < 1/n_k \to 0$，$y_{n_k} \to c$。
>
> 由 $f$ 在 $c$ 处连续：$f(x_{n_k}) \to f(c)$，$f(y_{n_k}) \to f(c)$。因此 $|f(x_{n_k}) - f(y_{n_k})| \to 0$，与 $|f(x_{n_k}) - f(y_{n_k})| \geq \epsilon_0 > 0$ 矛盾。$\blacksquare$

### 3.6 一致连续的意义

一致连续在理论和应用中都很重要：

- 在理论上，一致连续的函数可以从稠密子集（如 $\mathbb{Q}$）唯一地连续延拓到整个区间。
- 在数值计算中，一致连续保证了离散化误差的可控性——这是数值积分（如 Riemann 和逼近积分）正确性的基础。
- 在实变函数论中，一致连续是证明 Riemann 可积性的关键工具。

## 例题（综合）

> **例题 5**：利用介值定理证明：对任意连续函数 $f : [0, 1] \to [0, 1]$，存在**不动点** $c \in [0, 1]$ 使得 $f(c) = c$。

> **证明**
>
> 定义 $g(x) = f(x) - x$。$g$ 在 $[0, 1]$ 上连续。
>
> $g(0) = f(0) - 0 = f(0) \geq 0$（因为 $f(0) \in [0, 1]$）。
>
> $g(1) = f(1) - 1 \leq 0$（因为 $f(1) \in [0, 1]$）。
>
> 若 $g(0) = 0$，取 $c = 0$。若 $g(1) = 0$，取 $c = 1$。
>
> 否则 $g(0) > 0$ 且 $g(1) < 0$。由介值定理，存在 $c \in (0, 1)$ 使得 $g(c) = 0$，即 $f(c) = c$。$\blacksquare$

这是 **Brouwer 不动点定理**在一维情况下的特例。高维推广（每个从 $[0,1]^n$ 到自身的连续映射有不动点）是拓扑学中的深刻定理。

---

> **例题 6**：证明 $f(x) = \sqrt{x}$ 在 $[0, +\infty)$ 上一致连续。

> **证明**
>
> 设 $\epsilon > 0$。对 $x, y \geq 0$：
>
> $$|\sqrt{x} - \sqrt{y}| = \frac{|x - y|}{\sqrt{x} + \sqrt{y}}$$
>
> 若 $\sqrt{x} + \sqrt{y} \geq 1$（即 $x$ 或 $y$ 不太小），则 $|\sqrt{x} - \sqrt{y}| \leq |x - y|$，取 $\delta = \epsilon$ 即可。
>
> 若 $\sqrt{x} + \sqrt{y} < 1$（即 $x, y < 1$），用另一个估计：$|\sqrt{x} - \sqrt{y}| \leq \sqrt{|x-y|}$（因为 $(\sqrt{x}-\sqrt{y})^2 \leq |x-y|$，取平方根）。取 $\delta = \epsilon^2$。
>
> 综合取 $\delta = \min(\epsilon, \epsilon^2)$。对 $|x - y| < \delta$：
>
> $$|\sqrt{x} - \sqrt{y}| \leq \sqrt{|x-y|} < \sqrt{\delta} \leq \epsilon$$
>
> $\blacksquare$

## 要点回顾

| 概念 | 要点 |
|------|------|
| 介值定理 | 连续函数在闭区间上取到一切中间值；证明用上确界原理 |
| 零值定理 | IVT 的特殊情况：$f(a)f(b) < 0 \Rightarrow$ 存在零点 |
| 完备性的角色 | IVT 和 EVT 在 $\mathbb{Q}$ 上不成立——需要实数的完备性 |
| 最值定理 | 连续函数在闭区间上取到最大最小值；证明用 Bolzano-Weierstrass |
| 一致连续 | $\delta$ 不依赖于点——全局可控；闭区间上连续 $\Rightarrow$ 一致连续 |
| 不动点 | $f:[0,1] \to [0,1]$ 连续 $\Rightarrow$ 存在 $f(c) = c$ |

## 自测题

**自测题 1**：介值定理的证明用到了实数的什么性质？如果把 $\mathbb{R}$ 换成 $\mathbb{Q}$，为什么定理不成立？

<details>
<summary>答案</summary>

用到了**上确界原理**（完备性）：非空有上界的实数集有上确界。

在 $\mathbb{Q}$ 上，集合 $S = \{x \in \mathbb{Q} : x^2 < 2\}$ 有上界但没有（有理数的）上确界——$\sup S = \sqrt{2} \notin \mathbb{Q}$。因此证明中构造的 $c = \sup S$ 可能不在 $\mathbb{Q}$ 中，函数"跳过"了无理数值。

具体反例：$f(x) = x^2 - 2$ 在 $\mathbb{Q}$ 上连续，$f(1) = -1 < 0$，$f(2) = 2 > 0$，但不存在有理数 $c$ 使得 $f(c) = 0$。
</details>

**自测题 2**：$f(x) = x^2$ 在 $(0, +\infty)$ 上一致连续吗？

<details>
<summary>答案</summary>

不是。取 $x_n = n$，$y_n = n + 1/(2n)$。$|x_n - y_n| = 1/(2n) \to 0$，但 $|f(x_n) - f(y_n)| = |n^2 - (n+1/(2n))^2| = |n^2 - n^2 - 1 - 1/(4n^2)| = 1 + 1/(4n^2) > 1$。

因此不存在统一的 $\delta$ 使得 $|x - y| < \delta \Rightarrow |x^2 - y^2| < 1$。

直觉：$x^2$ 的变化率在 $x$ 增大时不断增加——同样的 $\Delta x$ 导致越来越大的 $\Delta(x^2)$。
</details>

**自测题 3**：最值定理需要"闭区间"。举一个连续函数在开区间上没有最大值的例子。

<details>
<summary>答案</summary>

$f(x) = x$ 在 $(0, 1)$ 上。$\sup f = 1$，但 $f$ 永远取不到 $1$（因为 $1 \notin (0, 1)$）。$f$ 可以任意接近 $1$ 但无法达到——$\sup$ 不是 $\max$。

另一个例子：$f(x) = 1/(1-x)$ 在 $(0, 1)$ 上。连续，无上界（$x \to 1^-$ 时 $f \to +\infty$）。
</details>

**自测题 4**：$f : [0, 1] \to [0, 1]$ 连续一定有不动点。$f : (0, 1) \to (0, 1)$ 连续一定有不动点吗？

<details>
<summary>答案</summary>

不一定。反例：$f(x) = x/2$（$f : (0,1) \to (0, 1/2) \subset (0,1)$）。$f(x) = x$ 要求 $x/2 = x$，即 $x = 0$，但 $0 \notin (0,1)$。$f$ 没有不动点。

闭区间条件是关键——我们证明不动点的存在用到了 $g(0) \geq 0$ 和 $g(1) \leq 0$，即端点的信息。
</details>
