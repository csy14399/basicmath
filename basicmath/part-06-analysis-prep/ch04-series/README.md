# 第 4 章：级数（Series）

## 章概览

上一章我们研究了连续函数的性质。现在我们回到数列——但这次不是研究数列本身的极限，而是研究**无穷多个数相加**的问题。

将有限求和 $\sum_{k=1}^{n} a_k$ 推广到无穷 $\sum_{k=1}^{\infty} a_k$，是数学史上最大胆的飞跃之一。Archimedes 用几何方法求出了几何级数的和；Euler 计算出 $\sum 1/n^2 = \pi^2/6$（巴塞尔问题）；Riemann 发现条件收敛级数可以重排为任意值。这些结果既美丽又反直觉。

本章从无穷级数的定义出发，系统介绍各种收敛判别法，区分绝对收敛与条件收敛，最后初步探索幂级数和 Taylor 展开——为微积分和分析学铺路。
