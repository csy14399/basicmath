# 第 2 章 极限 — 思考者角落（Thinker's Corner）

> 本节超越教材的核心内容，带你一窥极限概念的深层世界和历史脉络。这里没有考试，只有好奇心。

## 1. 无穷小的历史——从争议到严格

### Leibniz 的无穷小

17 世纪，Leibniz 发明微积分时，大量使用了"无穷小量"（infinitesimal）——比任何正数都小但不为零的量。他写 $dy/dx$，其中 $dy$ 和 $dx$ 是"无穷小"的增量。

这个概念极其好用——它让微积分的公式直观而优雅。但它也充满逻辑困难：

- **一个数怎么能"比任何正数都小"但不为零？**
- 如果无穷小 $\neq 0$，我们在计算中忽略它的高阶项（如 $dx^2$）时，为什么能得到精确结果？

### Berkeley 的批评

1734 年，爱尔兰主教 George Berkeley 在《分析家》（*The Analyst*）中尖锐地批评了微积分的基础：

> 这些"消失了的量的幽灵"（ghosts of departed quantities），究竟是有限量还是无穷小量？如果是有限量，结果怎么能精确？如果是无穷小量（即零），你怎么能除以零？

Berkeley 的批评完全正确——Newton 和 Leibniz 的微积分缺乏逻辑基础。

### Weierstrass 的解决

19 世纪，Weierstrass 用 $\epsilon$-$\delta$ 定义彻底解决了这个问题。他的关键洞察是：

**我们不需要"无穷小量"这个概念。** 我们只需要普通的正实数 $\epsilon$——只不过 $\epsilon$ 可以"任意小"。

极限 $\lim_{x \to a}f(x) = L$ 不是说 "$f(x)$ 与 $L$ 之间有一个无穷小的差"，而是说"**对任意**正数 $\epsilon$（无论多小），我们能保证 $|f(x) - L| < \epsilon$"。

这里没有任何神秘的"无穷小量"——只有普通的实数和量词 $\forall$, $\exists$。

### Robinson 的非标准分析——无穷小的复活

1960 年代，数学家 Abraham Robinson 证明了一个惊人的结果：**Leibniz 的无穷小可以被严格化。**

Robinson 构造了**超实数系**（hyperreal number system）${}^*\mathbb{R}$，它包含通常的实数，还包含"无穷小"和"无穷大"元素。在这个系统中：

- 存在正数 $\varepsilon$ 使得 $\varepsilon < 1/n$ 对所有正整数 $n$ 成立——这就是"无穷小"
- 存在数 $H$ 使得 $H > n$ 对所有正整数 $n$ 成立——这就是"无穷大"
- $\varepsilon = 1/H$

Robinson 证明了：**用超实数和无穷小做微积分，与用 Weierstrass 的 $\epsilon$-$\delta$ 方法做微积分，得到的定理完全相同。** 两种方法逻辑上等价。

这意味着 Leibniz 的直觉从一开始就是正确的——只是他没有严格的数学框架来支撑。Robinson 的**非标准分析**（non-standard analysis）提供了这个框架。

不过，大多数数学家仍然使用 Weierstrass 的 $\epsilon$-$\delta$ 方法，因为它不需要额外的逻辑框架（超实数的构造需要数理逻辑中的超滤引理）。

## 2. 极限概念的拓扑推广

$\epsilon$-$\delta$ 定义的本质是什么？让我们抽象地审视它：

$$\lim_{x \to a}f(x) = L \iff \text{对 } L \text{ 的每个邻域 } V，f^{-1}(V) \text{ 包含 } a \text{ 的某个去心邻域}$$

这里"邻域"是 $(L-\epsilon, L+\epsilon)$，"去心邻域"是 $(a-\delta, a) \cup (a, a+\delta)$。

在**拓扑学**（topology）中，这个思想被推广为：

$$\lim_{x \to a}f(x) = L \iff \text{对 } L \text{ 的每个开集 } V \ni L，存在 } a \text{ 的开集 } U \ni a \text{ 使得 } f(U \setminus \{a\}) \subset V$$

这就是极限概念在一般拓扑空间中的定义。$\epsilon$ 和 $\delta$ 消失了——它们只是实数线上"开集"的特殊参数化方式。

更进一步，可以用**网**（net）或**滤子**（filter）来统一所有类型的极限（$x \to a$, $x \to \infty$, 数列极限等）。这些是大学高年级拓扑课程的内容。

## 3. $e$ 与 $\pi$——超越数的世界

我们在第一章定义了 $e$，在本章用到了 $\lim \sin x/x = 1$（与 $\pi$ 密切相关，因为弧度制以 $\pi$ 定义）。$e$ 和 $\pi$ 都是**超越数**——不是任何整系数多项式的根。

**一个深刻的开放问题**：$e + \pi$ 和 $e\pi$ 是否是超越数？

已知 $e$ 和 $\pi$ 各自是超越的。可以证明 $e + \pi$ 和 $e\pi$ 中**至少有一个**是超越的（因为 $e$ 和 $\pi$ 是多项式 $x^2 - (e+\pi)x + e\pi$ 的两个根；如果 $e+\pi$ 和 $e\pi$ 都是代数数，则这个多项式是代数数系数的，$e$ 和 $\pi$ 就是代数数，矛盾）。但我们不知道具体是哪一个——也许两个都是。

已知的超越性结果（Lindemann-Weierstrass 定理的推论）：

- $e^\pi$ 是超越的（Gelfond 常数）
- $2^{\sqrt{2}}$ 是超越的（Gelfond-Schneider 定理的特例）
- $\pi^2$ 是超越的（由 $\pi$ 的超越性直接推出）

**未知的问题**：

- $e^e$ 是否超越？（未知！）
- $\pi^e$ 是否超越？（未知！）
- $\pi^\pi$ 是否超越？（未知！）

这些问题看似简单，实际上极其困难——它们是数论中最深的开放问题之一。

## 4. 从极限到微积分——预览

极限不是目的——它是工具。整个微积分建立在极限之上：

**导数**是极限：

$$f'(a) = \lim_{h \to 0}\frac{f(a+h) - f(a)}{h}$$

**定积分**是极限：

$$\int_a^b f(x)\,dx = \lim_{n \to \infty}\sum_{k=1}^{n}f(x_k^*)\Delta x$$

**微积分基本定理**将这两个极限联系起来：

$$\frac{d}{dx}\int_a^x f(t)\,dt = f(x)$$

在第五章（微积分直觉）中，我们将深入探索这些思想。

本章建立的 $\epsilon$-$\delta$ 框架是理解这一切的基础。当你在大学数学中遇到导数和积分的严格定义时，你会发现它们不过是 $\epsilon$-$\delta$ 定义的变体。
