# 第 2 章：极限（Limits）

## 章概览

在第一章中，我们定义了数列极限——一个离散对象（自然数列标的函数）的极限。本章将极限的概念推广到**函数极限**——当自变量 $x$ 趋近于某个值 $a$ 时，函数 $f(x)$ 的行为。

函数极限是微积分的基石。导数是一个极限（差商的极限），积分是一个极限（Riemann 和的极限），级数的收敛性用极限定义——分析学的一切都建立在极限之上。

本章首先给出函数极限的 $\epsilon$-$\delta$ 定义——分析学中最重要也最令人畏惧的定义之一——然后讨论单侧极限、极限运算法则和两个重要极限（$\sin x / x$ 和 $e$ 的连续版本）。第二节探讨无穷大与无穷小的概念，以及渐近分析的初步思想。
