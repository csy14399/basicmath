# 第 5 章：微积分直觉（Calculus Intuition）[Bridge]

## 章概览

本章是整个教材的终章，也是通往大学数学的桥梁。前四章建立了数列极限、函数极限、连续性和级数的严格理论。现在我们将这些工具汇聚起来，为数学史上最伟大的智力成就之一——**微积分**——提供直觉准备。

微积分处理两个看似不相关的问题：**切线问题**（给定曲线，在某点的切线斜率是多少？）和**面积问题**（曲线下方的面积是多少？）。Newton 和 Leibniz 在 17 世纪独立发现了一个惊人的事实：这两个问题是**互逆**的。这就是**微积分基本定理**——将微分与积分统一为一体。

本章最后用 Taylor 级数推导出数学中最美的公式——**Euler 公式** $e^{i\theta} = \cos\theta + i\sin\theta$，将指数函数、三角函数和复数完美联系在一起。

> 🌉 **Bridge 标记**：本章所有内容都是 Bridge（桥接）性质的——提供直觉和核心结论，不追求完全的严格性。严格的微积分理论属于大学分析学课程。

## 学习成果

本章完成后你将能够：

- **直觉理解导数**：作为切线斜率和瞬时变化率
- **用极限定义导数**并计算基本函数的导数
- **陈述求导法则**（和、积、商、链式法则）
- **理解"可导蕴含连续"**并知道其逆命题为假
- **直觉理解积分**：作为曲线下面积的极限
- **陈述微积分基本定理**的两个部分并理解其深刻含义
- **从 Taylor 级数推导 Euler 公式**
- **欣赏 Euler 恒等式**$e^{i\pi} + 1 = 0$ 的数学之美
