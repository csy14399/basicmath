# 第 1 章：数列（Sequences）

## 章概览

数列是分析学的起点。一个数列就是一列按顺序排列的数——$a_1, a_2, a_3, \ldots$——它是从自然数到实数的函数。数列之所以重要，是因为它是我们第一次严格面对"无穷过程"的场所：一列数可以无限延续下去，而我们要问——**这列数最终趋向什么？**

本章首先建立数列的基本概念：等差数列、等比数列、递推数列、有界性和单调性。然后进入本书最深刻的定义之一——**数列极限的 $\epsilon$-$N$ 定义**。你将学会用绝对精确的数学语言描述"趋近"这个直觉概念，并掌握证明极限的基本方法和核心定理。

## 前置知识

- **Part 1 第 1 章（逻辑）**：量词 $\forall$, $\exists$、逻辑联结词——$\epsilon$-$N$ 定义是量词的精巧组合
- **Part 1 第 3 章（证明方法）**：直接证明、反证法、数学归纳法——证明极限和数列性质的核心工具
- **Part 2 第 1 章（数系）**：自然数、实数、完备性——数列极限理论的根基
- **Part 3 第 2 章（不等式）**：绝对值不等式——$\epsilon$ 证明的基本工具
- **Part 4 第 01 章（函数概念）**：函数的定义——数列就是定义域为 $\mathbb{N}$ 的函数

## 学习成果

本章完成后你将能够：

- **理解数列的多种描述方式**：通项公式、递推关系、列举法
- **熟练运用等差数列和等比数列的公式**：通项、求和，并理解公式的推导
- **用特征方程法求解线性递推关系**
- **判断数列的有界性和单调性**
- **精确陈述并理解数列极限的 $\epsilon$-$N$ 定义**
- **用 $\epsilon$-$N$ 定义证明简单极限**
- **运用夹逼定理和单调有界定理求极限**
- **理解 $e = \lim_{n\to\infty}(1+1/n)^n$ 的存在性论证**
