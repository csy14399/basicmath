# 第六部分：分析预备（Analysis Prep）

## 本部分概览

分析学（analysis）是现代数学的核心分支，它以**极限**为基本工具，研究无穷过程、连续性、收敛性以及变化率。从 Newton 和 Leibniz 发明微积分，到 Cauchy、Weierstrass、Riemann 将其严格化，分析学的发展史就是数学从直觉走向严格的缩影。

如果说前五个部分建立了逻辑框架（Part 1）、认识了数的世界（Part 2）、掌握了代数工具（Part 3）、研究了函数家族（Part 4）、探索了几何空间（Part 5），那么第六部分要做的就是**跨越有限与无限之间的鸿沟**。这里是高中数学与大学数学的桥梁——你将第一次严格面对"无穷"这个概念，学会用 $\epsilon$-$N$ 和 $\epsilon$-$\delta$ 语言精确描述"趋近""收敛""连续"等直觉概念。

本部分的核心主题是：**理解无穷、极限与微积分的基础。**

本部分包含五章：

| 章 | 主题 | 内容 |
|----|------|------|
| [第 1 章：数列](ch01-sequences/README.md) | 数列（sequences） | 数列的概念、等差数列、等比数列、递推数列、有界性、单调性、数列极限、$\epsilon$-$N$ 定义、夹逼定理、单调有界定理 |
| [第 2 章：极限](ch02-limits/README.md) | 极限（limits） | 函数极限、$\epsilon$-$\delta$ 定义、单侧极限、极限运算、重要极限、无穷大与无穷小、渐近分析 |
| [第 3 章：连续性](ch03-continuity/README.md) | 连续性（continuity） | 连续函数的定义、间断点分类、连续函数的运算、介值定理、最值定理、一致连续 |
| 第 4 章：级数 | 级数（series） | 无穷级数的概念、收敛判别法、绝对收敛与条件收敛、幂级数初步 |
| 第 5 章：微积分直觉 | 微积分直觉（calculus intuition） | 导数的直觉、积分的直觉、微积分基本定理的思想、为大学数学做准备 |

这五章的关系：第一章从数列出发引入极限的概念——数列是最简单的"无穷过程"。第二章将极限推广到函数，引入 $\epsilon$-$\delta$ 语言——这是分析学的核心工具。第三章利用极限定义连续性，并证明连续函数的深刻性质（介值定理、最值定理）——这些定理的证明依赖实数的完备性。第四章研究无穷级数——将有限求和推广到无穷。第五章用极限和连续性的语言为微积分（导数和积分）做直觉准备。

## 前置知识

**第一部分（数学基础）**、**第二部分（数系与数论）**、**第三部分（代数）** 和 **第四部分（函数）**：

- **逻辑与证明**（Part 1 Ch01, Ch03）：命题逻辑、量词（$\forall$, $\exists$）、各种证明方法——$\epsilon$-$N$ 和 $\epsilon$-$\delta$ 定义的核心就是量词的巧妙嵌套。
- **集合论**（Part 1 Ch02）：集合运算、区间——定义域、值域的精确描述。
- **数系**（Part 2 Ch01）：实数的完备性——这是极限理论成立的根本保证；有理数与无理数——理解为何 $\mathbb{Q}$ 上没有完备性。
- **不等式**（Part 3 Ch02）：绝对值不等式——$\epsilon$-$\delta$ 证明的基本工具。
- **函数**（Part 4 Ch01–Ch04）：函数的概念、初等函数（多项式、三角、指数、对数）——极限和连续性研究的对象。

## 本部分的主题：驯服无穷

贯穿本部分的核心思想是**如何严格处理无穷**：

1. **数列极限**（Ch01）：无穷多个数能"趋向"一个确定的值——$\epsilon$-$N$ 定义将"趋向"这个模糊概念变得绝对精确。
2. **函数极限**（Ch02）：当自变量无限趋近某个值时，函数值的行为——$\epsilon$-$\delta$ 定义是 Weierstrass 的杰作，它消除了 Newton 和 Leibniz 的"无穷小"的含混性。
3. **连续性**（Ch03）：函数"没有跳跃"意味着什么？连续性是极限与函数值的和谐一致。介值定理揭示了实数完备性的深刻后果。
4. **无穷级数**（Ch04）：无穷多个数可以相加吗？什么时候可以？收敛与发散的分界线在哪里？
5. **微积分直觉**（Ch05）：导数是"瞬时变化率"——这是一个极限；积分是"无穷细分后的求和"——这也是一个极限。微积分的全部基础就是极限。

这五个主题层层递进：从离散到连续，从有限到无穷，从直觉到严格。本部分是整本教材中数学上最深刻的部分——它不只是学习新的计算技巧，更是经历一次思维方式的根本转变。
