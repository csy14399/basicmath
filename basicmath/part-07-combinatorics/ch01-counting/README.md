# 第 1 章：计数原理（Counting Principles）

## 章概览

"有多少种方式？"——这个看似简单的问题是整个组合数学的起点。本章建立最基本也最重要的两个计数工具：**加法原理**和**乘法原理**，然后引入处理"重叠计数"的利器——**容斥原理**（inclusion-exclusion principle）。这些原理不仅是排列组合（Ch02）和二项式定理（Ch03）的基础，更是概率论（Part 8）的核心工具。

本章首先从日常生活中的计数问题出发，建立加法原理（互斥情形分类）和乘法原理（独立步骤组合），通过树形图使抽象原理变得直观。然后进入容斥原理——当事件有重叠时，简单的加法会"多算"，容斥原理精确地修正这个多算。最后展示容斥原理的两个经典应用：Euler 函数 $\phi(n)$ 和错排问题（derangements）。

## 前置知识

- **Part 1 第 1 章（逻辑）**：命题逻辑、"或""且"的精确含义——加法原理对应"或"（互斥），乘法原理对应"且"（独立）
- **Part 1 第 2 章（集合）**：集合的并集、交集、容斥——本章的容斥原理直接建立在集合运算之上
- **Part 1 第 3 章（证明方法）**：数学归纳法——用于证明一般容斥公式
- **Part 2 第 3 章（数论）**：整除、素数、Euler 函数——容斥原理的经典应用
