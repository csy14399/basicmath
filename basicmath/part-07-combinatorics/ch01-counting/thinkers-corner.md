## 1. Möbius 反演公式

### 从 Euler 函数到一般理论

我们证明了 $\sum_{d \mid n} \phi(d) = n$。这个等式是一类更一般现象的特例。

设 $f$ 和 $g$ 是定义在正整数上的函数，满足

$$g(n) = \sum_{d \mid n} f(d)$$

则可以用 **Möbius 反演**将 $f$ 从 $g$ 中"恢复"出来：

$$f(n) = \sum_{d \mid n} \mu(d) \, g\!\left(\frac{n}{d}\right)$$

其中 **Möbius 函数** $\mu$ 定义为：

$$\mu(n) = \begin{cases} 1 & \text{若 } n = 1 \\ (-1)^k & \text{若 } n = p_1 p_2 \cdots p_k \text{（不同素数之积）} \\ 0 & \text{若 } n \text{ 有平方因子} \end{cases}$$

将 $g(n) = n$、$f(n) = \phi(n)$ 代入，可以得到 $\phi(n)$ 的另一种表达式。

### 更深的背景

Möbius 反演不只是一个数论技巧——它是**偏序集（poset）上的反演理论**的特例。任何有限偏序集 $(P, \leq)$ 上都可以定义 Möbius 函数 $\mu(x, y)$，使得

$$g(x) = \sum_{y \leq x} f(y) \implies f(x) = \sum_{y \leq x} \mu(y, x) \, g(y)$$

整除关系 $d \mid n$ 构成的偏序就给出了经典的 Möbius 函数。

## 2. Bonferroni 不等式

### 容斥原理的截断

一般容斥公式有 $2^n - 1$ 项——当 $n$ 很大时，这可能计算量巨大。但有一个优美的结果：**截断的容斥公式给出交替的上下界**。

**Bonferroni 不等式**：设 $S_k = \sum_{|I|=k} |A_{i_1} \cap \cdots \cap A_{i_k}|$。则

$$S_1 - S_2 \leq |A_1 \cup \cdots \cup A_n| \leq S_1$$

$$S_1 - S_2 + S_3 \geq |A_1 \cup \cdots \cup A_n| \geq S_1 - S_2$$

一般地：截断到奇数项得到上界，截断到偶数项得到下界。

这在概率论中特别有用——当精确计算困难时，Bonferroni 不等式给出有用的估计。

## 3. 从计数到概率

### 等可能事件

当一个试验的所有结果等可能时，事件 $A$ 的概率就是

$$P(A) = \frac{|A|}{|\Omega|}$$

其中 $|\Omega|$ 是总结果数。这将计数问题直接转化为概率问题——Part 8 的核心主题。

例如，错排的概率 $D_n/n! \to 1/e$——这是组合数学与分析学（指数函数）的一次美妙邂逅。

### 概率版容斥

在概率论中，容斥原理变成

$$P(A_1 \cup \cdots \cup A_n) = \sum P(A_i) - \sum P(A_i \cap A_j) + \cdots$$

形式完全一样，只是把集合大小换成了概率。

## 4. 计数的双射证明

### 一一对应的力量

组合数学中最优雅的证明方法之一是**双射证明**（bijective proof）：要证明两个集合大小相等，只需在它们之间建立一一对应。

**经典例子**：$n$ 元集合的子集个数等于长度为 $n$ 的 $0$-$1$ 字符串个数。

双射：子集 $S \subseteq \{1, 2, \ldots, n\}$ $\leftrightarrow$ 字符串 $(b_1, b_2, \ldots, b_n)$，其中 $b_i = 1$ 当且仅当 $i \in S$。

这比用乘法原理的"$2^n$"论证更深刻——它不只告诉你"有多少"，还告诉你"如何对应"。

双射证明的思想在第 2 章的组合恒等式证明中将反复出现。
