# 第 4 章：图论初步（Introduction to Graph Theory）

## 章概览

图论（graph theory）是离散数学中最直观、最具应用价值的分支之一。它用**顶点**（vertex）和**边**（edge）构成的简单结构——**图**（graph）——来描述对象之间的关系和连接。从社交网络到交通路线，从化学分子到互联网结构，图无处不在。

图论的起源可以追溯到 $1736$ 年 Euler 对 Königsberg 七桥问题的解答——这不仅是图论的开端，也被认为是拓扑学的萌芽。本章首先建立图的基本概念（顶点、边、度、特殊图），然后研究两个经典问题：Euler 路径（能否一笔画？）和 Hamilton 路径（能否走遍所有顶点？）。

## 学习成果

本章完成后你将能够：

- **准确使用图论的基本术语**：顶点、边、度、路径、环、连通分量
- **区分有向图与无向图**，并理解加权图的概念
- **证明和应用握手定理** $\sum \deg(v) = 2|E|$

- **判定 Euler 路径和 Euler 回路的存在性**
- **理解 Hamilton 路径问题的复杂性**
- **陈述和应用平面图的 Euler 公式**
