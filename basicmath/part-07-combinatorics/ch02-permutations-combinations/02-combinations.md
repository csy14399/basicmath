# §2 组合（Combinations）

**前置知识**：[本章 §1 排列](01-permutations.md)（排列数、阶乘）、[Ch01 §1 加法原理与乘法原理](../ch01-counting/01-addition-multiplication.md)

**全景图**：排列关心顺序，组合不关心顺序。本节从排列数出发推导组合数 $\binom{n}{r}$，研究其基本性质（对称性、Pascal 恒等式），然后引入"可重复组合"（星与条方法），最后将组合数与子集计数联系起来。

**预估学习时间**：约 3–4 小时

---

## 动机

从 $5$ 名同学中选 $3$ 人组成代表队参加比赛。有多少种选法？

如果考虑顺序——选 A, B, C 和选 B, A, C 是不同的——这是排列：$P(5, 3) = 60$。

但代表队不分角色——{A, B, C} 和 {B, A, C} 是同一个队。$3$ 个人有 $3! = 6$ 种排列顺序，因此

$$\text{组合数} = \frac{P(5, 3)}{3!} = \frac{60}{6} = 10$$

这就是**组合**的核心思想：从排列数中除去顺序的影响。

---

## 1. 组合数（Combination Number）

### 1.1 定义与公式

> **定义 1**（组合数）
>
> 从 $n$ 个不同对象中**无序**选取 $r$ 个（$0 \leq r \leq n$）的方式数称为**组合数**，记为 $\binom{n}{r}$（读作"$n$ 选 $r$"）：
>
> $$\binom{n}{r} = \frac{P(n, r)}{r!} = \frac{n!}{r!(n-r)!}$$

**推导**：每一种无序选取（组合）对应 $r!$ 种有序选取（排列）——因为 $r$ 个被选中的对象有 $r!$ 种排列。因此 $\binom{n}{r} = P(n,r)/r!$。

### 1.2 前几个值

| $\binom{n}{r}$ | $r=0$ | $r=1$ | $r=2$ | $r=3$ | $r=4$ | $r=5$ |
|-----------------|-------|-------|-------|-------|-------|-------|
| $n=0$ | $1$ | | | | | |
| $n=1$ | $1$ | $1$ | | | | |
| $n=2$ | $1$ | $2$ | $1$ | | | |
| $n=3$ | $1$ | $3$ | $3$ | $1$ | | |
| $n=4$ | $1$ | $4$ | $6$ | $4$ | $1$ | |
| $n=5$ | $1$ | $5$ | $10$ | $10$ | $5$ | $1$ |

这就是 **Pascal 三角形**（Pascal's triangle）——每个数等于它正上方两个数之和。

### 1.3 例题

> **例 1**（委员会选取）
>
> 从 $10$ 名学生中选 $4$ 人组成委员会。有多少种选法？

**解**：无序选取。$\binom{10}{4} = \dfrac{10!}{4! \cdot 6!} = \dfrac{10 \times 9 \times 8 \times 7}{4 \times 3 \times 2 \times 1} = 210$ 种。$\blacksquare$

> **例 2**（扑克牌）
>
> 从标准 $52$ 张扑克牌中抽 $5$ 张。(a) 共有多少种手牌？(b) 恰好有 $3$ 张红心的手牌有多少种？

**解**：

(a) $\binom{52}{5} = \dfrac{52!}{5! \cdot 47!} = 2{,}598{,}960$ 种。

(b) $3$ 张红心从 $13$ 张中选：$\binom{13}{3} = 286$。另外 $2$ 张从其余 $39$ 张中选：$\binom{39}{2} = 741$。

由乘法原理：$286 \times 741 = 211{,}926$ 种。$\blacksquare$

## 2. 组合数的基本性质

### 2.1 对称性

> **性质 1**（对称性）
>
> $$\binom{n}{r} = \binom{n}{n-r}$$

**代数证明**：$\dfrac{n!}{r!(n-r)!} = \dfrac{n!}{(n-r)!r!}$。两边相同。

**组合证明**：从 $n$ 个对象中选 $r$ 个，等价于决定不选哪 $n-r$ 个。

### 2.2 Pascal 恒等式

> **性质 2**（Pascal 恒等式）
>
> 对 $1 \leq r \leq n$：
>
> $$\binom{n}{r} = \binom{n-1}{r-1} + \binom{n-1}{r}$$

**代数证明**：

$$\binom{n-1}{r-1} + \binom{n-1}{r} = \frac{(n-1)!}{(r-1)!(n-r)!} + \frac{(n-1)!}{r!(n-1-r)!}$$

$$= \frac{(n-1)!}{(r-1)!(n-1-r)!}\left(\frac{1}{n-r} + \frac{1}{r}\right) \cdot \frac{r(n-r)}{1}$$

简化后等于 $\dfrac{n!}{r!(n-r)!} = \binom{n}{r}$。

**组合证明**（更优雅）：从 $\{1, 2, \ldots, n\}$ 中选 $r$ 个元素。聚焦元素 $n$：

- **选 $n$**：还需从 $\{1, \ldots, n-1\}$ 中选 $r-1$ 个，共 $\binom{n-1}{r-1}$ 种。
- **不选 $n$**：从 $\{1, \ldots, n-1\}$ 中选 $r$ 个，共 $\binom{n-1}{r}$ 种。

两类互斥，由加法原理：$\binom{n}{r} = \binom{n-1}{r-1} + \binom{n-1}{r}$。$\blacksquare$

Pascal 恒等式是 Pascal 三角形中"每个数 = 左上 + 右上"的精确表述。

### 2.3 边界值

$$\binom{n}{0} = \binom{n}{n} = 1, \quad \binom{n}{1} = n$$

## 3. 可重复组合 / 星与条方法（Stars and Bars）

### 3.1 问题

从 $n$ 种对象中**无序**选取 $r$ 个，**允许重复**。例如：从 $3$ 种水果中选 $5$ 个，允许重复选取，有多少种选法？

### 3.2 星与条模型

将 $r$ 个被选对象用 $r$ 颗"星"（$\star$）表示，$n$ 种类型用 $n - 1$ 根"条"（$|$）分隔。

例如 $n = 3$（苹果/橙子/香蕉），$r = 5$：

$$\star\star | \star\star\star | \quad \Leftrightarrow \quad \text{2 个苹果，3 个橙子，0 个香蕉}$$

$$| \star\star | \star\star\star \quad \Leftrightarrow \quad \text{0 个苹果，2 个橙子，3 个香蕉}$$

每种选法对应一种"$r$ 个星和 $n-1$ 个条"的排列。总共 $r + n - 1$ 个符号，选 $n - 1$ 个位置放条（或选 $r$ 个位置放星）。

> **定理 1**（可重复组合 / 星与条公式）
>
> 从 $n$ 种对象中无序选取 $r$ 个，允许重复，方式数为：
>
> $$\binom{r + n - 1}{r} = \binom{r + n - 1}{n - 1}$$

### 3.3 等价表述

上述问题等价于：求方程

$$x_1 + x_2 + \cdots + x_n = r, \quad x_i \geq 0, \; x_i \in \mathbb{Z}$$

的非负整数解的个数。答案相同：$\binom{r+n-1}{r}$。

如果要求 $x_i \geq 1$（每种至少选一个），令 $y_i = x_i - 1$，则

$$y_1 + y_2 + \cdots + y_n = r - n, \quad y_i \geq 0$$

解的个数为 $\binom{r-1}{n-1}$（要求 $r \geq n$）。

### 3.4 例题

> **例 3**（分糖果）
>
> 把 $10$ 颗相同的糖果分给 $4$ 个孩子，每人可以不分。有多少种分法？

**解**：$x_1 + x_2 + x_3 + x_4 = 10$，$x_i \geq 0$。

$$\binom{10 + 4 - 1}{4 - 1} = \binom{13}{3} = 286 \text{ 种}$$

$\blacksquare$

> **例 4**（购买水果）
>
> 商店有苹果、橙子、香蕉三种水果（每种数量充足）。买 $8$ 个水果，每种至少买一个，有多少种购买方案？

**解**：$x_1 + x_2 + x_3 = 8$，$x_i \geq 1$。令 $y_i = x_i - 1$：

$$y_1 + y_2 + y_3 = 5, \quad y_i \geq 0$$

$$\binom{5 + 3 - 1}{3 - 1} = \binom{7}{2} = 21 \text{ 种}$$

$\blacksquare$

## 4. 子集计数

### 4.1 与组合数的关系

$n$ 元集合的 $r$ 元子集个数就是 $\binom{n}{r}$——从 $n$ 个元素中无序选取 $r$ 个。

所有子集的个数：

$$\sum_{r=0}^{n} \binom{n}{r} = 2^n$$

这就是 Ch01 中用乘法原理得到的结果。我们将在 §3 中用二项式定理给出另一个证明。

### 4.2 分组问题

> **例 5**（分组）
>
> $12$ 人分成三组，每组 $4$ 人。(a) 三组有标签（A 组、B 组、C 组），有多少种分法？(b) 三组无标签，有多少种分法？

**解**：

(a) 先选 A 组：$\binom{12}{4}$。再选 B 组：$\binom{8}{4}$。C 组自动确定：$\binom{4}{4} = 1$。

$$\binom{12}{4}\binom{8}{4}\binom{4}{4} = 495 \times 70 \times 1 = 34{,}650$$

(b) 三组无标签，$3!$ 种标签方式对应同一种分组。$34{,}650 / 6 = 5{,}775$。$\blacksquare$

## 5. 组合与排列的关系总结

| 类型 | 有序（排列） | 无序（组合） |
|------|------------|------------|
| 不重复 | $P(n,r) = n!/(n-r)!$ | $\binom{n}{r} = n!/(r!(n-r)!)$ |
| 允许重复 | $n^r$ | $\binom{r+n-1}{r}$ |

**记忆技巧**：组合 $=$ 排列 $/$ 去序。$\binom{n}{r} = P(n,r)/r!$。

## 要点回顾

| 概念 | 核心内容 | 公式 |
|------|----------|------|
| 组合数 | 无序选取 $r$ 个 | $\binom{n}{r} = n!/(r!(n-r)!)$ |
| 对称性 | 选 $r$ 个 = 不选 $n-r$ 个 | $\binom{n}{r} = \binom{n}{n-r}$ |
| Pascal 恒等式 | 选或不选一个特定元素 | $\binom{n}{r} = \binom{n-1}{r-1} + \binom{n-1}{r}$ |
| 星与条 | 可重复组合 | $\binom{r+n-1}{r}$ |
| 分组 | 有标签 vs 无标签 | 无标签时除以 $k!$ |

## 自测题

**1.** 从 $7$ 人中选 $3$ 人组队，有多少种选法？

<details>
<summary>答案</summary>

$\binom{7}{3} = \dfrac{7 \times 6 \times 5}{3 \times 2 \times 1} = 35$ 种。
</details>

**2.** 方程 $x_1 + x_2 + x_3 + x_4 = 15$，$x_i \geq 0$ 的非负整数解有多少组？

<details>
<summary>答案</summary>

$\binom{15 + 4 - 1}{4 - 1} = \binom{18}{3} = 816$ 组。
</details>

**3.** 从标准 $52$ 张扑克中抽 $5$ 张，恰好有 $2$ 张 A 的手牌有多少种？

<details>
<summary>答案</summary>

$2$ 张 A 从 $4$ 张 A 中选：$\binom{4}{2} = 6$。另外 $3$ 张从 $48$ 张非 A 中选：$\binom{48}{3} = 17{,}296$。

$6 \times 17{,}296 = 103{,}776$ 种。
</details>
