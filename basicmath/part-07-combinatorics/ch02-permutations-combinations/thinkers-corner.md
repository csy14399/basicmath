## 1. 生成函数（Generating Functions）

### 从组合到代数

生成函数是将组合数学问题"编码"为代数运算的强大工具。

设数列 $\{a_n\}$，其**普通生成函数**（ordinary generating function, OGF）为

$$A(x) = \sum_{n=0}^{\infty} a_n x^n$$

例如，$a_n = \binom{m}{n}$ 的生成函数就是 $(1+x)^m$——这正是二项式定理（Ch03）。

**乘法的组合意义**：如果 $A(x) = \sum a_n x^n$ 和 $B(x) = \sum b_n x^n$，则

$$A(x) \cdot B(x) = \sum_{n=0}^{\infty} c_n x^n, \quad c_n = \sum_{k=0}^{n} a_k b_{n-k}$$

$c_n$ 就是**卷积**——Vandermonde 恒等式正是 $(1+x)^m \cdot (1+x)^n = (1+x)^{m+n}$ 的系数比较！

### 一窥威力

用生成函数可以一行证明 $\sum_{k} \binom{n}{k}^2 = \binom{2n}{n}$：

$(1+x)^n$ 中 $x^k$ 的系数是 $\binom{n}{k}$。$(1+x)^n \cdot (1+x)^n = (1+x)^{2n}$。比较 $x^n$ 的系数：左端 $= \sum_k \binom{n}{k}\binom{n}{n-k} = \sum_k \binom{n}{k}^2$，右端 $= \binom{2n}{n}$。

## 2. 置换群（Permutation Groups）

### 排列的代数结构

排列不只是计数对象——它们构成一个**群**（group）。$n$ 个元素的全排列集合在"复合"运算下构成**对称群** $S_n$，是代数学中最基本的群之一。

每个排列可以唯一分解为**不相交轮换**（disjoint cycles）的乘积。例如，排列 $(2, 3, 1, 5, 4)$ 分解为 $(1\;2\;3)(4\;5)$——这表示 $1 \to 2 \to 3 \to 1$ 和 $4 \to 5 \to 4$。

### 排列的奇偶性

每个排列要么是**偶排列**（可以分解为偶数个对换），要么是**奇排列**（奇数个对换）。$S_n$ 中偶排列恰好有 $n!/2$ 个——它们构成**交替群** $A_n$。

## 3. 第二类 Stirling 数

### 从满射到集合分拆

将 $n$ 个不同的对象分成 $k$ 个非空、无标签的组的方式数称为**第二类 Stirling 数** $S(n, k)$（或 $\left\{n \atop k\right\}$）。

它与满射数的关系：$n$ 元集到 $k$ 元集的满射数 $= k! \cdot S(n, k)$。

递推关系：$S(n, k) = k \cdot S(n-1, k) + S(n-1, k-1)$，$S(n, 1) = S(n, n) = 1$。

| $S(n,k)$ | $k=1$ | $k=2$ | $k=3$ | $k=4$ | $k=5$ |
|-----------|-------|-------|-------|-------|-------|
| $n=1$ | $1$ | | | | |
| $n=2$ | $1$ | $1$ | | | |
| $n=3$ | $1$ | $3$ | $1$ | | |
| $n=4$ | $1$ | $7$ | $6$ | $1$ | |
| $n=5$ | $1$ | $15$ | $25$ | $10$ | $1$ |

**Bell 数** $B_n = \sum_{k=1}^{n} S(n, k)$ 计算 $n$ 元集合的所有可能分拆数。

## 4. Pólya 计数定理

### 对称性下的计数

当对象之间有对称关系（如旋转、翻转）时，直接计数会产生重复。**Burnside 引理**说：

$$\text{不等价的着色数} = \frac{1}{|G|}\sum_{g \in G} |X^g|$$

其中 $G$ 是对称群，$X^g$ 是被变换 $g$ 保持不变的着色集合。

**例子**：正方形有 $8$ 个对称操作（$4$ 个旋转 + $4$ 个翻转）。用 $k$ 种颜色给 $4$ 个顶点着色，不等价的着色数为

$$\frac{1}{8}(k^4 + 2k + k^2 + 2k^2 + 2k^2) = \frac{k^4 + 2k^3 + 3k^2 + 2k}{8}$$

$k = 2$ 时：$(16 + 16 + 12 + 4)/8 = 6$ 种。

**Pólya 计数定理**将 Burnside 引理进一步推广，给出了权重计数的完整公式——这是组合数学与群论的深刻交汇。
