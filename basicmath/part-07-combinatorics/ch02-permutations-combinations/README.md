# 第 2 章：排列组合（Permutations & Combinations）

## 章概览

排列（permutation）和组合（combination）是计数问题的核心工具。它们将 Ch01 的加法原理和乘法原理系统化——当问题归结为"从 $n$ 个对象中选取 $r$ 个"时，排列和组合提供了标准的计数公式。本章分三节：首先研究排列（有序选取），然后研究组合（无序选取），最后展示组合数满足的一系列优美恒等式。

排列与组合的区别只在一个字——**序**：排列关心顺序，组合不关心顺序。理解这个区别，就理解了本章的核心。

- **处理特殊排列**：圆排列、可重复排列、多重集排列
