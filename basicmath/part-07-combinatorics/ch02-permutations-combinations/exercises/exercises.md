# 第 2 章 排列组合 — 练习题

## §1 排列

1. ★☆☆ 计算 $P(9, 4)$。

2. ★☆☆ $6$ 个人站成一排照相，共有多少种排法？

3. ★☆☆ 从 $26$ 个英文字母中选 $3$ 个不重复的字母排成一行，共有多少种排法？

4. ★★☆ $8$ 个人站成一排，甲和乙不相邻。有多少种排法？

5. ★★☆ $5$ 个男生和 $3$ 个女生站成一排，要求女生互不相邻。有多少种排法？

6. ★★☆ 用 BANANA 的字母排成一行，共有多少种不同的排列？

7. ★★☆ $6$ 人围坐圆桌，其中甲和乙必须相邻。有多少种坐法？

8. ★★☆ 用数字 $0, 1, 2, 3, 4, 5$ 组成没有重复数字的五位奇数，共有多少个？

9. ★★★ 单词 COMMITTEE 的字母有多少种不同排列？

10. ★★★ $n$ 对夫妇围坐圆桌，每对夫妇必须相邻。有多少种坐法？

## §2 组合

11. ★☆☆ 计算 $\binom{12}{5}$。

12. ★☆☆ 从 $9$ 人中选 $4$ 人参加会议，有多少种选法？

13. ★★☆ 平面上有 $10$ 个点，其中没有三点共线。这些点可以确定多少条直线？多少个三角形？

14. ★★☆ 方程 $x_1 + x_2 + x_3 = 12$，$x_i \geq 0$ 的非负整数解有多少组？若要求 $x_i \geq 2$，有多少组？

15. ★★☆ 从 $5$ 名男生和 $4$ 名女生中选 $4$ 人组队，要求至少有 $2$ 名女生。有多少种选法？

16. ★★☆ 把 $15$ 颗相同的球放入 $4$ 个不同的盒子，每个盒子至少放 $1$ 个球。有多少种放法？

17. ★★★ $20$ 人分成 $5$ 组，每组 $4$ 人，组没有标签。有多少种分法？

18. ★★★ 从 $\{1, 2, \ldots, 20\}$ 中选出 $5$ 个数，使得任意两个数的差的绝对值都大于 $1$。有多少种选法？

## §3 组合恒等式

19. ★☆☆ 验证 $\displaystyle\sum_{k=0}^{6}\binom{6}{k} = 2^6$。

20. ★★☆ 用 Vandermonde 恒等式计算 $\displaystyle\sum_{k=0}^{4}\binom{6}{k}\binom{8}{4-k}$。

21. ★★☆ 用 Hockey-stick 恒等式计算 $\binom{2}{2} + \binom{3}{2} + \binom{4}{2} + \cdots + \binom{10}{2}$。

22. ★★☆ 用组合证明证明 $\displaystyle\binom{2n}{2} = 2\binom{n}{2} + n^2$。

23. ★★★ 证明 $\displaystyle\sum_{k=0}^{n} \binom{n}{k}^2 = \binom{2n}{n}$。

24. ★★★ 证明 $\displaystyle\sum_{k=1}^{n} k^2 \binom{n}{k} = n(n+1)2^{n-2}$。
