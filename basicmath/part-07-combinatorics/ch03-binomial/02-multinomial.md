# §2 多项式定理（Multinomial Theorem）

**前置知识**：[本章 §1 二项式定理](01-binomial-theorem.md)、[Ch02 §1 排列](../ch02-permutations-combinations/01-permutations.md)（多重集排列 / 多项式系数）

**全景图**：二项式定理处理两项之和的 $n$ 次幂——如果是三项、四项甚至更多项之和呢？**多项式定理**（multinomial theorem）将二项式定理自然推广到任意有限项之和的幂展开。展开的系数——**多项式系数**（multinomial coefficient）——就是 Ch02 中学过的多重集排列数。

**预估学习时间**：约 2–3 小时

---

## 动机

$(a + b + c)^3$ 怎么展开？

直接用二项式定理两次：先把 $(a+b)$ 看成一个整体，$(a+b+c)^3 = ((a+b)+c)^3$，展开后再对每一项中的 $(a+b)^k$ 展开。但这种方法在项数更多或幂次更高时非常繁琐。

多项式定理提供了一步到位的公式。

---

## 1. 多项式定理的陈述

### 1.1 定理

> **定理 1**（多项式定理 / Multinomial Theorem）
>
> 对非负整数 $n$ 和任意实数 $x_1, x_2, \ldots, x_m$：
>
> $$(x_1 + x_2 + \cdots + x_m)^n = \sum_{\substack{k_1 + k_2 + \cdots + k_m = n \\ k_i \geq 0}} \binom{n}{k_1, k_2, \ldots, k_m} x_1^{k_1} x_2^{k_2} \cdots x_m^{k_m}$$
>
> 其中**多项式系数**（multinomial coefficient）定义为：
>
> $$\binom{n}{k_1, k_2, \ldots, k_m} = \frac{n!}{k_1! \, k_2! \cdots k_m!}$$

### 1.2 与二项式定理的关系

当 $m = 2$ 时，$k_1 + k_2 = n$，多项式系数变为

$$\binom{n}{k_1, k_2} = \frac{n!}{k_1! \, k_2!} = \binom{n}{k_1}$$

这就是二项式系数。

### 1.3 组合解释

$(x_1 + x_2 + \cdots + x_m)^n$ 是 $n$ 个因子 $(x_1 + \cdots + x_m)$ 的乘积。展开时，从每个因子中选一个 $x_i$，$n$ 次选择的结果构成一项。

如果 $x_1$ 被选了 $k_1$ 次，$x_2$ 被选了 $k_2$ 次，……，$x_m$ 被选了 $k_m$ 次（$k_1 + \cdots + k_m = n$），这一项就是 $x_1^{k_1} x_2^{k_2} \cdots x_m^{k_m}$。

选择"哪些因子贡献 $x_1$、哪些贡献 $x_2$、……"的方式数就是多重集排列数 $\frac{n!}{k_1! k_2! \cdots k_m!}$。

## 2. 多项式系数的性质

### 2.1 求和

所有多项式系数之和等于 $m^n$（令 $x_1 = x_2 = \cdots = x_m = 1$）：

$$\sum_{\substack{k_1 + \cdots + k_m = n \\ k_i \geq 0}} \binom{n}{k_1, k_2, \ldots, k_m} = m^n$$

**验证**：$m = 2$ 时 $\sum \binom{n}{k} = 2^n$。✓

### 2.2 项数

$(x_1 + \cdots + x_m)^n$ 展开后有 $\binom{n+m-1}{m-1}$ 项（即方程 $k_1 + \cdots + k_m = n$ 的非负整数解数——星与条！）。

### 2.3 多项式系数与组合数的关系

$$\binom{n}{k_1, k_2, \ldots, k_m} = \binom{n}{k_1} \binom{n-k_1}{k_2} \binom{n-k_1-k_2}{k_3} \cdots \binom{k_m}{k_m}$$

这说明多项式系数可以用一连串的二项式系数表示——先从 $n$ 中选 $k_1$ 个，再从剩余的 $n-k_1$ 中选 $k_2$ 个，以此类推。

## 3. 例题

> **例 1**（三项展开）
>
> 展开 $(a + b + c)^3$。

**解**：$n = 3$，$m = 3$。列出所有 $k_1 + k_2 + k_3 = 3$（$k_i \geq 0$）的解：

| $(k_1, k_2, k_3)$ | 系数 $\frac{3!}{k_1!k_2!k_3!}$ | 项 |
|---|---|---|
| $(3,0,0), (0,3,0), (0,0,3)$ | $1$ | $a^3, b^3, c^3$ |
| $(2,1,0), (2,0,1), (1,2,0), (0,2,1), (1,0,2), (0,1,2)$ | $3$ | $3a^2b, 3a^2c, 3ab^2, 3b^2c, 3ac^2, 3bc^2$ |
| $(1,1,1)$ | $6$ | $6abc$ |

$$(a+b+c)^3 = a^3 + b^3 + c^3 + 3a^2b + 3a^2c + 3ab^2 + 3b^2c + 3ac^2 + 3bc^2 + 6abc$$

共 $\binom{3+3-1}{3-1} = \binom{5}{2} = 10$ 项。✓ $\blacksquare$

> **例 2**（求特定项的系数）
>
> 求 $(x + y + z)^8$ 展开式中 $x^3 y^2 z^3$ 的系数。

**解**：$k_1 = 3, k_2 = 2, k_3 = 3$，$k_1 + k_2 + k_3 = 8$。✓

$$\binom{8}{3, 2, 3} = \frac{8!}{3! \cdot 2! \cdot 3!} = \frac{40320}{6 \times 2 \times 6} = \frac{40320}{72} = 560$$

$\blacksquare$

> **例 3**（含系数的多项式）
>
> 求 $(2x - y + 3z)^4$ 中 $x^2 y z$ 的系数。

**解**：$(2x - y + 3z)^4$ 中，$x_1 = 2x, x_2 = -y, x_3 = 3z$。$x^2 y z$ 对应 $k_1 = 2, k_2 = 1, k_3 = 1$。

$$\binom{4}{2,1,1}(2x)^2(-y)^1(3z)^1 = \frac{4!}{2! \cdot 1! \cdot 1!} \cdot 4x^2 \cdot (-y) \cdot 3z$$

$$= 12 \times 4 \times (-1) \times 3 \cdot x^2 y z = -144 \, x^2 y z$$

系数为 $-144$。$\blacksquare$

## 4. 多项式定理的应用

### 4.1 与计数的联系

多项式系数 $\binom{n}{k_1, \ldots, k_m}$ 的组合意义是：将 $n$ 个不同对象分成 $m$ 组，第 $i$ 组有 $k_i$ 个的方式数。这与 Ch02 §1 的多重集排列完全一致。

### 4.2 多项式系数恒等式

类比二项式系数的恒等式，多项式系数也满足递推：

$$\binom{n}{k_1, k_2, \ldots, k_m} = \binom{n-1}{k_1-1, k_2, \ldots, k_m} + \binom{n-1}{k_1, k_2-1, \ldots, k_m} + \cdots + \binom{n-1}{k_1, k_2, \ldots, k_m-1}$$

这是 Pascal 恒等式的推广——右边各项对应"第 $n$ 个因子选择了 $x_i$"的各种情况。

### 4.3 多项式定理与概率

在概率论中，**多项式分布**（multinomial distribution）描述的是 $n$ 次独立试验中每种结果出现 $k_i$ 次的概率：

$$P(X_1 = k_1, \ldots, X_m = k_m) = \binom{n}{k_1, \ldots, k_m} p_1^{k_1} \cdots p_m^{k_m}$$

这正是 $(p_1 + p_2 + \cdots + p_m)^n = 1$ 展开式中的一项。

## 要点回顾

| 概念 | 核心内容 | 公式/关键点 |
|------|----------|-------------|
| 多项式定理 | $(x_1 + \cdots + x_m)^n$ 展开 | $\sum \binom{n}{k_1, \ldots, k_m} x_1^{k_1}\cdots x_m^{k_m}$ |
| 多项式系数 | 分组的方式数 | $n!/(k_1! \cdots k_m!)$ |
| 项数 | 展开式的总项数 | $\binom{n+m-1}{m-1}$ |
| 系数之和 | 全部令 $1$ | $m^n$ |
| 与二项式的关系 | $m=2$ 的特例 | 多项式系数 $=$ 二项式系数 |

## 自测题

**1.** 求 $(a + b + c)^4$ 展开式中 $a^2 bc$ 的系数。

<details>
<summary>答案</summary>

$\binom{4}{2,1,1} = \frac{4!}{2! \cdot 1! \cdot 1!} = 12$。
</details>

**2.** $(x + y + z)^6$ 展开式共有多少项？

<details>
<summary>答案</summary>

$\binom{6 + 3 - 1}{3 - 1} = \binom{8}{2} = 28$ 项。
</details>

**3.** 求 $(1 + x + x^2)^4$ 展开式中 $x^4$ 的系数。

<details>
<summary>答案</summary>

设 $a = 1, b = x, c = x^2$。$x^4$ 对应 $k_2 + 2k_3 = 4$，$k_1 + k_2 + k_3 = 4$。

可能的 $(k_1, k_2, k_3)$：
- $(0, 4, 0)$：$\binom{4}{0,4,0} = 1$
- $(1, 2, 1)$：$\binom{4}{1,2,1} = 12$
- $(2, 0, 2)$：$\binom{4}{2,0,2} = 6$

总系数 $= 1 + 12 + 6 = 19$。
</details>
