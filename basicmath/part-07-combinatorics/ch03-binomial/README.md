# 第 3 章：二项式定理（Binomial Theorem）

## 章概览

二项式定理（binomial theorem）是代数与组合数学之间最优美的桥梁之一。它告诉我们 $(a+b)^n$ 展开后每一项的系数——恰好就是组合数 $\binom{n}{k}$。这不是巧合：展开 $(a+b)^n$ 的过程就是从 $n$ 个因子中"选 $a$ 还是选 $b$"的组合选择。

本章首先建立二项式定理并用数学归纳法严格证明，然后通过特殊值和系数提取展示其强大的应用能力。最后将二项式定理推广到**多项式定理**（multinomial theorem），处理三个或更多项的幂展开。
