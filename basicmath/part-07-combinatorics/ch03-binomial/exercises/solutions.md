# 第 3 章 二项式定理 — 练习题解答

## §1 二项式定理

**1.** $(x+1)^4 = x^4 + 4x^3 + 6x^2 + 4x + 1$。

---

**2.** $(2a-b)^4 = \sum_{k=0}^{4}\binom{4}{k}(2a)^{4-k}(-b)^k$

$= 16a^4 - 32a^3b + 24a^2b^2 - 8ab^3 + b^4$。

---

**3.** $x^4$ 对应 $k = 2$：$\binom{6}{2} \cdot 3^2 = 15 \times 9 = 135$。

---

**4.** $T_{k+1} = \binom{10}{k}(2x)^{10-k}(-1)^k$。$x^7$ 对应 $10 - k = 7$，$k = 3$。

$\binom{10}{3} \cdot 2^7 \cdot (-1)^3 = 120 \times 128 \times (-1) = -15360$。

---

**5.** $T_{k+1} = \binom{9}{k}(x^2)^{9-k}(x^{-1})^k = \binom{9}{k}x^{18-2k-k} = \binom{9}{k}x^{18-3k}$。

常数项：$18 - 3k = 0$，$k = 6$。$\binom{9}{6} = 84$。

---

**6.** $\binom{20}{k}$ 在 $k = 10$ 时最大，$\binom{20}{10} = 184756$。

对应项：$\binom{20}{10}x^{10} = 184756x^{10}$。

---

**7.** $(2 + (-1))^n = \sum_{k=0}^{n}\binom{n}{k}2^{n-k}(-1)^k = 1^n = 1$。$\blacksquare$

---

**8.** $0.99^{12} = (1 - 0.01)^{12}$。

$\approx 1 - 12(0.01) + \binom{12}{2}(0.01)^2 - \binom{12}{3}(0.01)^3$

$= 1 - 0.12 + 0.0066 - 0.000220 = 0.886$。

精确值 $\approx 0.88638...$，误差极小。

---

**9.** $(1+x)^n \cdot (1+x)^n = (1+x)^{2n}$。

左端 $x^n$ 的系数：$\sum_{k=0}^{n}\binom{n}{k} \cdot \binom{n}{n-k} = \sum_{k=0}^{n}\binom{n}{k}^2$。

右端 $x^n$ 的系数：$\binom{2n}{n}$。

因此 $\sum \binom{n}{k}^2 = \binom{2n}{n}$。$\blacksquare$

---

**10.** $\binom{2n}{n} = \frac{(2n)!}{(n!)^2}$。当 $n = p$ 为素数时：

$\binom{2p}{p} = \frac{(2p)(2p-1)\cdots(p+1)}{p!}$。

分子中 $2p$ 含因子 $p$，而分母 $p!$ 中 $p$ 恰好出现一次（$p$ 是素数）。

由 $(1+1)^{2p} = \sum \binom{2p}{k}$，$\binom{2p}{p}$ 是整数。$2p = p \cdot 2$ 贡献的因子 $p$ 除以分母的因子 $p$ 后仍然整除分子的其余部分。

更直接：$\binom{2p}{p} = \frac{2p}{p}\binom{2p-1}{p-1} = 2\binom{2p-1}{p-1}$，所以 $p \mid \binom{2p}{p}$ 当且仅当 $p \mid 2\binom{2p-1}{p-1}$。因为 $p > 2$ 是奇素数，$\gcd(p, 2) = 1$。由 Lucas 定理，$\binom{2p-1}{p-1} \equiv \binom{1}{0}\binom{p-1}{p-1} = 1 \pmod{p}$，所以 $\binom{2p}{p} = 2 \times (\text{something} \equiv 1) \equiv 2 \pmod{p}$。

实际上更简单：$p \mid \binom{2p}{p}$ 因为 $\binom{2p}{p} = \frac{(2p)!}{p! \cdot p!}$ 而 $v_p((2p)!) = 2 + \lfloor 2p/p^2 \rfloor + \cdots$ 而 $2v_p(p!) = 2(1 + \lfloor p/p^2 \rfloor + \cdots) = 2$。当 $p^2 > 2p$（即 $p > 2$）时两者相等，但分子中的 $2p$ 多贡献了一个 $p$。所以 $p \mid \binom{2p}{p}$。$\blacksquare$

---

## §2 多项式定理

**11.** $\binom{5}{3,1,1} = \frac{5!}{3! \cdot 1! \cdot 1!} = \frac{120}{6} = 20$。

---

**12.** $\binom{3 + 4 - 1}{4 - 1} = \binom{6}{3} = 20$ 项。

---

**13.** $(k_1, k_2, k_3) = (2, 2, 1)$。

$\binom{5}{2,2,1} \cdot 1^2 \cdot (-2)^2 \cdot 1^1 = \frac{5!}{2!2!1!} \times 4 = 30 \times 4 = 120$。

---

**14.** $x^3$ 对应 $k_2 + 2k_3 = 3$，$k_1 + k_2 + k_3 = 3$。

- $(k_1, k_2, k_3) = (0, 3, 0)$：$\binom{3}{0,3,0} = 1$
- $(k_1, k_2, k_3) = (0, 1, 1)$：$\binom{3}{0,1,1} = ... $ 不行，$k_1 + k_2 + k_3 = 2 \neq 3$。

再来：$k_1 = 3 - k_2 - k_3$，$k_2 + 2k_3 = 3$。
- $k_3 = 0$：$k_2 = 3$，$k_1 = 0$。系数 $= \binom{3}{0,3,0} = 1$。
- $k_3 = 1$：$k_2 = 1$，$k_1 = 1$。系数 $= \binom{3}{1,1,1} = 6$。

总系数 $= 1 + 6 = 7$。

---

**15.** $(1 + 1 + 1)^n = 3^n = \sum \binom{n}{k_1,k_2,k_3}$。$\blacksquare$

---

**16.** 设 $a = 1, b = x, c = x^2, d = x^3$。$x^6$ 对应 $k_2 + 2k_3 + 3k_4 = 6$，$k_1 + k_2 + k_3 + k_4 = 5$。

列出所有满足条件的 $(k_1, k_2, k_3, k_4)$：

| $(k_1, k_2, k_3, k_4)$ | 条件验证 | 系数 $\frac{5!}{k_1!k_2!k_3!k_4!}$ |
|---|---|---|
| $(2, 0, 0, 1)$ | $0+0+3=3 \neq 6$ | — |
| $(0, 0, 0, 2)$ | $0+0+6=6$, $\sum = 2 \neq 5$ | — |
| $(3, 0, 0, 0)$ 系列需 $k_2 + 2k_3 + 3k_4 = 6$ |

系统枚举 $k_4$：
- $k_4 = 2$：$k_2 + 2k_3 = 0$，$k_1 + k_2 + k_3 = 3$。$k_2 = k_3 = 0$，$k_1 = 3$。$(3,0,0,2)$：$\frac{5!}{3!0!0!2!} = 10$。
- $k_4 = 1$：$k_2 + 2k_3 = 3$，$k_1 + k_2 + k_3 = 4$。
  - $k_3 = 0$：$k_2 = 3$，$k_1 = 1$。$(1,3,0,1)$：$\frac{5!}{1!3!0!1!} = 20$。
  - $k_3 = 1$：$k_2 = 1$，$k_1 = 2$。$(2,1,1,1)$：$\frac{5!}{2!1!1!1!} = 60$。
- $k_4 = 0$：$k_2 + 2k_3 = 6$，$k_1 + k_2 + k_3 = 5$。
  - $k_3 = 0$：$k_2 = 6$，$k_1 = -1$ — 不行。
  - $k_3 = 1$：$k_2 = 4$，$k_1 = 0$。$(0,4,1,0)$：$\frac{5!}{0!4!1!0!} = 5$。
  - $k_3 = 2$：$k_2 = 2$，$k_1 = 1$。$(1,2,2,0)$：$\frac{5!}{1!2!2!0!} = 30$。
  - $k_3 = 3$：$k_2 = 0$，$k_1 = 2$。$(2,0,3,0)$：$\frac{5!}{2!0!3!0!} = 10$。

总系数 $= 10 + 20 + 60 + 5 + 30 + 10 = 135$。
